# cAtIx wiki: data

The knowledge base of the cAtIx assistant of Innopolis University, in OKF v0.2 (`wiki/`, see `wiki/README.md`), and what it
is made from (`raw/`). This branch has no code: the wiki's own run (`catix-wiki autopilot`, the code is on the main branch)
asks the sources, makes the pages and guides, checks them and commits here. A commit that fails the checks goes to a
`wiki-review/<time>` branch for a person (`catix-wiki autopilot accept | discard`).
