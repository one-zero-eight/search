# Вики Университета Иннополис

Каталог markdown-файлов в формате [Open Knowledge Format](https://okf.md/spec/) v0.2 (бандл). Из него ассистент cAtIx берёт знания об университете. Читатели — все, кто спрашивает об университете: студенты, аспиранты, абитуриенты, преподаватели, сотрудники, руководство и люди вне университета. Вики **собирается автоматически** из двух источников: [eduwiki](https://eduwiki.innopolis.university) и официальных документов университета ([раздел «Сведения об образовательной организации»](https://innopolis.university/sveden/), PDF). Руками файлы не правят: следующая сборка их перезапишет (см. «Как изменить»).

## Что где лежит

| Каталог | Тип (`type`) | Что это |
| --- | --- | --- |
| `courses/` | `course` | страницы курсов (программы, пререквизиты, оценивание) |
| `people/` | `person` | преподаватели: контакты, курсы |
| `programs/` | `study-plan` | учебные планы, списки электив |
| `procedures/` | `procedure` | как что-то сделать (академический отпуск, обмен) |
| `regulations/` | `regulation` | официальные положения (текст **дословно**) и общие правила |
| `calendars/`, `schedules/` | `calendar`, `schedule` | календари и расписания |
| `pages/` | `page` | остальное (FAQ, списки, главная) |
| `guides/` | `guide` | сводные страницы, собранные из многих источников |

`index.md` — оглавление, `log.md` — журнал сборок. Ссылки между файлами — обычные markdown-ссылки от корня бандла: `[текст](/courses/bsc-operating-systems.md)`. Идентификатор концепта — путь без `.md`.

## Что значит `status: draft`

`status: draft` — **черновик: страница создана программой и человек её не проверял**. Это не оценка качества, а честная отметка происхождения. Сейчас такие все страницы.

- Точность разная: дословные положения и таблицы (их переносит код) надёжнее, чем текст, который переписала модель.
- Страница становится проверенной, когда человек добавляет `verified: [{by: "human:<id>", at: "<дата>"}]` и ставит `status: stable`. Остальные значения (`deprecated` и др.) допустимы, словарь открытый.
- Проверка относится к конкретной версии. Если страницу собирают заново (изменился источник), отметка пропадает.

## Поля front matter

Стандартные поля OKF: `type` (обязательное), `title`, `description`, `resource` (адрес оригинала), `tags`, `aliases` (названия-редиректы), `sources`, `generated`, `status`, `stale_after`.

- `sources` — откуда взято: `resource` (адрес или путь в бандле), `id` (номер ревизии вики или хэш PDF), `title`, `last_modified`.
- `generated` — кем и когда создано (`by`: программа и модель).
- `stale_after` — когда информация считается устаревшей: через 2 года после последней правки источника (для календарей и расписаний через 1 год). **Просроченное значение — сигнал недоверия, не ошибка.** Сейчас у большинства страниц срок уже вышел: eduwiki обновлялась в 2021–2023 годах.
- `tags` — слова из `a-z`, `0-9` и `-` (теги с пробелами и спецсимволами приводятся к такому виду).

Наши расширения (OKF их сохраняет и не отвергает):

| Поле | Где | Смысл |
| --- | --- | --- |
| `audience` | положения, гайды | для кого страница: `student` (бакалавр, магистр), `postgraduate`, `applicant`, `teacher`, `staff`, `management`, `public` (вне университета). У положений выбирает модель из этого списка, у гайдов — модель при предложении темы или код по источникам. У страниц eduwiki поля нет: это студенты и преподаватели |
| `review` | любая | **есть непроверенное место**: потерянное положение таблиц, скан без вычитки, предложение гайда без подтверждения. Текст поля говорит, что именно |
| `source_warning` | гайды | опирается на скан (OCR): в буквах и числах возможны ошибки чтения, сверяйте с PDF |
| `source_kind: official-document` | положения | официальный документ университета: приоритет выше остальных |
| `extraction` | положения | как получен текст: `text layer` или `ocr (tesseract rus)` |
| `evidence_sha` | гайды | отпечаток свидетельств: пока не изменился, гайд не пересобирается |
| `prerequisites`, `prerequisite_of`, `taught_by`, `teaches`, `duplicate_of` | курсы, люди | связи, посчитанные по страницам (см. ниже); `relations_by` — кем |

Связи дублируются в теле файла блоком `## Relations` (между `<!-- catix:relations -->`), чтобы это были настоящие ссылки. Пререквизит с пометкой `via: model` выбрала модель из закрытого списка кандидатов, остальные найдены кодом по названиям и кодам курсов.

## Как читать страницу

Доверие по убыванию:

1. **Положения** (`source_kind: official-document`): текст университета без изменений. Номера пунктов сохранены (`**5.3.**`) — цитируйте их.
2. **Гайды**: код собрал свидетельства, модель написала связный текст. Каждое предложение имеет ссылку на свидетельство `[n]`, числа проверены программой. Смысл фразы программа не проверяет.
3. **Страницы курсов, людей и т. д.**: пересказ eduwiki; таблицы и структура — кодом, проза — моделью.

Ссылки `[n]` ведут в `# Citations` в конце страницы. Дубликаты (одна страница вики под разными названиями) помечены `duplicate_of`: актуальна страница, которую правили позже.

## Как это собирается

```bash
catix-wiki build            # вся цепочка, пересчитывается только изменившееся
catix-wiki build --offline  # без скачивания
catix-wiki lint             # проверка на соответствие OKF v0.2
```

| Шаг | Команда | Кто делает |
| --- | --- | --- |
| снимок eduwiki | `fetch` | код (API MediaWiki) → `raw/eduwiki/` (не в git) |
| положения (PDF) | `regs fetch`, `regs compile` | код: текстовый слой или OCR; модель пишет лишь описание и теги |
| страницы вики | `compile` | код: таблицы, разметка, источники; модель: тип, название, описание, теги, чистка прозы |
| ссылки, индекс | `link` | код |
| связи | `graph` | код; модель выбирает курс из 6 кандидатов только для строк, которые код не разобрал |
| гайды | `synth` | код: свидетельства и таблицы; модель: текст со ссылками; код: проверка |

Модель: локальная Qwen через `LLM_ROUTE` (llama.cpp). Подробности каждого шага в докстринге модуля `src/catix/wiki/`.

Защита от ошибок модели: страница с зациклившимся текстом или потерянными таблицами не записывается; гайд обязан цитировать, а числа в нём (в том числе записанные словами) должны быть в цитируемых свидетельствах; гайд без свидетельств не пишется.

## Как изменить

- Хотите исправить факт: меняйте **источник** (eduwiki) или код; ручная правка файла в `wiki/` пропадёт при следующей сборке этой страницы.
- Кому адресована вики и какие документы брать: `src/catix/wiki/instructions.md` — по ней модель отбирает документы `sveden`.
- Новое положение: добавьте его в `DOCS` в `regulations.py` (документы `sveden` подхватываются сами).
- Новая тема гайда: `TOPICS` в `synth.py`. Для положений достаточно `auto_topic(вопрос, [документы])`: модель сама выберет пункты по оглавлению, код проверит, что они существуют.

## Известные ограничения

- Всё в статусе `draft`; у части гайдов есть `review`. Для ответов, на которые будут опираться студенты, нужна выборочная вычитка.
- Проверка гайдов ловит выдуманные числа и несуществующие ссылки, но не логику фразы.
- Положения об отчислении и академической добросовестности прочитаны с **скана**: возможны ошибки в буквах и числах.
- Многие страницы eduwiki устарели (`stale_after` просрочен), часть курсов — пустые шаблоны (например, раздел о пересдаче).
- Общих правил пересдач и отчисления в самой eduwiki нет (есть только описания пересдачи в отдельных курсах): они подтянуты из положений.
