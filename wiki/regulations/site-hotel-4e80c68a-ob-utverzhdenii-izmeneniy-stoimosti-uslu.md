# Стоимость услуг размещения для льготных категорий

Стоимость услуг размещения в Жилом комплексе АНО ВО «Университет Иннополис» отдельных категорий лиц с 20 октября 2025 года

**1.** Стоимость услуг размещения по категориям номеров:

| № п/п | Категории номеров (тип размещения) | Стоимость койко- места за сутки, рублей |
| --- | --- | --- |
| Корпуса №№ 1–4 |  |  |
| 1. | Двухместный однокомнатный номер (койко-место) | 1 800 |
| 2. | Двухместный двухкомнатный номер (койко-место) | 2 200 |
| 3. | Четырехместный двухкомнатный номер (койко-место) | 1 800 |
| 4. | Пятиместный трехкомнатный номер (койко-место) | 1 800 |
| Корпуса №№ 5–7 |  |  |
| 1. | Двухместный однокомнатный номер (койко-место) | 2 100 |
| 2. | Трехместный однокомнатный номер (койко-место/второй ярус) | 1 000 |
| 3. | Трехместный однокомнатный номер (койко-место/первый ярус) | 1 400 |
| 4. | Трехместный однокомнатный номер (койко-место) | 1 800 |
| 5. | Четырехместный двухкомнатный номер (койко-место) | 2 000 |
| 6. | Пятиместный двухкомнатный номер (койко-место в трехместном блоке/второй ярус) | 1 000 |
| 7. | Пятиместный двухкомнатный номер (койко-место в трехместном блоке/первый ярус) | 1 400 |
| 8. | Пятиместный двухкомнатный номер (койко-место в трехместном блоке) | 1 600 |
| 9. | Пятиместный двухкомнатный номер (койко-место в двухместном блоке) | 2 000 |

В стоимость услуг размещения входит: поддерживающий клининг номеров, пользование холодильником, телевизором, микроволновой печью и чайником (при наличии в номере), кондиционером в летний период, Wi-Fi-зоной, автостоянкой, круглосуточной прачечной комнатой, а также предоставление комплекта постельного белья и полотенец. Ребенку в возрасте до 7 (семи) лет включительно услуги размещения оказываются бесплатно при совместном размещении с родителем без предоставления отдельного места.

**4.** Категории лиц, которым предоставляется скидка при оказании услуг размещения:

- – для обучающихся АНО ВО «Университет Иннополис» предоставляется скидка

в размере 90 % от стоимости услуг размещения по типу «койко-место» на период обучения;

- – для окончивших обучение в АНО ВО «Университет Иннополис» (выпускникам)

предоставляется скидка в размере 72 % от стоимости услуг при размещении по типу «койко-место» в течение первого года после окончания обучения;

- – для сотрудников АНО ВО «Университет Иннополис» при размещении в

двухместном однокомнатном номере устанавливается скидка за каждое койко-место в размере 90 % от стоимости услуг размещения при соблюдении условий, указанных в Порядке согласования на корпоративном портале «Битрикс24» заявок на временное размещение в жилом комплексе АНО ВО «Университет Иннополис» сотрудников АНО ВО «Университет Иннополис» в период ожидания арендного жилья или в рамках служебной необходимости, а также приглашенных лиц;

- – для студентов и сотрудников АНО ВО «Университет Иннополис» при

размещении совместно с супругой/супругом в номере устанавливается скидка за второе койко-место для супруга/супруги в размере 80 % от стоимости услуг размещения;

- – для студентов и сотрудников АНО ВО «Университет Иннополис» при

размещении совместно с супругой/супругом и детьми в номере устанавливается скидка за койко-место для супруга/супруги в размере 70 %, несовершеннолетние дети при этом размещаются совместно с родителями на дополнительных местах в номере соответствующей вместимости;

- – для сотрудников АО «Иннополис» при размещении в двухместном

однокомнатном номере устанавливается скидка за каждое койко-место в размере 90 % от стоимости услуг размещения.

**5.** В период академического отпуска обучающимся в АНО ВО «Университет Иннополис», указанным в пункте 4 настоящего Приложения, скидка на услуги размещения не предоставляется.
