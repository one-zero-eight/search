Примерные практические задания для промежуточной аттестации Примерное практическое задание по Модулю 1 «Педагогический модуль» Тема: Верстка учебного макета Цель: сверстать сайт по учебному макету со своей страницей и выложить его на Github Pages Форма работы: Индивидуальная Набор технологий: HTML, CSS, JS, Github Pages Требования к проекту:

- • HTML и CSS код проходит валидацию без ошибок (красные).

Предупреждения допустимы (желтые).

- • Макс ширина содержимого, как на макете.

- • Содержимое страницы должно располагаться по центру при

ширине вьюпорта больше максимальной.

- • Адаптивная верстка. Минимальная ширина содержимого 400

пикселей. Дизайн решения при адаптиве на усмотрение студента.

- • При уменьшении вьюпорта меньше максимальной ширины

контент не должен выходить за вьюпорт. Нельзя скрывать эту проблему через overflow: hidden.

- • При наполнении контентом, как на макете, страница должна

выглядеть как на макете. Допускаются отличия в тексте, небольшие отличия расстояниях. Пиксель в пиксель верстать не нужно. Цвета должны совпадать.

- • Вместо заглушек должен быть контент по выбору студентом.

- • К странице студента о себе относятся все требования, кроме

соответствия макету. При этом шапка и футер должны быть как на макете. Примерное практическое задание по Модулю 3 «Профессиональный модуль» Тема: Разработка чат-бота Цель: Разработать программный продукт Форма работы: Групповая Перед выполнением работы студентам необходимо провести анализ существующей информации по тематике проекта и распространенных подходов, и методик реализации чат-бота на языке Python. Сбор информации: изучение мессенджеров, изучение информации от приемной комиссии университета, сбор информации реализации чатбота. Осуществляется студентом самостоятельно из открытых источников, без нарушения авторских и смежных прав. Предполагается активная работа с заказчиком и кураторами проекта. Формирование видения продукта: обработка информации осуществляется студентами самостоятельно. Результаты этапа:

- • Выбор технологий и средств для разработки чат-бота.

- • Формирование набора задач для реализации.

- • Формирование набора выходных данных для чат-бота

Проектирование осуществляется студентами самостоятельно. Архитектура: определение основных функций чат-бота. Результат:

- • Набор функций и их использование.

- • Иерархия запросов в чат-боте.

- • Регистрация чат-бота на платформе Telegram

Интерфейс чат-бота: определение команд чат-бота и способов взаимодействия с пользователем. Результаты этапа:

- • Набор команд чат-бота

- • Элементы управления чат-бота

Разработка программного продукта: написание программного кода на языке Python, подключение чат-бота в Telegram к написанной программной составляющей. Результаты этапа: программный продукт чат-бот. Заполнение дневника стажировки. Основным отчетным документом для стажера является дневник стажировки (приложение 2). В дневнике стажер дает краткую характеристику места стажировки, формулирует цели стажировки согласно программе стажировки. В дневнике ведется ежедневный учет выполненной работы. Дневник заканчивается отчетом по стажировке. В конце срока проведения стажировки руководителем от организации дается отзыв (заключение) о ее прохождении стажером. Соответствующая запись производится в дневнике и заверяется печатью организации. Защита проектной работы Целью защиты проектной работы является установление уровня подготовленности обучающегося, осваивающего дополнительную профессиональную программу, к выполнению профессиональных задач и соответствия его подготовки требованиям федерального государственного образовательного стандарта высшего образования (требованиям образовательного стандарта) и профессионального стандарта. В рамках государственной итоговой аттестации проверяется уровень сформированности результатов освоения образовательной программы. Тематика проектных работ должна быть направлена на решение определенных профессиональных задач. В результате проектной работы слушатель должен либо предоставить проект разработки информационной системы, либо разработать и задокументировать программный код модуля информационной системы. Тема может быть предложена обучающимся самостоятельно, или выбрана из перечня типовых тем. Примеры тем проектных работ:

- - Информационная система управления инцидентами, проблемами и

изменениями IT-сервиса банка;

- - Разработка автоматизированной системы размещения контента на

российских интернет-площадках.

- - Разработка и реализация алгоритмов поиска при неполном совпадении

элементов запроса и содержимого области поиска.

- - Разработка справочной системы зональной научной библиотеки

учебного заведения.

- - Прогнозирование нагрузки на техподдержку по данным с обращений

клиентов методами статистики и искусственного интеллекта.

- - Прогнозирование нагрузки на магазин по известным чекам методами

искусственного интеллекта.

- - Производственная система контроля нанесения рисунка на битумное

полотно при производстве мягкой черепицы с использованием линейной промышленной камеры.

- - Анализ данных пациентов с кардиологическими патологиями методами

машинного обучения.

- - Сервис хранения и обмена данными для корпоративных клиентов.

- - Исследование мастер-системы, системы хранения и их сопровождение

в банке.
