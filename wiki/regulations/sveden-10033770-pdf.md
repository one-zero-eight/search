| 1. ОБЩИЕ ПОЛОЖЕНИЯ |
| --- |
| 1.1. Колледж автономной некоммерческой организации высшего образования |
| «Университет Иннополис» (далее – Колледж) является структурным подразделением |
| автономной некоммерческой организации высшего образования «Университет |
| Иннополис» (далее – Университет), осуществляющим подготовку обучающихся по |
| образовательным программам в соответствии с федеральными государственными |
| образовательными стандартами среднего профессионального образования (далее |
| также – СПО). |
| 1.2. Настоящее Положение о колледже автономной некоммерческой |
| организации высшего образования «Университет Иннополис» (далее – Положение) |
| регулирует деятельность Колледжа, определяет его задачи, функции, права и |
| обязанности. |
| 1.3. В своей деятельности Колледж руководствуется действующим |
| законодательством и иными нормативно-правовыми актами Российской Федерации, |
| Уставом Университета, Правилами внутреннего трудового распорядка Университета, |
| Порядком приема на обучение по образовательным программам среднего |
| профессионального образования, Положением о порядке организации и |
| осуществления образовательной деятельности по образовательным программам |
| среднего профессионального образования в Колледже, иными локально- |
| нормативными актами Университета, а также настоящим Положением. |
| 1.4. Колледж не имеет статус юридического лица, является структурным |
| подразделением Университета в подчинении начальника управления по организации |
| и сопровождению проектно-образовательной деятельности. |
| 1.5. Колледж создается, переименовывается и ликвидируется приказом |
| директора Университета в соответствии с действующим законодательством |
| Российской Федерации. |
| 1.6. Условия труда сотрудников Колледжа определяются трудовыми |
| договорами, заключаемыми с каждым сотрудником, а также Правилами внутреннего |
| трудового распорядка Университета. |
| 1.7. Права, обязанности, степень ответственности сотрудников Колледжа |
| устанавливаются должностными инструкциями, нормами трудового и гражданского |
| законодательства Российской Федерации. |
| 1.8. Сотрудники Колледжа могут привлекаться в рамках своих компетенций к |
| участию в выполнении работ по грантам/проектам/субсидиям и иным программам, |
| реализуемых Университетом. |
| 1.9. Настоящее Положение, а также вносимые в него дополнения и изменения |
| утверждаются директором Университета или иным уполномоченным им лицом. |
| 2. ЦЕЛИ, ЗАДАЧИ И ФУНКЦИИ КОЛЛЕДЖА |
| 2.1. Целью создания Колледжа является реализация образовательных программ |
| СПО, направленных на подготовку квалифицированных специалистов, отвечающих |
| требованиям рынка труда и стандартам СПО. |

| 2.2. Основными задачами Колледжа являются: |
| --- |
|  организация и контроль проведения образовательного процесса в |
| соответствии с требованиями федерального законодательства, регулирующего |
| образовательную деятельность, федеральных государственных образовательных |
| стандартов (далее – ФГОС), иных федеральных и региональных нормативно-правовых |
| актов, локальных нормативных актов Университета; |
|  внедрение практико-ориентированного обучения и развитие |
| профессиональных компетенций у обучающихся; |
|  интеллектуальное, культурное, физическое и нравственное развитие |
| обучающихся; |
|  удовлетворение потребностей общества в квалифицированных |
| специалистах, в том числе в сфере информационных технологий, робототехники и |
| мехатроники; |
|  разработка и реализация образовательных программ СПО и удовлетворение |
| потребности личности в получении СПО и квалификации в избранной области |
| профессиональной деятельности; |
|  формирование у обучающихся гражданской позиции и трудолюбия, |
| развитие ответственности, самостоятельности и творческой активности; |
|  сохранение и приумножение нравственных и культурных ценностей |
| общества; |
|  развитие цифровых компетенций обучающихся, необходимых для успешной |
| профессиональной деятельности в условиях цифровой экономики. |
| 2.3. Основные функции Колледжа: |
|  планирование, организация, координация и контроль учебной, учебно- |
| методической, практической и воспитательной работы в процессе реализации |
| образовательных программ СПО и проведение учебного процесса в соответствии с |
| требованиями действующего законодательства Российской Федерации, Уставом |
| Университета, и локально-нормативными актами Университета; |
|  выполнение требований ФГОС при организации образовательного процесса |
| и подготовке соответствующих локально-нормативных актов; |
|  поддержание связей с общеобразовательными учебными заведениями и |
| проведение профориентационной и рекламно-информационной работы в |
| соответствии с планами, утвержденными приемной комиссией; |
|  взаимодействие с научными и общественными организациями по созданию |
| благоприятных условий, способствующих росту объема и качества знаний |
| обучающихся; |
|  обеспечение взаимодействия с государственными и муниципальными |
| органами власти и иными учреждениями и предприятиями в той мере, в которой это |
| необходимо для обеспечения решения задач Колледжа; |
|  реализация мероприятий по гражданской обороне, охране труда и |
| пожарной безопасности в Колледже; |
|  разработка стратегии развития и ежегодного плана работы Колледжа; |
|  обеспечение внедрения новых технологий обучения и контроля знаний |
| обучающихся; |

|  координирование деятельности преподавательского состава, учебно- |
| --- |
| вспомогательного персонала, а также обучающихся Колледжа; |
|  организация и проведение учебной, методической и воспитательной |
| работы в Колледже; |
|  оформление договоров на предоставление платных образовательных услуг |
| по образовательным программам СПО и контроль своевременности оплаты обучения; |
|  составление учебного расписания, расписания зачетов и экзаменов, |
| контроль их выполнения; |
|  организация учета успеваемости, посещаемости обучающихся и анализ их |
| результатов; |
|  организация и контроль реализации промежуточной и итоговой аттестации |
| обучающихся; |
|  организация и проведение воспитательной и просветительской работы |
| среди обучающихся, а также координация общественно-полезной деятельности |
| обучающихся и сотрудников Колледжа; |
|  создание и обеспечение благоприятных условий для сотрудников и |
| обучающихся Колледжа; |
|  организация и контроль повышения квалификации и переподготовки |
| сотрудников Колледжа; |
|  ведение документации Колледжа по учебным, методическим вопросам и |
| воспитательной работе; |
|  контроль состояния учебных, производственных и служебных помещений, |
| закрепленных за Колледжем; |
|  взаимодействие с предприятиями – базами прохождения практик и |
| организациями различных видов практик и стажировок; |
|  организация взаимодействия с работодателями для обеспечения |
| трудоустройства выпускников и адаптации образовательных программ к требованиям |
| рынка труда; |
|  поддержание связи с выпускниками Колледжа и содействие |
| трудоустройству выпускников; |
|  подведение итогов работы Колледжа и своевременно предоставление их |
| руководству Университета. |
| 3. УПРАВЛЕНИЕ |
| 3.1. Управление Колледжем осуществляется в соответствии с |
| законодательством Российской Федерации, Уставом Университета, иными локально- |
| нормативными актами и настоящим Положением. |
| 3.2. Руководство деятельностью Колледжа осуществляет директор, |
| назначаемый приказом директора Университета на основании заключенного |
| трудового договора, должностной инструкцией и на основании локально- |
| нормативных актов Университета. |
| 3.3. Директор Колледжа в пределах своих компетенций, определяемых |
| директором Университета: |

|  осуществляет руководство Колледжем в соответствии с законами, иными |
| --- |
| нормативно-правовыми, локально-нормативными актами Университета и несет |
| ответственность перед директором Университета за результаты деятельности |
| Колледжа; |
|  разрабатывает и реализует стратегию развития Колледжа, организует |
| взаимодействие с другими образовательными учреждениями и организациями для |
| обмена опытом и внедрения лучших практик; |
|  непосредственно организует и руководит учебной, воспитательной и |
| инновационной работой в Колледже; |
|  обеспечивает реализацию программ подготовки специалистов среднего |
| звена в соответствии с требованиями ФГОС СПО; |
|  осуществляет контроль за обеспечением обучающихся Колледжа учебной |
| литературой по всем изучаемым дисциплинам согласно существующим нормативам и |
| ее своевременным обновлением; |
|  организует и контролирует работу по информационному обеспечению |
| учебного процесса посредством современных информационных источников; |
|  организует и контролирует реализацию учебных планов во всех их |
| компонентах; |
|  организует систему контроля качества учебных занятий, практик и иных |
| форм организации учебного процесса; |
|  на основании отсутствия академической задолженности, выполнения |
| учебного плана или индивидуального учебного плана по осваиваемой |
| образовательной программе СПО организует в установленном порядке допуск |
| обучающихся к государственной итоговой аттестации; |
|  в пределах своей компетенции издает нормативные акты, обязательные для |
| всех сотрудников и обучающихся Колледжа; |
|  представляет на утверждение проекты штатного расписания сотрудников и |
| планов финансово-хозяйственной деятельности; |
|  разрабатывает предложения и проводит мероприятия по укреплению и |
| развитию учебной и материально-технической базы, совершенствованию финансово- |
| хозяйственной деятельности, укреплению дисциплины и законности, обеспечению |
| сохранности и экономному расходованию материально-технических ресурсов и |
| денежных средств Колледжа, оснащению современным оборудованием, учебной |
| литературой, пособиями и техническими средствами обучения, обеспечивает их |
| сохранность, пополнение и эффективное использование; |
|  организует и обеспечивает участие преподавателей, сотрудников в |
| совершенствовании образовательного процесса; |
|  принимает меры по комплектованию Колледжа квалифицированными |
| кадрами, организации регулярного повышения квалификации преподавательского |
| состава и иных категорий сотрудников Колледжа, обмену опытом, созданию |
| благоприятных и безопасных условий труда, соблюдению требований правил по |
| охране труда и пожарной безопасности; |
|  способствует развитию трудовой мотивации, инициативы и активности |
| сотрудников Колледжа; |

|  вносит предложения по созданию необходимых социально-бытовых |
| --- |
| условий для обучающихся и сотрудников Колледжа; |
|  координирует подготовку, рецензирование учебно-методических |
| документов, выполнение научно-методической работы; |
|  обеспечивает своевременное составление установленной отчетной |
| документации; |
|  организует работу и взаимодействие Колледжа с другими структурными |

|  выполняет иные обязанности, предусмотренные законодательством |
| Российской Федерации, локально-нормативными актами Университета, должностной |
| инструкцией. |

| процесса, расходование денежных средств, результаты финансово-хозяйственной |
| деятельности, полное и своевременное представление статистической отчетности, |

| 4. ПРАВА |
| --- |
| 4.1. Для выполнения возложенных на Колледж задач сотрудники Колледжа |
| имеют право: |
| – запрашивать от руководителей и сотрудников структурных подразделений |
| Университета необходимые информационные материалы по вопросам учебной и |
| методической работы; |
| – участвовать в конкурсах, грантах и проектах, направленных на развитие |
| образовательной деятельности и повышение качества образовательных услуг; |
| – решать вопросы совершенствования и организации учебного процесса в |
| Колледже в рамках своей компетенции, вносить соответствующие предложения |
| руководству; |
| – требовать от соответствующих структурных подразделений Университета |
| создания необходимых технических условий для организации учебного процесса и |
| работы сотрудников Колледжа; |

| деятельности Колледжа; |
