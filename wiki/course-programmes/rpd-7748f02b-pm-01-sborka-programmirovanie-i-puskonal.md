## 2. Оценочные средства промежуточной аттестации

**2.1.** МДК.01.01 Установка и регулировка элементов мехатронных систем Зачет с оценкой (4 семестр) Зачет с оценкой по МДК в форме письменной контрольной работы проводится с целью оценки уровня и качества усвоенных умений и знаний в конце изучения МДК. Задания дифференцируются по уровню сложности. Варианты заданий для контрольной работы равноценны по трудности, одинаковы по структуре, параллельны по расположению заданий: под одним и тем же порядковым номером во всех вариантах контрольной работы находится задание, проверяющее один и тот же элемент содержания МДК. На выполнение контрольной работы отводится 90 минут. Задания, применяемые на зачете. Тестовые задания:

| Задача 1.1 |
| --- |
| Условие: При монтаже индуктивного датчика приближения (PNP, NO) мехатронной |
| станции необходимо настроить зазор между датчиком и металлической пластиной. В |
| паспорте датчика указан диапазон срабатывания 2…5 мм. |
| Требования: Определить оптимальный зазор, обеспечить надежное срабатывание и |
| гистерезис. Оформить протокол настройки. |
| Пример решения: Выбираем зазор 3 мм (середина диапазона). При перемещении |
| пластины проверяем: при приближении – датчик должен выдать логическую 1 (24 В |
| на выходе), при удалении – 0. Гистерезис обеспечивается конструкцией. Записываем |
| в протокол: тип датчика, установленный зазор, напряжение питания, результат. |
| Правильный ответ: Оптимальный зазор – 3…3,5 мм. Протокол содержит дату, |
| подпись, измеренное расстояние и тестовые состояния. |
| Задача 1.2 |
| Условие: На мехатронной станции не работает аналоговый вход ПЛК, к которому |
| подключен датчик давления 4–20 мА. При давлении 0 бар на выходе датчика 4 мА, |
| при 10 бар – 20 мА. ПЛК показывает 0. |
| Требования: Найти неисправность, предложить порядок проверки. |
| Пример решения: 1) Проверить питание датчика (24 В). 2) Измерить ток в цепи |
| миллиамперметром – если есть 4 мА, то датчик исправен. 3) Проверить соединение |
| проводов с клеммой ПЛК. 4) Проверить конфигурацию входа (тип сигнала, |
| масштабирование). |
| Правильный ответ: Неисправность: обрыв цепи или неправильная конфигурация |
| входа ПЛК. После восстановления цепи и настройки масштабирования (Raw min=0, |
| Raw max=27648, Eng min=0, Eng max=10) показания должны соответствовать |
| давлению. |
| Задача 1.3 |
| Условие: При пуско-наладке пневматического цилиндра он медленно выдвигается. |
| Давление в магистрали 6 бар, регулятор давления на станции установлен на 5 бар. |
| Требования: Определить возможные причины и устранить. |
| Пример решения: Проверить: 1) достаточный расход воздуха (диаметр трубок, не |
| пережат ли шланг); 2) правильность подключения быстроразъемных соединений; 3) |
| наличие фильтра-влагоотделителя; 4) не заедает ли поршень. |
| Правильный ответ: Причина – заниженное давление или засор фильтра. Увеличить |
| давление до номинального, прочистить фильтр, проверить смазку. |
| Задача 1.4 |
| Условие: При проверке структурной схемы мехатронной системы вы обнаружили, что |
| сигнал от датчика температуры подается на два разных регулятора. Допустимо ли это |
| с точки зрения электрических характеристик? |
| Требования: Дать аргументированный ответ и предложить схему подключения, если |
| допустимо. |
| Пример решения: Если датчик имеет аналоговый выход (0–10 В или 4–20 мА), |
| пассивное параллельное подключение недопустимо из-за искажения сигнала. |
| Следует использовать разветвитель сигнала (изолирующий преобразователь 1 вход – |
| 2 выхода). |
| Правильный ответ: Не допускается; нужно применить гальванически развязанный |
| --- |
| повторитель сигнала. |
| Задача 1.5 |
| Условие: При наладке системы позиционирования сервопривода требуется настроить |
| конечные выключатели (механические). Ход штока 200 мм. Выключатели должны |
| срабатывать при 5 мм до конца хода. |
| Требования: Указать, как выставить выключатели и проверить. |
| Пример решения: 1) Переместить шток в крайнее левое положение. Установить |
| левый концевик так, чтобы его толкатель касался упора за 5 мм до упора. 2) |
| Аналогично для правого. 3) В ручном режиме проверить срабатывание. |
| Правильный ответ: Зазор должен быть подобран так, чтобы при движении штока |
| концевик щелкал за 5 мм до механического упора. |
| Задача 1.6 |
| Условие: В мехатронной системе используется датчик Холла для определения |
| положения магнита на штоке. При медленном перемещении штока сигнал датчика |
| пропадает, при быстром – появляется. |
| Требования: Определить вероятную причину. |
| Пример решения: Возможно, магнит расположен далеко от датчика, и гистерезис не |
| позволяет зафиксировать слабое поле. Или датчик имеет минимальную частоту |
| переключения. |
| Правильный ответ: Недостаточная напряженность поля в статике; следует |
| уменьшить зазор или использовать датчик с большей чувствительностью. |
| Задача 1.7 |
| Условие: Необходимо разработать технологическую карту проверки |
| потенциометрического датчика угла поворота (0–10 В). |
| Требования: Перечислить операции и оборудование. |
| Пример решения: Операции: 1) Визуальный осмотр. 2) Проверка сопротивления |
| между крайними выводами (должно быть по паспорту). 3) Подключение к источнику |
| питания 10 В. 4) Измерение выходного напряжения при разных углах (0°, 45°, 90°, …), |
| построение характеристики. 5) Сравнение с идеальной линейной зависимостью. |
| Оборудование: мультиметр, источник питания, угломер. |
| Правильный ответ: Технологическая карта включает последовательность из 5 |
| операций с допусками ±2% от линейности. |
| Задача 1.8 |
| Условие: При монтаже электродвигателя с частотным преобразователем появились |
| ложные срабатывания датчика обратной связи по току. |
| Требования: Предложить способы устранения помех. |
| Пример решения: Использовать экранированный кабель для датчика, заземлить |
| экран только со стороны ПЛК, разделить силовые и сигнальные трассы, установить |
| ферритовые кольца. |
| Правильный ответ: Применить экранирование, заземление, фильтры. |
| Задача 1.9 |
| Условие: В паспорте мехатронной станции указано, что наладка пневматической |
| системы должна проводиться при давлении 6±0,5 бар. Манометр на входе |
| показывает 5,8 бар. |
| Требования: Определить, допускается ли работа, и что сделать. |
| --- |
| Пример решения: Значение 5,8 бар входит в допуск (5,5…6,5 бар). Работа допустима, |
| но желательно отрегулировать редуктор до 6 бар. |
| Правильный ответ: Допускается, но рекомендуется поднять давление до 6 бар для |
| оптимальной работы. |
| Задача 1.10 |
| Условие: После замены датчика давления на аналогичный показания ПЛК стали ниже |

| 0 (неудовлетворительно) | Задание не выполнено или выполнено с грубыми нарушениями: более 70% требований не выполнены, результат отсутствует или неверен, логика непонятна, |

программа не компилируется или содержит критические ошибки. Нарушены правила техники безопасности, что может привести к повреждению оборудования или травме. Дополнительные пояснения: При оценке практических заданий по монтажу и наладке обязательно учитывается правильность использования измерительного инструмента, соблюдение последовательности операций, наличие протокола проверки. При оценке задач по программированию проверяется синтаксическая корректность, соответствие стандарту IEC 61131-3, эффективность алгоритма (отсутствие «мертвого кода», правильное использование таймеров/счетчиков). По решению экзаменационной комиссии «0» баллов также ставится в случае, если студент не приступал к выполнению задания или использовал запрещенные источники (шпаргалки, смартфон и др.).
