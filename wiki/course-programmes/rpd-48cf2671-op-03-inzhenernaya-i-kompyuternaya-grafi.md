Практические задания для зачета:

| Задание 1. Модель вала привода колеса робота |
| --- |
| Условие: Построить трёхмерную модель вала ступенчатой формы для колёсного |
| робота. Длина вала 80 мм, диаметры ступеней: 10, 12, 10 мм. На конце – лыска длиной |
| 15 мм, глубина 1 мм. Материал – Сталь 45. |
| Требования к выполнению: |
| 1) Создать деталь в Компас-3D. |
| 2) Использовать операцию «Выдавливание» или «Вращение» (для ступенчатого |
| вала предпочтительнее вращение с вырезанием паза). |
| 3) Назначить материал и получить массу. |
| 4) Сохранить модель с именем «Вал_привода_робот». |
| Критерии оценки: |
| Отлично – модель полностью соответствует размерам, есть все элементы |
| (ступени, лыска), материал задан, масса рассчитана, эскизы полностью определены. |
| Хорошо – модель верна, но эскизы имеют незначительные избыточные |
| размеры, или не назначен материал. |
| Удовлетворительно – модель построена, но есть ошибки в размерах (до 2 мм) |
| или отсутствует один из элементов (лыска). |
| Неудовлетворительно – допущены грубые ошибки в размерах или форме; |
| задание не выполнено. |
| Задание 2. Кронштейн крепления датчика |
| Условие: Создать модель Г-образного кронштейна из листа 4 мм (сталь). |
| Размеры: полка 40х50 мм и 30х40 мм. Два отверстия Ø5 мм на каждой полке для |
| крепления. Сопряжение полок – скругление R3. |
| Требования: |
| 1) Построить выдавливанием из эскиза. |
| 2) Отверстия выполнить операцией «Вырезать выдавливанием». |
| 3) Добавить скругления. |
| Критерии: |
| Отлично – точные размеры, все отверстия на своих местах, скругления |
| выполнены, эскизы ортогональны. |
| Хорошо – мелкие неточности в позиционировании отверстий (±0,5 мм). |
| Удовлетворительно – неверная толщина кронштейна или отсутствует |
| скругление. |
| Неудовлетворительно – допущены грубые ошибки в размерах или форме; |
| задание не выполнено. |
| Задание 3. Корпус редуктора (упрощённый) |

| Условие: Модель корпуса размерами 60x40x30 мм (параллелепипед). Внутри |
| полость 40x20x20 мм. Два прилива под подшипники – цилиндры Ø20 мм высотой 5 мм |
| на внешней стороне. Четыре отверстия Ø4 мм для крепления крышки. |
| Требования: |
| 1) Применить операцию «Выдавливание» с добавлением и вырезанием. |
| 2) Использовать массив отверстий. |
| 3) Материал – Алюминий. |
| Критерии: |
| Отлично – форма и полость соответствуют, приливы и отверстия выполнены, |
| материал задан. |
| Хорошо – нет массива (отверстия вручную, но симметрично). |
| Удовлетворительно – один из приливов не на месте или неправильный размер. |
| Неудовлетворительно – допущены грубые ошибки в размерах или форме; |
| задание не выполнено. |

| Условие: Модель шестерни: модуль m=2 мм, число зубьев z=20, ширина венца |
| 15 мм, диаметр отверстия 10 мм, шпоночный паз 4x4 мм. Построить 3D-модель. |
| Требования: |
| 1) Использовать библиотеку «Валы и механические передачи» → «Зубчатые |

| 3) Назначить материал – Сталь 40Х. |
| Критерии: |
| Отлично – шестерня построена с помощью библиотеки, все параметры верны, |
| паз на месте. |
| Хорошо – зубья построены массивом, но один параметр не совпадает |
| (например, угол паза). |
| Удовлетворительно – шестерня без паза или с грубой формой зуба. |
| Неудовлетворительно – допущены грубые ошибки в размерах или форме; |
| задание не выполнено. |

| Условие: Модель пружины сжатия: диаметр проволоки 2 мм, наружный |

| мм. |

| Удовлетворительно – пружина спиралью без учёта шага. |
| Неудовлетворительно – допущены грубые ошибки в размерах или форме; |

| 3) Проставить габаритные и координатные размеры. |
| Критерии: |
| Отлично – все виды выполнены по ГОСТ, размеры полные, нет лишних цепочек. |
| Хорошо – отсутствует один размер или вид. |
| Удовлетворительно – неверный масштаб или грубые нарушения линий. |
| Неудовлетворительно – допущены грубые ошибки в размерах или форме; |

| Хорошо – один элемент из библиотеки нестандартный, но узнаваемый. |
| Удовлетворительно – нет обозначений или перечня элементов. |

| Удовлетворительно – грубая компоновка, много пропусков. |
