| 3.3. Практические задания, применяемые на экзамене |
| Задача 1 (по теме ПР №1 «Расчёт параметров пневматической системы») |
| Условие. Роботизированная ячейка использует пневмоцилиндр двустороннего |
| действия с диаметром поршня 40 мм. Давление в магистрали 0,6 МПа. Определить |
| усилие, развиваемое на штоке при выдвижении (со стороны поршневой полости). |
| КПД цилиндра принять 0,9. |
| Требования. Написать формулу, подставить значения, вычислить силу в ньютонах. |
| Пример решения. |
| Площадь поршня S = π * d² / 4 = 3,14 * (0,04 м)² / 4 = 0,001256 м². |
| Сила теоретическая Fт = p * S = 0,6e6 Па * 0,001256 м² = 753,6 Н. |
| С учётом КПД F = Fт * 0,9 = 678,2 Н. |
| Правильный ответ: ≈ 678 Н. |
| Задача 2 (ПР №1) |
| Условие. Цилиндр захвата имеет диаметр 25 мм, давление 0,5 МПа. Какое |
| усилие зажима создаётся на одной губке, если рычажный механизм усиливает силу в |
| 2 раза? |
| Решение. S = π*0,025²/4 = 0,000491 м², Fт = 0,5e6*0,000491 = 245,5 Н, с учётом рычага |
| Fзахв = 245,5*2 = 491 Н. |
| Ответ: 491 Н. |
| Задача 3 (ПР №2 «Расчёт параметров сжатия воздуха») |
| Условие. В ресивере объёмом 50 л давление сжатого воздуха равно 0,8 МПа |
| (изб.). Температура 20°С. Атмосферное давление 0,1 МПа. Определить объём |
| атмосферного воздуха, который занял бы этот газ (приведённый к атмосферному |
| давлению). |
| Требования. Применить закон Бойля-Мариотта для изотермического процесса. |
| Решение. Абсолютное давление в ресивере p₁ = 0,8+0,1 = 0,9 МПа. V₁ = 50 л. p₂ = 0,1 |
| МПа. V₂ = p₁V₁/p₂ = 0,9*50/0,1 = 450 л. |
| Ответ: 450 л (нормальные литры). |
| Задача 4 (ПР №2) |
| Условие. За цикл работы робот потребляет 10 л сжатого воздуха при давлении |
| 0,6 МПа (изб.). Сколько атмосферного воздуха засасывает компрессор за один цикл? |
| Атм. давление 0,1 МПа. |
| Решение. p₁абс = 0,7 МПа, V₁ = 10 л, p₂ = 0,1 МПа → V₂ = 0,7*10/0,1 = 70 л. |
| Ответ: 70 л. |
| Задача 5 (ПР №3 «Расчёт параметров трубопровода») |
| Условие. Расход воздуха через трубу длиной 10 м, внутренним диаметром 8 мм |
| --- |
| составляет 300 л/мин (при норм. условиях). Определить скорость потока в трубе (при |
| давлении 0,6 МПа изб.). |
| Решение. Привести расход к давлению в трубе: pабс = 0,7 МПа, Qтруба = Qнорм * |
| (pатм/pабс) = 300 * (0,1/0,7) ≈ 42,86 л/мин = 7,14e-4 м³/с. Площадь сечения S = π*d²/4 |
| = π*0,008²/4 = 5,027e-5 м². Скорость v = Q/S = 7,14e-4 / 5,027e-5 ≈ 14,2 м/с. |
| Ответ: ≈ 14,2 м/с. |
| Задача 6 (ПР №3) |
| Условие. Допустимая скорость воздуха в трубопроводе 15 м/с. Расход при |
| норм. условиях 500 л/мин, давление 0,5 МПа (изб.). Каков минимальный внутренний |
