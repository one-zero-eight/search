## 1. Краткая характеристика дисциплины (модуля)

Дисциплина (модуль) «Аналитические и компьютерные модели (углубленный курс)» фокусируется на прикладных аспектах моделирования в высокотехнологичных отраслях: автономных системах, робототехнике и компьютерном зрении. Курс обеспечивает углубленную подготовку для решения задач очистки зашумленных данных (временных рядов, данных сенсоров), создания реалистичных симуляций для обучения агентов и применения вероятностных подходов в навигации. Это напрямую готовит выпускника к трудовым функциям по разработке архитектуры комплексных ML- систем и внедрению ИИ-решений в физический мир.

Примеры кейсов представлены ниже:

**1.** Гибридное агентно-математическое моделирование социально-экологических систем для оценки последствий изменения климата в регионе Описание: Модель должна учитывать как физические процессы (динамика влажности почвы, рост биомассы, описываемые уравнениями в частных производных), так и принятие решений множеством независимых агентов-фермеров (выбор культур, технологий полива на основе экономических стимулов и прогнозов). Цель — оценить долгосрочную устойчивость агроэкосистемы при различных сценариях климата и господдержки. Цель: разработать и программно реализовать гибридную модель, интегрирующую дискретно-событийную агентную платформу (для фермеров) с модулем решения уравнений в частных производных (для биогеофизических процессов). Провести анализ чувствительности и сценарное моделирование для выработки рекомендаций по адаптационной политике.

**2.** Стохастическое дифференциальное уравнение для моделирования динамики распространения инвазивного биологического вида по данным ДЗЗ Описание: Распространение инвазивного растения зависит от детерминированных факторов (пригодность среды, направление ветра для переноса семян - конвекция) и случайных событий (антропогенный занос, локальные погодные аномалии). Наблюдаемые данные - ежегодные карты распространения, полученные по спутниковым снимкам. Цель: построить модель в виде стохастического дифференциального уравнения в частных производных (типа уравнения диффузии-конвекции с аддитивным или мультипликативным шумом). Провести калибровку параметров модели (коэффициенты диффузии, сноса, интенсивность шума) на исторических данных. Реализовать численное решение (метод Монте-Карло для СПДУ) для построения вероятностного прогноза границ ареала с доверительными интервалами.

**3.** Многоуровневое моделирование (multiscale modeling) наноразмерных процессов в микроэлектронике Описание: для проектирования надежных микрочипов необходимо предсказать явление электромиграции - миграции атомов проводника под действием тока, ведущей к образованию пустот и обрыву соединений. Атомарные процессы описываются стохастически (молекулярная динамика), а макроскопическое повреждение - детерминированными уравнениями переноса. Цель: разработать концептуальную схему многоуровневого моделирования: 1) Атомистический уровень (уравнения Ньютона со случайными силами) для определения коэффициентов миграции. 2) Мезоскопический уровень (уравнение Фоккера-Планка) для описания эволюции плотности атомов. 3) Макроуровень (уравнение непрерывности с источником) для прогноза деградации всего проводника. Проанализировать методы сопряжения моделей разных масштабов.

**4.** Верификация и валидация (V&V) комплексной имитационной модели транспортного потока в мегаполисе Описание: Создана детальная агентная модель транспортной сети города, включающая поведение водителей, работу светофоров, инциденты. Прежде чем использовать модель для принятия решений (например, об изменении схемы движения), необходимо доказать её соответствие реальности. Цель: разработать и применить всесторонний план V&V: Верификация - проверка корректности реализации (анализ кода, тестирование модулей, проверка законов сохранения). Валидация - сравнение выходных данных модели с реальными наблюдениями (трафик-счетчики, GPS-треки) на качественном (форма графика загруженности) и количественном (сравнение гистограмм скоростей, метрика KS-теста) уровнях. Определить границы применимости модели.

Критерии оценивания сформированности компетенций Оценивание уровня учебных достижений, обучающихся по дисциплине (модулю), осуществляется в виде текущего контроля успеваемости и промежуточной аттестации. В рамках внутренней системы оценки качества образовательной деятельности по программе обучающимся предоставляется возможность оценивания условий, содержания, организации и качества образовательного процесса по данной дисциплине (модулю). Промежуточная аттестация по дисциплине (модулю) осуществляется в форме экзамена, при этом проводится оценка компетенций, сформированных по дисциплине. Система оценивания результатов обучения по дисциплине (модулю) Знания, умения и навыки обучающихся при промежуточной аттестации определяются в следующей форме: «отлично» (A), «хорошо» (B), «удовлетворительно» (C), «неудовлетворительно» (D).
