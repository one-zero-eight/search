## 1. Краткая характеристика дисциплины (модуля)

Дисциплина (модуль) «Big Data Technologies and Analytics / Технологии и анализ больших данных» посвящена изучению методов и инструментов для хранения, обработки и анализа сверхбольших объемов данных (Big Data), которые невозможно эффективно обработать на одном узле. Курс ориентирован на формирование инженерных компетенций в области построения масштабируемых пайплайнов данных (Data Engineering) и распределенных вычислений. В ходе освоения дисциплины обучающиеся изучают экосистему Apache Hadoop (HDFS, YARN, MapReduce) как фундамент распределенных систем, и переходят к современному стандарту обработки данных - Apache Spark. Рассматриваются различные модули Spark: Core (RDD), SQL (DataFrames), Streaming (структурированный стриминг) и MLlib (распределенное машинное обучение). Особое внимание уделяется архитектурным паттернам (Lambda и Kappa архитектуры), технологиям потоковой обработки событий (Apache Kafka) и NoSQL-хранилищам (Cassandra, HBase), обеспечивающим высокую доступность и горизонтальную масштабируемость. Курс носит ярко выраженный прикладной характер: студенты разворачивают кластеры, оптимизируют производительность Spark-джоб и решают задачи аналитики на реальных датасетах. Требования к «входным» знаниям, умениям и навыкам: Изучение дисциплины базируется на компетенциях, сформированных в ходе освоения следующих дисциплин: «Introduction to Programming / Введение в программирование» - уверенное владение Python (или Java/Scala) необходимо для написания Spark-приложений; «Databases / Проектирование баз данных» - знание SQL, теории реляционных баз данных и индексирования критически важно для работы с Hive и Spark SQL; «Operating Systems and Networks» - понимание принципов работы файловых систем, сетевого взаимодействия и командной строки Linux (Bash) необходимо для управления кластером Hadoop; «Data Wrangling and Visualization / Обработка и визуализация данных» - навыки очистки данных (ETL) на малых объемах (Pandas) являются концептуальной основой для перехода к Big Data. Дисциплины, для которых данная дисциплина является предшествующей: Компетенции, полученные в ходе освоения дисциплины, используются при: «Practicum Project / Прикладной проект» - для реализации проектов, требующих обработки больших массивов данных или построения рекомендательных систем; «Производственной практике (преддипломной)» - многие индустриальные партнеры требуют навыков работы с Hadoop/Spark; Выполнении выпускной квалификационной работы - при проведении экспериментов на больших датасетах.

Целью освоения дисциплины (модуля) является формирование у обучающихся профессиональных компетенций в области проектирования и реализации масштабируемых систем обработки данных (Data Engineering), освоение технологий распределенных вычислений (Apache Spark) и принципов построения архитектур больших данных (Big Data Architectures) для решения задач аналитики и машинного обучения. Задачами дисциплины являются: изучение экосистемы Apache Hadoop и принципов хранения данных в распределенных файловых системах (HDFS); освоение фреймворка Apache Spark (PySpark) для пакетной (Batch) и потоковой (Streaming) обработки данных; формирование навыков построения ETL-пайплайнов, интегрирующих различные источники данных (SQL, NoSQL, Kafka); изучение методов оптимизации производительности распределенных вычислений. Пишет аналитические запросы к данным и анализирует план запроса, умеет создавать представления, хранимые процедуры, функции и триггеры; базы данных в хранилищах Ключ-Значение, Документные, Колоночные и Графовые; знает и умеет использовать основные команды для работы с данными в таких хранилищах; работает на уровне применения наиболее известных подходов и технологий каждого класса хранилищ. Знания: сформированы систематические знания об архитектуре экосистемы Apache Hadoop (HDFS, YARN) и парадигме MapReduce; внутреннем устройстве Apache Spark (Driver, Executors, DAG, Lazy Evaluation); современных форматах хранения больших данных (Parquet, ORC, Avro); теоретических ограничениях распределенных систем (CAP- теорема, ACID vs BASE); архитектурных паттернах построения хранилищ данных (Data Lake, Lambda/Kappa Architecture). Умения: сформированы умения разрабатывать масштабируемые приложения для пакетной (Batch) и потоковой (Streaming) обработки данных с использованием Apache Spark (PySpark/Scala); проектировать эффективные ETL-конвейеры для очистки и трансформации данных; оптимизировать производительность распределенных вычислений (управление памятью, партиционирование, минимизация Shuffle- операций); выбирать соответствующие NoSQL-решения (Cassandra, HBase, MongoDB) под требования бизнес-задачи. Навыки (владения): сформировано владение инструментами командной строки для работы с распределенными файловыми системами (HDFS CLI); навыками профилирования и отладки Spark-приложений (Spark UI, History Server); методами интеграции брокеров сообщений (Apache Kafka) в аналитические пайплайны; навыками написания и оптимизации запросов Spark SQL для анализа структурированных больших данных.
