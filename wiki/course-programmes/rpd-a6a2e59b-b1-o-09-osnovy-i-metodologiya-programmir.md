## 1. Краткая характеристика дисциплины (модуля)

Изучение дисциплины (модуля) «Основы и методология программирования» обеспечивает формирование и развитие компетенций обучающихся в области алгоритмического мышления, разработки программного обеспечения, работы с различными языками программирования, их применение для решения различных прикладных задач в рамках профессиональной деятельности. Для успешного продолжения изучения дисциплины «Основы и методология программирования» во втором семестре обучающимся необходимо обладать знаниями, умениями и навыками: пониманием основных концепций программирования, включая принципы объектно-ориентированного программирования, умением работать с языками Python и C++, включая создание и отладку классов и объектов, знанием алгоритмов и структур данных, таких как массивы, списки, деревья и графы, а также умением оценивать сложность алгоритмов и производительность программ, навыками работы с библиотеками и фреймворками, такими как NumPy, Pandas и Matplotlib, основами многопоточности и параллельных алгоритмов, а также умением оптимизировать код на C++, что позволит эффективно усваивать более сложные темы курса.

**1.** Разработка чат-бота для поддержки пользователей Описание: Студенты разрабатывают чат-бота, который отвечает на часто задаваемые вопросы пользователей. Цели: изучить основы работы с библиотеками Python, применить методы обработки естественного языка и научиться разрабатывать простые приложения на Python.

**2.** Создание системы рекомендаций на основе машинного обучения Описание: Студенты разрабатывают систему рекомендаций для онлайн- магазина, используя Python и библиотеки для машинного обучения (например, Scikit- learn). Они анализируют данные о покупках пользователей и создают алгоритмы, которые будут предлагать товары на основе их предпочтений. Цели: понять основные принципы работы с данными, изучить методы машинного обучения и разработать практическое приложение для решения реальной задачи.

**3.** Моделирование игры с использованием C++ Описание: Студенты создают простую игру (например, «Крестики-нолики» или «Змейка») на языке C++. В процессе разработки они изучают основы объектно- ориентированного программирования, управление состояниями игры и взаимодействие с пользователем. Цели: освоить основы программирования на C++, применять принципы ООП и развивать навыки разработки игр. Примеры задач представлены ниже:

**1.** Разработка консольной или десктопной программы (MVP) для экспресс- экономического расчёта Описание: Студенты создают простую программу для выполнения базовых финансовых расчетов, таких как вычисление прибыли, рентабельности, налогов и кредитов. В процессе разработки они изучают основы программирования, работу с пользовательским вводом и структурирование кода. Цель: освоить основы программирования, применять принципы разработки программного обеспечения и развивать навыки работы с финансовыми расчетами.

**2.** Разработка алгоритмов, инструментов машинного обучения и парсинга данных для формирования базы данных и отчетов ГРП Описание: Студенты разрабатывают алгоритмы для анализа и обработки больших объемов данных, создают инструменты машинного обучения для прогнозирования и классификации, а также парсят данные из различных источников для формирования отчетов. Цель: изучить основы машинного обучения, научиться работать с данными и развивать навыки в области аналитики и программирования.

**3.** Разработка лингвистических Веб-Сервисов Описание: Студенты создают веб-сервисы для обработки текстовой информации, такие как анализатор текстов, генератор словарей или переводчик. В процессе работы они изучают основы веб-разработки и обработки естественного языка. Цель: освоить технологии веб-разработки, применить методы обработки естественного языка и развивать навыки создания веб-сервисов.

**4.** Разработка веб-приложения для парсинга вакансий и резюме Описание: Студенты разрабатывают приложение, которое автоматически собирает данные о вакансиях и резюме с различных платформ, анализирует их и предоставляет пользователям удобный интерфейс для поиска и фильтрации. Цель: изучить основы веб-разработки, парсинга данных и взаимодействия с API, а также развивать навыки работы с пользовательскими интерфейсами.

**5.** Разработка инструмента для автоматизированного анализа логов полета Описание: Студенты создают инструмент для анализа логов полета самолетов, который позволяет выявлять аномалии, генерировать отчеты и визуализировать данные. В процессе разработки они изучают методы анализа данных и визуализации информации. Цель: освоить методы обработки и анализа данных, развивать навыки в области создания аналитических инструментов и визуализации данных.

В рамках внутренней системы оценки качества образовательной деятельности по программе обучающимся предоставляется возможность оценивания условий, содержания, организации и качества образовательного процесса по данной дисциплине (модулю). Промежуточная аттестация по дисциплине (модулю) осуществляется в форме экзамена, при этом проводится оценка компетенций, сформированных по дисциплине. Система оценивания результатов обучения по дисциплине (модулю) Знания, умения и навыки обучающихся при промежуточной аттестации определяются в следующей форме: «отлично» (A), «хорошо» (B), «удовлетворительно» (C), «неудовлетворительно» (D). Критерии оценивания результатов обучения по дисциплине (модулю)

| Результат обучения по дисциплине (модулю) | Общая характеристика результата обучения по дисциплине (модулю) |
| --- | --- |
| A «Отлично» | Обучающийся владеет знаниями предмета в полном объеме рабочей программы, достаточно глубоко осмысливает дисциплину; самостоятельно, в логической последовательности и исчерпывающе отвечает на все вопросы, подчеркивая при этом самое существенное, умеет анализировать, сравнивать, классифицировать, обобщать, конкретизировать и систематизировать изученный материал, выделять в нем главное: устанавливать причинно-следственные связи; четко формирует ответы, свободно читает результаты анализов и других исследований и решает ситуационные задачи повышенной сложности; хорошо знаком с основной литературой и методами исследования большого объема, необходимым для практической деятельности; увязывает теоретические аспекты предмета с задачами практического значения. |
| B «Хорошо» | Обучающийся владеет знаниями предмета практически в полном объеме рабочей программы; самостоятельно, в логической последовательности и исчерпывающе отвечает на все вопросы, подчеркивая при этом самое существенное, умеет анализировать, сравнивать, классифицировать, обобщать, конкретизировать и систематизировать изученный материал, выделять в нем главное: устанавливать причинно-следственные связи; четко формирует ответы, свободно читает результаты анализов и других исследований и решает ситуационные задачи повышенной сложности; хорошо знаком с основной литературой и методами исследования большого объема, необходимым для практической деятельности; увязывает теоретические аспекты предмета с задачами практического значения. |
| C «Удовлетворительно» | Обучающийся владеет основным объемом знаний по дисциплине; проявляет затруднения в самостоятельных ответах, оперирует неточными формулировками; в процессе ответов допускаются ошибки по существу вопросов. Студент способен решать лишь наиболее легкие задачи, владеет только обязательным минимумом методов исследований. |
| D «Неудовлетворительно» | Обучающийся не освоил обязательного минимума знаний предмета, не способен ответить на вопросы даже при дополнительных наводящих вопросах преподавателя. |
