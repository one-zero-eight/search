## 1. Краткая характеристика дисциплины (модуля)

Дисциплина (модуль) «Методы обработки и генерации текста и речи» является ключевым компонентом подготовки специалистов по программе AI360, формирующим профессиональные навыки для ролей NLP-инженера (Natural Language Processing Engineer), Исследователя генеративного ИИ и Разработчика мультимодальных систем. Курс направлен на развитие комплекса компетенций: ОПК-3, ПК-4, ПК-6, ПК-7 и ПК-8. В рамках ПК-4, ПК-7 и ПК-8 студенты овладевают методами разработки и адаптации (fine- tuning) современных архитектур глубоких нейронных сетей (Трансформеры, BERT, GPT, LLaMa) для задач анализа и генерации текста, создания мультимодальных моделей (text-to-speech, text-to-image) и проведения передовых исследований в области больших языковых моделей (LLM). Компетенции ПК-6 и ОПК-3 обеспечивают способность формализовывать бизнес-задачи, проектировать архитектуру NLP- сервисов, проводить эксперименты с оценкой качества (метрики перплексии, BLEU, ROUGE) и использовать профессиональные библиографические ресурсы для анализа SOTA-решений. Содержание дисциплины последовательно раскрывает эволюцию методов обработки естественного языка. Первый блок посвящен классическим подходам: предобработке текста (токенизация BPE, лемматизация), N-граммным языковым моделям, синтаксическому анализу (деревья зависимостей) и дистрибутивной семантике (word2vec, GloVe, fasttext). Второй блок фокусируется на методах глубокого обучения: архитектурах RNN, LSTM, механизмах внимания (Attention) и трансформерах. Третий блок детально рассматривает большие языковые модели (LLM): методы их эффективного дообучения (LoRA), техники промпт-инжиниринга (Chain-of-Thought) и применение для прикладных задач (машинный перевод, суммаризация, вопросно- ответные системы). Отдельное внимание уделяется этическим аспектам и проблемам галлюцинаций в генеративных моделях. Для успешного изучения дисциплины обучающимся необходимо: владеть методами машинного обучения и глубокого обучения (нейронные сети, оптимизация); знать основы теории вероятностей и математической статистики; иметь уверенные навыки программирования на Python и опыт работы с библиотеками глубокого обучения (PyTorch) для реализации NLP-пайплайнов.

Примеры кейсов представлены ниже:

**1.** Создание ассистента для автоматического анализа и ответа на частые вопросы (FAQ) в чате поддержки с использованием RAG Описание: Клиенты задают однотипные вопросы о тарифах, работе карт, отделениях. Требуется создать ассистент, который по вопросу клиента находит наиболее релевантный ответ в базе знаний (документация, FAQ) и формулирует его в естественной форме. Прямое использование LLM может приводить к галлюцинациям, поэтому необходим точный поиск по знаниям. Цель: реализовать архитектуру RAG (Retrieval-Augmented Generation): создать семантический поисковик по базе документов (на основе векторных эмбеддингов модели типа BERT) и модуль-генератор (на основе дообученной LLM, например, ruGPT- 3), формирующий ответ на основе найденных релевантных фрагментов.

**2.** Генерация персонализированных описаний товаров для маркетплейса на основе их характеристик Описание: для миллионов товаров в каталоге продавцы загружают скудные описания или вовсе их не заполняют, что ухудшает поиск и конверсию. Необходимо автоматически генерировать качественные, уникальные и SEO-оптимизированные текстовые описания на основе структурированных данных: название, категория, бренд, атрибуты (цвет, размер, материал). Цель: обучить тексто-генеративную модель (например, на архитектуре T5 или GPT) для задачи conditional text generation. Модель должна на вход принимать структурированные данные о товаре и генерировать на выходе связный, убедительный и уникальный текст описания. Оценить качество по метрикам BLEU, ROUGE, а также с помощью экспертной оценки релевантности и грамотности.

**3.** Построение системы распознавания именованных сущностей (NER) для извлечения ключевой информации из новостных статей Описание: Дан корпус новостных текстов. Требуется автоматически находить и классифицировать упоминания именованных сущностей: персоны (PER), организации (ORG), географические объекты (LOC), даты, денежные суммы. Это базовый этап для построения информационно-поисковых систем и анализа тональности. Цель: обучить модель для NER на основе предобученной языковой модели (например, BERT) с использованием архитектуры «токенизация -> BERT -> Linear Classification Head». Использовать схему разметки BIO/BIOES. Оценить качество модели по метрикам precision, recall, F1-score для каждого типа сущностей на тестовом наборе данных (например, Collection3).

**4.** Разработка системы автоматического распознавания эмоциональной окраски (тональности) в пользовательских отзывах Описание: имеется датасет текстовых отзывов (например, с сайта отзовиков или маркетплейса) с размеченной тональностью: положительный, отрицательный, нейтральный. Необходимо создать модель, которая автоматически определяет тональность нового отзыва для агрегации рейтингов и выявления проблем. Цель: обучить классификатор тональности, сравнив несколько подходов: 1) классический ML (TF-IDF + Logistic Regression/SVM), 2) нейросетевые модели (CNN/LSTM на эмбеддингах слов), 3) fine-tuning предобученной языковой модели (BERT, DistilBERT). Сравнить их точность (accuracy), F1-score и скорость работы.

В ходе практических занятий студенты работают в группах для обсуждения предлагаемых вопросов. |
| Самостоятельная работа | Самостоятельная работа состоит из следующих частей: 1) чтение учебной, справочной, научной литературы; 2) повторение материала лекций; 3) составление планов устных выступлений; 4) подготовка видеопрезентации. При чтении учебной литературы нужно разграничивать для себя материал на отдельные проблемы, концепции, идеи. Учебную литературу можно найти в электронных библиотечных системах, на которые подписан АНО Университет Иннополис. |
| Видеопрезентация | Подготовка видеопрезентаций по курсу. Видеопрезентации могут быть сделаны на любую тему, затронутую в ходе курса. Темы должны быть заранее согласованы с преподавателем. Видеопрезентации продолжительностью около 5 минут (300 секунд) должны быть подготовлены в группах, определяемых преподавателем. Несмотря на то, что это групповая работа, должен явно присутствовать вклад каждого члена группы. |
| --- | --- |
| Доклад | Публичное, развернутое сообщение по определенной теме или вопросу, основанное на документальных данных. При подготовке доклада рекомендуется использовать разнообразные источники, позволяющие глубже разобраться в теме. Учебную литературу можно найти в электронных библиотечных системах, на которые подписан АНО Университет Иннополис. |
| Дискуссия | Публичное обсуждение спорного вопроса, проблемы. Каждая сторона должна оппонировать мнение собеседника, аргументируя свою позицию. |
| Контрольная работа | При подготовке к контрольной работе необходимо проработать материалы лекций, семинаров, основной и дополнительной литературы по заданной теме. |
| Тестирование (устное/письменное) | При подготовке к тестированию необходимо проработать материалы лекций, семинаров, основной и дополнительной литературы по заданной теме. Основная цель тестирования – показать уровень сформированности знаний по конкретной теме или ее части. |
| Индивидуальная работа | При выполнение индивидуальной работы необходимо взять задание у преподавателя, ознакомиться с требованиями к выполнению работы, изучить поставленную проблему, найти решение проблемы. Если самостоятельно не удается разобраться в материале, необходимо сформулировать вопрос и задать преподавателю на консультации, во время семинарского (практического) занятия. Оформить результаты работы. |
| Разработка отдельных частей кода | Разработать часть кода, исходя из поставленной задачи и рекомендаций преподавателя. При выполнении работы рекомендуется обращаться к материалам лекций и семинарских (практических) занятий. Если возникают затруднения, необходимо проконсультироваться с преподавателем. |
| Выполнение домашних заданий и групповых проектов | Для выполнения домашних заданий и групповых проектов необходимо получить формулировку задания от преподавателя и убедиться в понимании задания. При выполнение домашних заданий и групповых проектов необходимо проработать материалы лекций, основной и дополнительной литературы по заданной теме. |

Для подготовки к занятиям рекомендуется использовать представленные источники в электронных форматах и дополнительную литературу.
