## 1. Краткая характеристика дисциплины (модуля)

Изучение дисциплины (модуля) «Introduction to Robot Operating System / Введение в операционную систему для роботов» обеспечивает формирование и развитие компетенций обучающихся в области робототехники, их применение для решения различных прикладных задач в рамках профессиональной деятельности. В ходе освоения дисциплины обучающиеся рассматривают установку Linux и ROS, учатся решать задачи планирования маршрутов в грид-мире, а также генерировать пути и реализовывать алгоритмы следования для мобильных роботов. Кроме того, обучающиеся изучают методы прослеживания пути с использованием геометрических алгоритмов и модельно-предсказуемого управления (MPC), а также траектории движения по кадру Френе с обходом препятствий.

## 2. Перечень планируемых результатов обучения

Целью освоения дисциплины (модуля) является формирование знаний, умений и навыков в рамках профессиональной деятельности, позволяющих успешно работать в избранной отрасли, а также обладать компетенциями, способствующими социальной мобильности, устойчивости и конкурентоспособности обучающегося в условиях современных рыночных отношений. Задачи изучения дисциплины заключаются в освоении установки и основ работы с Linux и ROS, разработке и решении задач планирования маршрутов в грид-мира, генерации путей с использованием путевых точек и реализации алгоритмов следования для мобильных роботов, а также в изучении методов прослеживания пути с применением геометрических алгоритмов и модельно- предсказуемого управления (MPC), включая навигацию по траектории движения с обходом препятствий. **52.** Какой из следующих аспектов кадра Френе позволяет лучше управлять движением робота в сложной среде? A) Использование только линейных моделей движения. B) Учет динамики системы при расчете нормальных и бинормальных компонентов. C) Применение статических координат для описания движения. D) Игнорирование влияния внешних сил на движение. Правильный ответ: B) Учет динамики системы при расчете нормальных и бинормальных компонентов.

**53.** Какой из следующих методов обхода препятствий наиболее эффективно использует информацию о траектории для планирования пути? A) Алгоритм A* без учета динамики робота. B) Метод потенциальных полей с использованием градиентного спуска. C) Алгоритм RRT (Rapidly-exploring Random Tree). D) Алгоритм Дейкстры с фиксированной картой. Правильный ответ: B) Метод потенциальных полей с использованием градиентного спуска.

**54.** Какой из следующих подходов может привести к проблемам с локальными минимумами при обходе препятствий? A) Использование метода RRT с адаптивной дискретизацией. B) Применение метода потенциальных полей без учета динамики. C) Интеграция методов машинного обучения для адаптации к окружающей среде. D) Использование алгоритма A* с эвристикой, основанной на расстоянии до цели. Правильный ответ: B) Применение метода потенциальных полей без учета динамики.

**55.** Какой из следующих методов обеспечивает более плавное движение при обходе препятствий? A) Линейная интерполяция между точками пути. B) Метод сплайнового интерполирования (например, кубические сплайны). C) Применение жадного алгоритма для нахождения кратчайшего пути. D) Использование алгоритма Дейкстры с жесткими ограничениями на повороты. Правильный ответ: B) Метод сплайнового интерполирования (например, кубические сплайны).

**56.** Какой из следующих факторов следует учитывать при выборе метода обхода препятствий? A) Только геометрические характеристики препятствий. B) Динамику робота и скорость его движения. C) Наличие статической карты окружения без изменений. D) Все вышеперечисленные факторы не имеют значения. Правильный ответ: B) Динамику робота и скорость его движения.

**57.** Какое из следующих утверждений верно относительно интеграции навигационных решений с френетической траекторией? A) Френетическая траектория игнорирует ограничения навигации. B) Интеграция позволяет учитывать динамические изменения в окружении при планировании пути. C) Навигационные решения всегда приводят к прямолинейным траекториям. D) Френетическая траектория не может быть использована для динамических роботов. Правильный ответ: B) Интеграция позволяет учитывать динамические изменения в окружении при планировании пути.

**58.** Какой из следующих методов обычно используется для преобразования глобальных навигационных решений в локальные френетические траектории? A) Алгоритм A* без учета препятствий. B) Метод линейной интерполяции между ключевыми точками. C) Метод обратной связи с учетом текущего положения и ориентации робота. D) Статический анализ карты окружения без обновлений. Правильный ответ: C) Метод обратной связи с учетом текущего положения и ориентации робота.

**59.** Какой из следующих аспектов является критически важным для успешной интеграции френетических траекторий в систему навигации? A) Сложность реализации алгоритма обхода препятствий. B) Способность системы адаптироваться к изменяющимся условиям окружающей среды. C) Наличие статической карты без изменений в реальном времени. D) Отсутствие необходимости в вычислительных ресурсах для обработки данных. Правильный ответ: B) Способность системы адаптироваться к изменяющимся условиям окружающей среды.

**60.** Какой параметр наиболее важен для оценки качества френетической траектории в контексте навигации? A) Длина траектории по сравнению с прямым расстоянием до цели. B) Угловые изменения касательной вдоль траектории. C) Общее время выполнения навигационного решения. D) Наличие статических препятствий на пути следования. Правильный ответ: B) Угловые изменения касательной вдоль траектории. Критерии оценивания сформированности компетенций Оценивание уровня учебных достижений, обучающихся по дисциплине (модулю), осуществляется в виде текущего контроля успеваемости и промежуточной аттестации. В рамках внутренней системы оценки качества образовательной деятельности по программе обучающимся предоставляется возможность оценивания условий, содержания, организации и качества образовательного процесса по данной дисциплине (модулю). Промежуточная аттестация по дисциплине (модулю) осуществляется в форме экзамена, при этом проводится оценка компетенций, сформированных по дисциплине. Система оценивания результатов обучения по дисциплине (модулю) Знания, умения и навыки обучающихся при промежуточной аттестации определяются в следующей форме: «отлично» (A), «хорошо» (B), «удовлетворительно» (C), «неудовлетворительно» (D). Критерии оценивания результатов обучения по дисциплине (модулю)

| Результат обучения по дисциплине (модулю) | Общая характеристика результата обучения по дисциплине (модулю) |
| --- | --- |
| A «Отлично» | Обучающийся владеет знаниями предмета в полном объеме рабочей программы, достаточно глубоко осмысливает дисциплину; самостоятельно, в логической последовательности и исчерпывающе отвечает на все вопросы, подчеркивая при этом самое существенное, умеет анализировать, сравнивать, классифицировать, обобщать, конкретизировать и систематизировать изученный материал, выделять в нем главное: устанавливать причинно-следственные связи; четко формирует ответы, свободно читает результаты анализов и других исследований и решает ситуационные задачи повышенной сложности; хорошо знаком с основной литературой и методами исследования большого объема, необходимым для практической деятельности; увязывает теоретические аспекты предмета с задачами практического значения. |
| B «Хорошо» | Обучающийся владеет знаниями предмета практически в полном объеме рабочей программы; самостоятельно, в логической последовательности и исчерпывающе отвечает на все вопросы, подчеркивая при этом самое существенное, умеет анализировать, сравнивать, классифицировать, обобщать, конкретизировать и систематизировать изученный материал, выделять в нем главное: устанавливать причинно-следственные связи; четко формирует ответы, свободно читает результаты анализов и других исследований и решает ситуационные задачи повышенной сложности; хорошо знаком с основной литературой и методами исследования большого объема, необходимым для практической деятельности; увязывает теоретические аспекты предмета с задачами практического значения. |
| C «Удовлетворительно» | Обучающийся владеет основным объемом знаний по дисциплине; проявляет затруднения в самостоятельных ответах, оперирует неточными формулировками; в процессе ответов допускаются ошибки по существу вопросов. Студент способен решать лишь наиболее легкие задачи, владеет только обязательным минимумом методов исследований. |
| D «Неудовлетворительно» | Обучающийся не освоил обязательного минимума знаний предмета, не способен ответить на вопросы даже при дополнительных наводящих вопросах преподавателя. |
