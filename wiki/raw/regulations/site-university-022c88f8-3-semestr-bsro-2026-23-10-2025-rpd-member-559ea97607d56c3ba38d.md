**1.** КРАТКАЯ ХАРАКТЕРИСТИКА ДИСЦИПЛИНЫ (МОДУЛЯ)

Изучение дисциплины (модуля) «Введение в паттерны проектирования ПО» обеспечивает формирование и развитие компетенций обучающихся в области объектно-ориентированного программирования, их применение для решения различных прикладных задач в рамках профессиональной деятельности. В ходе освоения дисциплины обучающиеся рассматривают основы объектно-ориентированного проектирования ПО, базовые концепции программной инженерии и алгоритмизации.

**2.** ПЕРЕЧЕНЬ ПЛАНИРУЕМЫХ РЕЗУЛЬТАТОВ ОБУЧЕНИЯ

Целью освоения дисциплины (модуля) является формирование знаний, умений и навыков в рамках профессиональной деятельности, позволяющих успешно работать в избранной отрасли, а также обладать компетенциями, способствующими социальной мобильности, устойчивости и конкурентоспособности обучающегося в условиях современных рыночных отношений. Задачами дисциплины являются изучение методов объектно-ориентированного программирования, разработки алгоритмов.

Компетенции, формируемые в результате освоения дисциплины (модуля) при проведении учебных занятий в форме контактной работы обучающихся с педагогическими работниками Университета и в форме самостоятельной работы обучающихся:

Умения: сформированы умения применять новые возможности языка C++ для написания современного кода; создавать и использовать структуры и перечисления для организации данных; разрабатывать функции, классы и объекты, а также эффективно использовать их в своих проектах; реализовывать конструкторы и деструкторы для управления жизненным циклом объектов; перегружать операторы для создания удобных интерфейсов классов; использовать наследование для создания расширяемых и поддерживаемых программных решений; работать с виртуальными функциями для реализации полиморфизма; создавать шаблоны для написания обобщенного кода, который может работать с различными типами данных; обрабатывать исключения для повышения надежности программного обеспечения; применять принципы ООАП при проектировании программных систем.

Навыки (владения): сформировано владение навыками написания чистого, читаемого и поддерживаемого кода на языке C++ с использованием современных стандартов; разработки сложных программных систем с использованием объектно-ориентированных подходов; эффективного применения структур данных, функций и классов в реальных проектах; использования инструментов разработки для отладки и тестирования кода на C++; анализа требований к программному обеспечению и проектирования архитектуры программных систем на основе принципов ООАП.

Данная учебная дисциплина (модуль) включена в «Блок 1. Критерии оценивания сформированности компетенций

Оценивание уровня учебных достижений, обучающихся по дисциплине (модулю), осуществляется в виде текущего контроля успеваемости и промежуточной аттестации.

В рамках внутренней системы оценки качества образовательной деятельности по программе обучающимся предоставляется возможность оценивания условий, содержания, организации и качества образовательного процесса по данной дисциплине (модулю).

Промежуточная аттестация по дисциплине (модулю) осуществляется в форме экзамена, при этом проводится оценка компетенций, сформированных по дисциплине.

Система оценивания результатов обучения по дисциплине (модулю) Знания, умения и навыки обучающихся при промежуточной аттестации определяются в следующей форме: «отлично» (A), «хорошо» (B), «удовлетворительно» (C), «неудовлетворительно» (D).
