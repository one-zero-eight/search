# ioai26 task tour1 ru

Задача 1: Статистика текста

Прежде чем нейросеть научится писать стихи или отвечать на вопросы, ей необходимо понять базовые закономерности языка. Анализ длины слов — первый шаг в подготовке данных для обучения языковых моделей. Эта задача погружает вас в фундаментальные принципы обработки естественного языка (NLP), которые лежат в основе таких систем, как ChatGPT.

Условие задачи

Дан текстовый файл text.txt, содержащий произвольный текст на русском и английском языках. Необходимо:

## 1. Извлечь все слова из текста согласно правилам ниже.

## 2. Рассчитать три статистические метрики для длин извлеченных слов:

- • Среднее арифметическое (с точностью 6 знаков после запятой)

- • Медиану (нижнюю медиану при четном числе элементов)

- • Моду (с разрешением конфликтов в пользу наименьшего значения)

## 3. Сохранить результаты в два файла: - words.txt — список извлеченных слов -

result.txt — вычисленные метрики

## 4. Заархивировать оба файла в task1.zip.

Теоретическая часть

Что такое слово? Слово — непрерывная последовательность буквенных символов, где:

- • Буквенные символы:

o Латинские буквы: a-z, A-Z o Кириллические буквы: а-я, А-Я, включая ё и Ё

- • Разделители: все остальные символы (цифры, знаки препинания, пробелы,

спецсимволы).

Примеры:

- • "Привет, world123! Это-тест." → Привет, world, Это, тест

- • "Hello-world" → Hello, world

- • "abc123def" → abc, def

Статистические метрики

## 1. Среднее арифметическое

Для списка длин слов 𝐿 = [𝑙1,𝑙2,. ..,𝑙𝑛]: 𝑙‾ =

𝑛 ∑𝑙𝑖 𝑛 𝑖=1 Требование: результат выводится с точностью 6 знаков после запятой.

## 2. Медиана

Значение в середине упорядоченного списка. При четном 𝑛 берется нижняя медиана (элемент с индексом (𝑛 − 1)//2 в отсортированном списке). Пример: [2,3,5,8] → 𝑛 = 4, индекс (4 − 1)//2 = 1 → медиана = 3.

## 3. Мода

Наиболее частая длина. При равенстве частот выбирается наименьшее значение.

Пример: [2,3,2,4,3,4] → частоты: 2 → 2, 3 → 2, 4 → 2 → мода = 2.

В реальном мире данные редко бывают идеальными. Как археологи, вычищающие древние артефакты от пыли, дата-сайентисты тратят большую часть времени на очистку “грязных” данных. Пропущенные значения, ошибки датчиков, мусорные символы — всё это мешает анализу. Сегодня вы научитесь превращать хаотичные данные в чистые и пригодные для работы числа. Без этого ни одна модель искусственного интеллекта не сможет дать точный результат!

Что такое CSV?

CSV (Comma-Separated Values) — текстовый формат хранения табличных данных, где значения разделены запятыми. Для этой задачи действуют строгие правила форматирования.

Правила корректной строки CSV:

- • Каждая строка содержит ровно три вещественных числа

- • Числа разделены запятыми без пробелов

- • Все три значения должны быть корректными вещественными числами в

десятичном формате

Примеры корректных строк:

1.5,2.3,4.1

-0.5,10,3.14

0.0,0.0,0.0 Примеры некорректных строк:

1.5, 2.3, 4.1 ← пробелы вокруг запятых

1.5,2.3 ← меньше трёх значений 1e3,2.3,4.1 ← экспоненциальная запись abc,2.3,4.1 ← нечисловое значение 1.5,,4.1 ← пропущенное значение Что такое вещественное число в задаче? Допустимые форматы:

- • Целые числа: 42, -17, 0

- • Дробные числа: 3.14, -0.5, 100.0

- • Числа с нулевой дробной частью: 0.0, -0.0

Запрещено использовать:

- • Экспоненциальную запись (1e3, 2.5e-2)

- • Спецсимволы (inf, NaN, null)

- • Числа с пробелами или другими разделителями

Задача 3: Детектор аномалий во временном ряде

Каждую секунду миллионы датчиков собирают данные о работе критически важных систем: от сердечного ритма пациентов до состояния ядерных реакторов. Раннее обнаружение аномалий позволяет предотвратить катастрофы и спасти жизни. В основе таких систем лежит анализ локального контекста — сравнение текущего значения с характерным поведением системы в ближайшем окружении. Эта задача погружает вас в фундаментальные принципы временных рядов и статистического контроля качества, которые используются в медицине, промышленности и научных исследованиях.

Условие задачи

Дан временной ряд измерений в файле series.txt. Для каждого элемента ряда с индексом 𝑖 (начиная с 0) необходимо определить, является ли он аномалией относительно своего локального окружения.

Аномалией считается точка 𝑥𝑖, если одновременно выполняются условия:

## 1. Для неё можно построить полное скользящее окно размером 11 точек (т.е.

5 ≤ 𝑖 ≤ 𝑁 − 6, где 𝑁 — общее количество точек).

## 2. Её отклонение от локального среднего превышает удвоенное стандартное

отклонение: |𝑥𝑖 − 𝜇𝑖| > 2 ⋅ 𝜎𝑖.

## 3. Стандартное отклонение в окне положительно: 𝜎𝑖 > 0.

Требуется:

## 1. Для всех точек из диапазона [5, 𝑁 − 6] рассчитать 𝜇𝑖 (среднее) и 𝜎𝑖

Косинусная схожесть пользователей

Косинусная схожесть — мера сходства двух векторов, основанная на угле между ними. Для двух пользователей 𝑢 и 𝑣 вычисляется только по общим оценённым товарам 𝐼𝑢𝑣:

Пример вычисления: Для User 0 ([5,0,4,0,0,3]) и User 3 ([5,0,3,0,0,4]):

- • Общие товары: индексы {0,2,5},

- • Векторы оценок по общим товарам: [5,4,3] и [5,3,4],

- • Числитель: 5 ⋅ 5 + 4 ⋅ 3 + 3 ⋅ 4 = 25 + 12 + 12 = 49,

- • Знаменатель: √52 + 42 + 32 ⋅ √52 + 32 + 42 = √50 ⋅ √50 = 50,

- • sim(0,3) = 49/50 = 0.98.

Задача 8: Оптимальная политика в решётке

Обучение с подкреплением формирует основу для создания автономных систем, способных принимать решения в сложных средах. От шахматных программ до систем управления роботами — все они используют принципы оценки состояний и поиска оптимальных стратегий. Алгоритм Value Iteration представляет собой фундаментальный метод динамического программирования, позволяющий агенту заранее оценивать ценность каждого состояния среды. Эта задача погружает вас в суть алгоритмов планирования, которые лежат в основе современных систем искусственного интеллекта.

Условие задачи

Дана прямоугольная сетка размером 𝐻 × 𝑊, где:

- • S — стартовая позиция агента (ровно 1 клетка)

- • T — сокровище (цель, даёт награду +10)

- • X — ловушки (дают штраф −5)

- • . — пустые клетки (штраф −0.1 за шаг)

Агент может выполнять действия в 4 направлениях: вверх, вниз, влево, вправо. При попытке выхода за границы сетки агент остаётся в текущей позиции. Терминальными состояниями являются T и X, из которых дальнейшие переходы невозможны.

## 1. Реализовать алгоритм Value Iteration с коэффициентом дисконтирования 𝛾 =

## 2. Вычислить ценность стартового состояния 𝑉(𝑆) после 100 итераций.

Теоретическая часть

Основные понятия Среда — прямоугольная сетка, где каждая клетка представляет собой состояние. Координатная система: (𝑟𝑜𝑤, 𝑐𝑜𝑙), где 𝑟𝑜𝑤 = 0 соответствует верхней строке, 𝑐𝑜𝑙 = 0

— левому столбцу.

Состояние 𝑠 — текущая позиция агента (𝑟𝑜𝑤,𝑐𝑜𝑙). Действие 𝑎 — выбор направления движения из множества 𝐴 = {Up,Down,Left,Right}. Награда 𝑅(𝑠,𝑎,𝑠′):

- • +10 при переходе в состояние с сокровищем T

- • −5 при переходе в состояние с ловушкой X

- • −0.1 для всех остальных переходов (включая попытки выхода за границы)

Терминальные состояния — состояния с метками T и X. Для терминальных состояний 𝑉(𝑇) = 𝑉(𝑋) = 0, так как из них нет возможных переходов.

Функция ценности и алгоритм Функция ценности 𝑉(𝑠) — ожидаемая суммарная дисконтированная награда при оптимальной стратегии, начинающейся из состояния 𝑠. Уравнение Беллмана для оптимальной ценности:

𝑉∗(𝑠) = max

[𝑅(𝑠,𝑎) + 𝛾 ⋅ 𝑉∗(𝑠′)] 𝑎∈𝐴

Алгоритм Value Iteration:

## 1. Инициализация: 𝑉0(𝑠) = 0 для всех состояний 𝑠

## 2. Итерация: Для 𝑘 = 1 до 100:

𝑉𝑘(𝑠) = max 𝑎∈𝐴 [𝑅(𝑠,𝑎) + 𝛾 ⋅ 𝑉𝑘−1(𝑠′)] где 𝑠′ — следующее состояние при действии 𝑎 из состояния 𝑠

## 3. Результат: 𝑉100(𝑆) — ценность стартового состояния после 100 итераций

Пример Для сетки:
