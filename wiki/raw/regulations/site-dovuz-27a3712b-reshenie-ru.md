Задача C. Встреча в плацкартном поезде

Дан поезд из n вагонов с заполненностями ai. Камиль начинает в тамбуре 0 и идет вправо, Вадим начинает в тамбуре n и идет влево. При встрече в тамбуре k:

- • Путь Камиля: сумма a1 + a2 + ··· + ak (обозначим Pk)

- • Путь Вадима: сумма an + an−1 + ··· + ak+1 (это S − Pk, где S = ni=1 ai)

Нужно найти k (от 0 до n), минимизирующий |Pk − (S − Pk)| = |2Pk − S|, а при равенстве выбрать минимальный k.

Innopolis Open по робототехнике , Идея решения Обозначим:

- • S = ni=1 ai — сумма всех заполненностей

- • Pk = ki=1 ai — префиксная сумма до k-го вагона (при k = 0: P0 = 0)

Тогда:

- • Сложность пути Камиля до тамбура k: Cкам = Pk

- • Сложность пути Вадима до тамбура k: Cвад = S − Pk

- • Разность: |Cкам − Cвад| = |Pk − (S − Pk)| = |2Pk − S|

Таким образом, задача сводится к поиску k ∈ [0,n], минимизирующего |2Pk − S|. Ключевое наблюдение: При увеличении k на 1 значение Pk увеличивается на ak+1 ⩾ 0, поэтому 2Pk − S монотонно не убывает. Значит, минимум модуля будет достигаться в точке, где 2Pk − S меняет знак с отрицательного на положительный, или там, где оно равно нулю.

Оптимизация: Не нужно хранить все префиксные суммы, достаточно накапливать текущую сумму в переменной.

Имеется m сотрудников, находящихся на этажах a1,...,am. Лифт:

Задача G. Робот и доставка

Дан двумерный лабиринт L × C с базовой стоимостью pi,j ⩾ 1 или −1 (недоступно). Робот стартует в (L1,C1), должен добраться до (L2,C2). Энергия для перехода из клетки (i,j) в соседнюю составляет pi,j ·W, где W — масса посылки. Общий лимит энергии — E. Нужно найти максимальное целое W, при котором существует путь в пределах лимита E.

- • P = (i,j)∈path pi,j — сумма базовых стоимостей по выбранному пути

- • Тогда общая энергия: Etotal = P · W

Для фиксированного W задача сводится к поиску кратчайшего пути в графе, где вес ребра

(перехода из клетки (i,j)) равен pi,j · W. Так как W — константа для конкретной проверки, можно использовать алгоритм Дейкстры.

Ключевое наблюдение: при увеличении W стоимость любого пути возрастает пропорционально. Поэтому существует монотонность: если для W существует путь ⩽ E, то для любого W′ < W тоже существует (возможно, другой путь). Это позволяет использовать бинарный поиск по W.

Алгоритм

**1.** Прочитать данные, преобразовать координаты в 0-индексацию.

**2.** Бинарный поиск по W в пределах [0,2 · 109] (верхняя граница завышена для надёжности).

**3.** Для каждого Wmid запустить Дейкстру:

- • Вес перехода из (x,y) в соседнюю клетку: px,y · W

- • Найти минимальную энергию для достижения цели

**4.** Если минимальная энергия ⩽ E, пробуем увеличить W, иначе уменьшаем.

**5.** Вывести максимальное W, для которого путь существует.
