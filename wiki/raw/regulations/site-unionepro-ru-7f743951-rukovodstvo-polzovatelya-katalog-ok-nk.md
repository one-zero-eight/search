## 1. ВВЕДЕНИЕ

**1.1.** Область применения Система представляет собой модуль для хранения и отображения информации об образовательных курсах, доступных для прохождения пользователю, с их описанием, а также списку преподавателей курсов.

**1.2.** Краткое описание возможностей Система обеспечивает выполнение следующих основных функций: ­ информирование пользователей об образовательных курсах, доступных для прохождения, в том числе акционных и рекламируемых;

­ информирование пользователей о списке преподавателей и спикеров образовательных курсов;

­ работа с информацией об образовательных курсах и преподавателях, доступная пользователям с соответствующими правами.

**1.3.** Уровень подготовки пользователя Для эксплуатации Системы пользователю необходимо обладать базовыми навыками работы с персональным компьютером.

**1.4.** Перечень эксплуатационной документации, с которой необходимо ознакомиться пользователю Пользователю необходимо ознакомиться со следующей документацией: ­ руководство администратора Системы; ­ настоящее руководство пользователя Системы.

## 2. НАЗНАЧЕНИЕ И УСЛОВИЯ ПРИМЕНЕНИЯ

**2.1.** Виды деятельности, функции, для автоматизации которых предназначена Система

Система позволяет: ­ автоматизировать сбор информации об образовательных курсах; ­ автоматизировать процесс предоставления образовательных курсов пользователям

Системы.

**2.2.** Условия, при соблюдении которых обеспечивается применение Системы в соответствии с его назначением

Техническое обеспечение, а именно аппаратно-программные средства Системы должны отвечать следующим требованиям: ­ процессор: не менее 4 процессоров на устройстве, частотой не менее 2 ГГц; ­ оперативная память: не менее 16 Гб; ­ жесткий диск: не менее 500 Гб свободного дискового пространства; ­ операционная система: Windows 10 или выше; ­ браузер: Google Chrome 106.0.5249.119 и выше.

## 3. ПОДГОТОВКА К РАБОТЕ

**3.1.** Состав и содержание дистрибутивного носителя данных Состав дистрибутивного носителя данных приведен в разделе 4 документа «Руководство администратора Системы».

**3.2.** Порядок загрузки программ и данных Порядок загрузки данных и программ представлен в разделе 4 документа «Руководство администратора Системы».

**3.3.** Порядок проверки работоспособности Проверка работоспособности Системы осуществляется путем выполнения операций, описанных в разделе 4 настоящего документа.

## 4. ОПИСАНИЕ ОПЕРАЦИЙ

**4.1.** Авторизация Для авторизации в Каталоге необходимо авторизоваться в ЕМОП (см. «Руководство пользователя «Единой системы идентификации UniOne (OneID)»).

Для начала работы с разделом «Каталог образовательных курсов» необходимо перейти во вкладку «Курсы», расположенную в верней панели рабочего окна программы (Рис. 1).

Раздел «Курсы»

Рис. 1

**4.2.** Работа с разделом «Курсы»

**4.2.1.** Работа с информационным каталогом После перехода в раздел «Курсы» пользователю откроется стартовая страница раздела

(Рис.2).

Стартовая страница раздела «Курсы»

Рис. 2 На странице представлены следующие подразделы: ­ Подраздел «Каталог курсов»; ­ Подраздел «Избранное»; ­ Подраздел «Мои курсы». При переходе в раздел «Курсы» по умолчанию открывается страница подраздела «Каталог курсов».

**4.2.1.1** Подраздел «Каталог курсов» При переходе в подраздел «Каталог курсов» пользователю открывается страница со списком доступных для покупки курсов, а также поисковая строка и фильтры для их сортировки и поиска.

На странице «Каталог курсов» представлен список карточек с курсами, содержащий следующую краткую информацию о каждом из курсов: ­ «Логотип» – изображение установленного логотипа курса; ­ «Наименование курса» – наименование образовательного курса; ­ «Направление обучения» – направление обучения, по которому осуществляется подготовка слушателей курса;

­ «Даты проведения курса» (при наличии) – даты, в которые проводится обучение по образовательному курсу.

Выше списка карточек с курсами находится список фильтров, сортирующих список курсов, и поисковая строка, осуществляющая поиск по наименованию курса.

Слева от списка карточек с курсами находится панель фильтров для поиска курсов по следующим категориям: ­ «Направление обучения»; ­ «Тип обучения»; ­ «Спецпредложения»; ­ «Сложность». При выборе карточки курса пользователь может перейти к конкретной карточке за дополнительной информацией. Работа с карточками курсов подробнее описана в п. 4.2.1.4.

**4.2.1.2** Подраздел «Избранное» Подраздел «Избранное» представляет собой список курсов, добавленных пользователем в

«избранное» (Рис.3). Подробное описание добавления курсов в «избранное» описано в п. 4.2.1.4. Страница подраздела «Избранное»

Рис. 3 Работа с разделом осуществляется аналогично описанной в п. 4.2.1.1.

**4.2.1.3** Подраздел «Мои курсы» Подраздел «Мои курсы» представляет собой список курсов, приобретенных пользователем для прохождения обучения. Работа с разделом осуществляется аналогично описанной в п. 4.2.1.1.

**4.2.1.4** Работа с карточкой курса При переходе в карточку курса пользователю открывается страница с подробной информацией о курсе (Рис.4):

Карточка курса

Рис. 4 На странице представлена следующая информация: ­ наименование образовательного курса; ­ описание образовательного курса; ­ кнопка перехода приобретения курса (кнопка «Оставить заявку»; после нажатия на кнопку пользователю будет предоставлена инструкция о приобретении курса, а после приобретения курс будет отображаться в подразделе «Мои курсы»);

­ кнопка добавления курса в «избранное» (кнопка «Добавить в избранное»; после нажатия на кнопку курс будет отображаться в подразделе «Избранное»); ­ даты проведения образовательного курса; ­ результаты обучения; ­ стоимость курса; ­ продолжительность курса (в часах).

**4.3.** Выход из Системы Для выхода из Системы после авторизации необходимо перевести курсор мыши на имя пользователя в правом верхнем углу и нажать кнопку «Выход», после чего для дальнейшей работы с Системой пользователю необходимо повторно авторизоваться.

## 5. АВАРИЙНЫЕ СИТУАЦИИ

**5.1.** Действия в случае несоблюдения условий выполнения технологического процесса, в том числе при длительных отказах технических средств

Надежность аппаратной платформы сервера и рабочих станций, операционных систем серверов и рабочих станций, систем управления базами данных обеспечивается их производителями.

Надежность аппаратного средства пользователя также обеспечивается его производителем. Во избежание потери информации, вводимой пользователем, рекомендуется при вводе большого количества данных выполнять процедуру их сохранения в процессе ввода.

**5.2.** Действия по восстановлению программ и/или данных при отказе магнитных носителей или обнаружении ошибок в данных

Выполнение процедуры восстановления программ и/или данных может быть необходимо по причинам:

­ системного сбоя, который привел к полной или частичной потери данных или нарушению работы программы;

­ по причине неверных действий пользователя, которые привели к изменению/потери данных; ­ нарушению работы программы. В случае необходимости восстановления программ и/или данных системный администратор проводит процедуру восстановления с резервного носителя.

**5.3.** Действия в случаях обнаружении несанкционированного доступа к данным В случаях обнаружения несанкционированного вмешательства в данные необходимо, не совершая никаких действий в интерфейсе пользователя, сообщить о факте вмешательства системному администратору.

**5.4.** Действия в других аварийных ситуациях

При возникновении других аварийных ситуаций пользователю не рекомендуется самостоятельно пытаться восстановить работоспособность Системы. В случае возникновения аварийной ситуации необходимо проинформировать системного администратора Системы и/или обратиться в службу технической поддержки.

## 6. РЕКОМЕНДАЦИИ ПО ОСВОЕНИЮ

Для успешной эксплуатации Системы пользователю необходимо обладать базовыми навыками работы с персональным компьютером (или другим аппаратным средством, на котором осуществляется работа с Системой), а также выбранным браузером.

Перед началом работы необходимо внимательно ознакомиться с документацией, перечисленной в п. 1.4 настоящего документа.
