# Второй отборочный этап — uslovia zadach 2 tur ru

Innopolis Open по информатике Второй отборочный тур. 2025-2026 Иннополис, 28 декабря 2025 г.

Общая информация по задачам олимпиады

Ограничение по памяти

Во всех задачах ограничение составляет 256 мегабайт.

Ограничение на размер исходного кода программы

Во всех задачах размер файла с исходным кодом решения не должен превышать 256 КБ.

Ограничение на посылку решений

По каждой задаче на проверку принимается не более 50 решений. По каждой задаче участник не может отправить решение более одного раза в течение 30 секунд.

Это ограничение не распространяется на последние 15 минут соревнований.

Система оценки

Каждая задача олимпиады поделена на несколько подзадач. Чтобы набрать баллы по подзадаче, программа должна пройти все тесты этой подзадачи.

За каждую задачу выставляется суммарный балл по всем ее подзадачам. В каждой подзадаче оценивается лучшее решение, то есть за подзадачу выставляется максимальный набранный по ней балл среди всех решений.

Получение информации о результатах проверки

Чтобы получить информацию о проверке вашего решения, используйте ссылку «Информация о проверке» во вкладке «Решения» в PCMS2 Web Client. По каждой задаче вам будет доступна информация по количеству набранных баллов в каждой подзадаче или результат проверки на первом непройденном тесте.

Таблица результатов

Во время соревнования доступна текущая таблица результатов. Для доступа к ней используйте ссылку «Результаты» в PCMS2 Web Client. Таблица результатов в PCMS2 Web Client не является окончательной.

Задача A. Непростая энергия кристаллов

Ограничение по времени: 1 секунда

Хомяк Шустрик и ёжик Шуршик проводят рискованный эксперимент. У них есть n магических кристаллов, каждый с целочисленным уровнем энергии. Кристаллы нужно разложить по двум камерам для дальнейших наблюдений. Дабы эксперимент не был провальным, должно соблюдаться правило: два кристалла, чьи энергии в сумме дают простое число, не должны находиться в одной камере.

Помогите хомяку и ёжику найти такое распределение кристаллов по двум камерам, чтобы ни одна пара кристаллов не нарушала описанного правила.

Шустрик и Шуршик напоминают, что простым числом называется натуральное (целое положительное) число, имеющее ровно два различных натуральных делителя — единицу и самого себя.

Формат входных данных

В первой строке ввода содержится целое число n — количество магических кристаллов

(1 ⩽ n ⩽ 105). Во второй строке ввода содержится n целых чисел ai — энергии всех магических кристаллов

(2 ⩽ ai ⩽ 1012). Формат выходных данных

Если невозможно распределить кристаллы по двум камерам с соблюдением описанного правила, то в единственной строке выведите −1 − 1 (два числа минус один, разделённые пробелом). Если распределить кристаллы возможно, то:

В первой строке выведите числа n1 и n2 — количество кристаллов в первой и второй камерах соответственно.

Во второй строке выведите в любом порядке энергии магических кристаллов из первой камеры, разделяя элементы пробелом.

В третьей строке выведите в любом порядке энергии магических кристаллов из второй камеры, также разделяя элементы пробелом.

Если существует несколько распределений, выведите любое из них.

Система оценки

Тесты к этой задаче состоят из семи групп. Баллы за каждую группу ставятся только при прохождении всех тестов группы, всех тестов необходимых для неё групп и тестов из условия.

Задача B. Продажа квартир

Ограничение по времени: 1 секунда

Бобёр Борис Луговой продаёт квартиры по очень выгодной (для него) цене. Помогите ему заработать как можно больше за t дней!

Есть n квартир, квартиры пронумерованы от 1 до n в порядке задания во входных данных. Квартира i имеет стоимость ai и находится в районе bi.

Дни продаж пронумерованы от 1 до t. В каждый день Борис может:

- • продать ровно одну квартиру, которую он ещё не продавал ранее; или

- • не продавать ничего.

Каждый раз при продаже Борис утверждает, что в квартире жил только он последние несколько лет (этот аргумент помогает продать квартиру дороже), поэтому в одном районе за K подряд идущих дней он может продать не больше одной квартиры (иначе жители этого района заметили бы что у Бориса несколько квартир).

Формат входных данных

В первой строке записаны три целых числа n, K, t (1 ⩽ n ⩽ 105, 1 ⩽ K ⩽ 105, 1 ⩽ t ⩽ 105). В следующих n строках записаны пары целых чисел ai, bi (0 ⩽ ai ⩽ 109, 1 ⩽ bi ⩽ n) — стоимость квартиры и номер района, в котором она находится.

Формат выходных данных

В первой строке выведите одно целое число — максимальную возможную выручку Бориса за t дней.

Во второй строке выведите t целых чисел. d-е число должно быть равно номеру квартиры, проданной в день d, или −1, если в этот день Борис не продаёт квартиру. Если существует несколько оптимальных ответов, выведите любой.

Задача C. Задача Арсения

Ограничение по времени: 1 секунда

Хомяку Арсению было слишком скучно на школьных уроках, поэтому он придумал для себя интересную задачу. Арсений хочет найти такое минимальное n-значное число x, чтобы существовало k n-значных чисел, не превосходящих число x, с одинаковой суммой цифр. Помогите хомяку решить эту задачу. n-значное число — это неотрицательное целое число, запись которого в десятичной системе счисления состоит ровно из n цифр и не содержит ведущих нулей.

Формат входных данных

В первой строке дано одно целое число n (1 ⩽ n ⩽ 106). Во второй строке дано одно целое число k (1 ⩽ k ⩽ 1018).

Формат выходных данных

Выведите x. Если x не существует, выведите «−1» (без кавычек).

Система оценки

Тесты к этой задаче состоят из девяти групп. Баллы за каждую группу ставятся только при прохождении всех тестов группы, всех тестов необходимых для неё групп и тестов из условия.

Задача D. Слон Филимон и цифра три

Ограничение по времени: 2 секунды

Все знают, что Индийский Слон Филимон большой фанат цифры 3. Слон считает число красивым, если оно состоит из цифр не превосходящих 3, то есть из 0, 1,

2 и 3.

У Филимона есть натуральное число n. За одну операцию он может прибавить к текущему значению числа n любое натуральное число, десятичная запись которого состоит исключительно из его любимой цифры 3 (например, 3, 33, 333, 3333 и так далее).

Помогите Слону Филимону определить минимальное число операций, необходимое, чтобы сделать число n красивым.

Формат входных данных

Каждый тест состоит из нескольких наборов входных данных. Первая строка содержит одно целое число t (1 ⩽ t ⩽ 1000) — количество наборов входных данных. Далее следует описание наборов входных данных.

Единственная строка набора входных данных содержит число n (1 ⩽ n < 10107). Обозначим за len(n) количество цифр в десятичной записи числа n. Гарантируется, что сумма len(n) по всем наборам входных данных не превосходит 107.

Формат выходных данных

Для каждого набора входных данных выведите одно число: ответ на задачу. Можно показать, что в ограничениях задачи, ответ всегда существует и не превосходит 263.

Система оценки

Тесты к этой задаче состоят из десяти групп. Баллы за каждую группу ставятся только при прохождении всех тестов группы и всех тестов необходимых для неё групп. Знак обозначает сумму по всем наборам входных данных.

Задача E. Шустрик и коробки

Ограничение по времени: 2 секунды

У хомяка Шустрика есть набор из n пронумерованных коробок. Эти коробки могут быть вложены друг в друга, образуя своеобразную иерархию. Коробка с номером 1 — самая внешняя (корень иерархии). Для каждой другой коробки точно известно, внутри какой коробки-родителя она находится.

Внутри каждой коробки (вместе со всеми вложенными в неё коробками) лежат «стержни» (рёбра). Каждый стержень соединяет две «точки» (вершины). Все точки пронумерованы. Содержимое каждой коробки u можно представить как граф Gu, который получается, если собрать все рёбра из коробки u и из всех коробок внутри неё.

Для каждой коробки u Шустрик хочет вычислить значение F(Gu).

F(G) = |A|=k f(A), где F(G) — функция от графа, равная сумме функций f от всех возможных наборов вершин A из k вершин ( — знак суммы). f(A) — это функция от набора вершин, её значение равно произведению ai (где ai — вес в вершине i) по всем i ∈ A, если все вершины из A попарно достижимы† друг из друга, и 0 иначе.

Число k принимает только целые значения от 1 до 4 (k = 1,2,3,4). Так, например, для k = 3, необходимо посчитать сумму произведений ai по всем связным тройкам вершин в графе. Помогите Шустрику справиться с этой задачей и посчитайте значение F(Gu) для всех коробок. † Две вершины графа считаются достижимыми, если существует путь, соединяющий их.

Формат входных данных

В первой строке ввода одно целое число k (1 ⩽ k ⩽ 4) — по множествам какого размера необходимо посчитать F(Gu).

Во второй строке ввода два целых числа n и m(n,m ⩽ 500000) — число коробок и число вершин в рассматриваемом графе.

В следующей строке n − 1 целое число — для всех коробок от 2 до n информация, в какую коробку вложена данная pi < i. В следующих n строках описываются коробки. Сначала указано число e — количество рёбер в данной коробке. Затем идёт e пар чисел, описывающих рёбра u,v (1 ⩽ u,v ⩽ m). В последней строке указано m чисел ai (0 ⩽ ai ⩽ 107), записанных в вершинах графа. Гарантируется, что сумма значений e по всем коробкам не превосходит 500000.

Формат выходных данных

В одной строке выведите значение функции F(u) для всех u в порядке возрастания номеров коробок. Так как это число может быть очень большим, выведите его по модулю 232.

Тесты к этой задаче состоят из восьми групп. Баллы за каждую группу ставятся только при прохождении всех тестов группы и всех тестов необходимых для неё групп.

Замечание

Рассмотрим первый пример. Задана иерархия коробок, где коробка 1 является внешней, а каждая коробка u > 1 вложена в коробку pu. Для каждой коробки задан набор рёбер между вершинами графа.

При k = 2 значение функции F(Gu) равно сумме произведений весов всех пар вершин, которые принадлежат одной компоненте связности графа Gu. Граф Gu получается объединением всех рёбер, лежащих в коробке u и во всех вложенных в неё коробках.

Коробка 6. В коробке 6 и во всех вложенных в неё коробках отсутствуют рёбра, поэтому все вершины изолированы и связных пар нет.

F(G6) = 0.

Коробка 5. Граф содержит одно ребро (1,4), соединяющее вершины 1 и 4. Единственная связная пара даёт вклад

1 · 4 = 4. Следовательно,

F(G5) = 4.

Коробка 4. Граф содержит рёбра (4,3) и (5,1). Компоненты связности:

{3,4}, {1,5}. Суммарный вклад равен

3 · 4 + 1 · 5 = 12 + 5 = 17, откуда

F(G4) = 17.

Коробка 2. В коробке 2 нет собственных рёбер, однако учитываются рёбра из вложенной коробки 5, а именно (1,4). Единственная связная пара даёт вклад

1 · 4 = 4, поэтому

F(G2) = 4.

Коробка 3. Граф содержит рёбра (2,6), (4,3) и (5,1). Компоненты связности:

{2,6}, {3,4}, {1,5}. Суммарный вклад равен

2 · 6 + 3 · 4 + 1 · 5 = 12 + 12 + 5 = 29, следовательно,

F(G3) = 29.

Коробка 1. Граф содержит все рёбра из всех коробок. Компоненты связности:

{1,3,4,5}, {2,6}. Сумма по всем связным парам равна

(1 · 3 + 1 · 4 + 1 · 5 + 3 · 4 + 3 · 5 + 4 · 5) + (2 · 6) = 59 + 12 = 71. Таким образом,

F(G1) = 71. Итоговые значения функции F(Gu) для коробок 1,...,6: 71 4 29 17 4 0.
