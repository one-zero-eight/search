## 1. Краткая характеристика дисциплины (модуля)

Изучение дисциплины (модуля) «Natural Language Processing / Обработка естественного языка» обеспечивает формирование и развитие компетенций обучающихся в области машинного обучения, их применение для решения различных прикладных задач в рамках профессиональной деятельности. **1.** Автоматическая категоризация обращений в техподдержку РТК ИТ Описание: разработать прототип модели для автоматической классификации входящих клиентских обращений (письма, чаты) по тематическим категориям (проблемы с интернетом, ТВ, счета) для их оперативного перенаправления нужным специалистам. Цель: освоить полный цикл создания модели классификации текста на реальных бизнес-данных.

**2.** Детекция тональности в отзывах и соцсетях для мониторинга бренда Описание: построить модель сентимент-анализа для автоматического определения эмоциональной окраски (позитив/негатив/нейтрал) упоминаний услуг и бренда РТК ИТ в публичном пространстве. Цель: получить практический навык анализа тональности неформального текста для задач бизнес-аналитики.

**3.** Прототип контекстного чат-бота для раздела FAQ портала госуслуг Описание: создать прототип диалоговой системы, способной отвечать на вопросы пользователей госуслуг с учетом контекста диалога и извлечением ключевых параметров (intent recognition и slot filling). Цель: понять принципы и разработать ключевые модули диалогового ИИ для поддержки пользователей.

**4.** Автоматизация извлечения бизнес-сущностей из новостей и документов Описание: разработать модель NER для автоматического выделения из текстов новостей и документов ключевых сущностей: компаний, персон, сумм контрактов, технологий - для последующего анализа рынка. Цель: освоить извлечение структурированной информации из неструктурированного текста с помощью современных NLP-методов.
