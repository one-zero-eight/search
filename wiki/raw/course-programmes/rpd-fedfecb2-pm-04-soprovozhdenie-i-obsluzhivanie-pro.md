## 3. Оценочные средства текущего контроля успеваемости

**3.1.** МДК.04.01 Внедрение и поддержка компьютерных систем Вопросы по темам МДК для устного и письменного опроса:

| 1. Какой стандарт описывает процессы жизненного цикла ПО? |
| --- |
| ГОСТ Р ИСО/МЭК 12207. |
| 2. Назовите три основные стратегии внедрения ИС. |
| Прямая ("Big Bang"), поэтапная, параллельная. |
| 3. В чем разница между менеджером сопровождения и менеджером |
| развертывания? |
| Менеджер развертывания отвечает за установку и настройку, а менеджер |
| сопровождения – за поддержку и обновление после внедрения. |
| 4. Что такое CALS-технологии? |
| Это технологии непрерывной информационной поддержки жизненного цикла |
| продукта, включая оценку качества функционирования. |
| 5. Что такое регламент обновления ПО? |
| Это документ, устанавливающий правила, периодичность и процедуру |
| применения обновлений. |
| 6. Назовите два вида эксплуатационной документации. |
| Руководство администратора и руководство пользователя. |
| 7. Зачем проводится тестирование в процессе эксплуатации? |
| Для выявления дефектов, возникающих в реальных условиях, и проверки |
| корректности обновлений. |
| 8. Что такое пилотный сценарий внедрения? |
| Внедрение системы сначала в одном подразделении или для ограниченной |
| группы пользователей. |
| 9. Какую функцию выполняет инструментарий автоматизации внедрения |
| (например, SCCM, Ansible)? |
| Автоматизирует развертывание, настройку и обновление ПО на множестве |
| компьютеров. |
| 10. Что входит в оценку качества функционирования ИС? |
| Надежность, производительность, безопасность, удобство сопровождения. |
| 11. Назовите два типа совместимости ПО. |
| Аппаратная и программная. |
| 12. Что такое "системная заплатка" (shim)? |
| Библиотека-прослойка, которая перехватывает вызовы API для имитации |
| старой среды. |
| 13. Как войти в безопасный режим Windows 10/11? |
| Через "Параметры > Восстановление > Особые варианты загрузки" или |
| клавишей F8 (не всегда). |
| 14. Что такое дефрагментация диска? |
| Перемещение фрагментированных частей файлов для увеличения скорости |
| чтения/записи. |
| 15. Какой инструмент показывает загрузку процессора и памяти? |
| Диспетчер задач (Task Manager). |
| 16. Чем отличается установка клиентского ПО от серверного? |
| --- |
| Серверное ПО часто требует предустановленной СУБД, служб IIS и настройки |
| прав доступа. |
| 17. Что такое групповая политика? |
| Механизм централизованного управления настройками ОС и ПО в домене. |
| 18. Как восстановить систему до предыдущего состояния после неудачной |
| установки драйвера? |
| Использовать точку восстановления системы (System Restore). |
| 19. Назовите три инструмента повышения производительности в Windows. |
| Очистка диска, дефрагментация, отключение визуальных эффектов. |
| 20. Где в Windows хранятся журналы событий приложений и системы? |
| В оснастке "Просмотр событий" (Event Viewer). |

**3.2.** МДК.04.02 Обеспечение качества функционирования компьютерных систем Вопросы по темам МДК для устного и письменного опроса:

| 1. Назовите три уровня модели качества ПО по ISO 25010. |
| --- |
| Характеристики, подхарактеристики, метрики. |
| 2. Что такое первичная ошибка? |
| Дефект, внесенный разработчиком в исходный код. |
| 3. Приведите пример вторичной ошибки. |
| Падение программы при вводе специальных символов в поле даты (из-за |
| неверной валидации – первичной ошибки). |
| 4. Что такое программная избыточность? |
| Введение дополнительных модулей, которые не нужны для нормальной |
| работы, но помогают при отказах (например, контроль целостности). |
| 5. Какие бывают дестабилизирующие факторы? |
| Аппаратные сбои, некорректные входные данные, ошибки в ОС, атаки |
| злоумышленников. |
| 6. Что такое анализ рисков? |
| Процесс выявления угроз, оценки вероятности их реализации и тяжести |
| последствий. |
| 7. Для чего нужны модули адаптации? |
| Для переноса ПО на разные платформы без изменения основной логики. |
| 8. Как называется модель надежности, основанная на зависимости |
| интенсивности отказов от числа оставшихся ошибок? |
| Модель Джелински-Моранды. |
| 9. Что такое временная избыточность? |
| Использование дополнительного времени (повторы, таймауты) для повышения |
| надежности. |
| 10. Приведите пример информационной избыточности в файловой системе. |
| Журналирование (журнал изменений) перед записью данных. |
| 11. Назовите три класса вредоносных программ. |
| Вирусы, черви, трояны. |
| 12. Чем отличается червь от вируса? |
| Червь распространяется самостоятельно по сети, не внедряясь в файлы, а вирус |
| --- |
| требует запуска зараженной программы. |
| 13. Какие методы обнаружения вредоносных программ существуют? |
| Сигнатурный, эвристический, поведенческий. |
| 14. Что такое файрвол? |
| Межсетевой экран, фильтрующий трафик по правилам (IP, порты, протоколы). |
| 15. Как настроить входящее правило в брандмауэре Windows для разрешения |
| RDP (3389)? |
| "Брандмауэр Защитника" → "Дополнительные параметры" → "Правила для |
| входящих подключений" → создать правило для порта 3389 (TCP). |
| 16. Что такое групповая политика безопасности? |
| Часть GPO, управляющая парольной политикой, аудитом, правами |
| пользователей. |
| 17. Что такое двухфакторная аутентификация? |
| Проверка по двум компонентам (пароль + токен/отпечаток пальца). |
| 18. Для чего применяется тестирование защиты ПО? |
| Для выявления уязвимостей до того, как их найдут злоумышленники. |
| 19. Назовите два протокола шифрования сообщений. |
| PGP (GPG), S/MIME. |
| 20. Что такое эвристический анализатор антивируса? |
| Анализирует поведение программы или код по косвенным признакам, |
| обнаруживая неизвестные вирусы. |
