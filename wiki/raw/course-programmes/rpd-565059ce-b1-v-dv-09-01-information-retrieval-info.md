## 1. Краткая характеристика дисциплины (модуля)

Изучение дисциплины (модуля) «Information Retrieval / Информационный поиск» обеспечивает формирование и развитие компетенций обучающихся в области информационного поиска, их применение для решения различных прикладных задач в рамках профессиональной деятельности. В ходе освоения дисциплины обучающиеся знакомятся с базовыми понятиями теории информационного поиска, основными принципами организации информационно-поисковых систем и алгоритмами аналитико-синтетической переработки документов, учатся осуществлять обоснованный выбор технологии построения информационно-поисковой системы, практически реализовывать основные алгоритмы информационного поиска. Для успешного освоения дисциплины обучающимся необходимо владеть компетенциями, сформированными в рамках изучения дисциплин: «Алгоритмы и структуры данных», «Линейная алгебра», «Теория вероятностей и математическая статистика», а также владеть языком программирования Python.

**1.** Разработка поисковой системы по базе знаний (Knowledge Base) для технической поддержки, включающей документацию, мануалы и историю инцидентов Описание: Инженеры службы поддержки тратят много времени на поиск решений проблем в обширной внутренней документации (PDF-мануалы, статьи базы знаний, отчеты по прошлым инцидентам). Необходима система, которая по запросу на естественном языке (например, «сброс настроек ONT Huawei») быстро находит наиболее релевантные документы, а не просто ищет по вхождению ключевых слов. Цель: построить прототип поисковой системы: 1) Индексирование документов (преобразование в векторные представления с помощью современных эмбеддинговых моделей, например, Sentence-BERT). 2) Реализация семантического поиска (поиск ближайших соседей в векторном пространстве). 3) Ранжирование результатов с учетом дополнительных факторов (популярность статьи, свежесть). Создать простой веб- интерфейс для поиска и оценить точность (precision@k) на тестовых запросах. Построение системы мониторинга и анализа текстовых обращений в социальных сетях и на форумах для выявления массовых проблем с услугами связи Описание: Пользователи часто первыми сообщают о проблемах с интернетом или связью в соцсетях (Twitter, VK) и на форумах. Необходимо в реальном времени мониторить эти источники, находить сообщения, релевантные услугам оператора, кластеризовать их по темам («нет интернета в районе X», «проблемы с мобильной связью») и определять всплески активности для оперативного реагирования. Цель: разработать пайплайн: сбор данных через API соцсетей, предобработка текста, классификация релевантности (бинарная модель: относится к услугам оператора или нет), кластеризация релевантных сообщений (например, методом LDA или тематического моделирования BERTopic). Построить дашборд, отображающий топ-тем проблем и их динамику во времени. Оценить эффективность обнаружения реальных инцидентов.

**3.** Реализация поискового индекса на основе инвертированного индекса (inverted index) и оценка релевантности по TF-IDF/BM25 Описание: необходимо создать упрощенную, но функциональную поисковую систему для небольшой коллекции текстовых документов (например, новостных статей). Система должна уметь быстро находить документы по запросу и ранжировать их по релевантности. Цель: реализовать ключевые компоненты: 1) Инвертированный индекс: построить структуру данных (термин -> список документов, где он встречается, с частотой). 2) Ранжирование: реализовать подсчет релевантности по моделям TF-IDF и Okapi BM25. 3) Обработка запроса: разбить запрос на термины, найти документы через индекс, вычислить скор для каждого и вывести ранжированный список. Оценить качество поиска по метрикам precision и recall на небольшом тестовом наборе с размеченной релевантностью.

**4.** Оценка качества поисковой системы с помощью метрик Precision, Recall, F1, MAP и NDCG Описание: после создания поисковой системы необходимо объективно оценить, насколько хорошо она работает. Для этого используются различные метрики, каждая из которых измеряет разные аспекты: полноту выдачи (Recall), точность (Precision), учет порядка документов (MAP, NDCG). Цель: для заданного набора запросов и коллекции документов с известной релевантностью (размеченный датасет, например, из TREC или собственный небольшой) вычислить и проанализировать метрики: 1) Precision@k, Recall@k, F1@k для разных k. 2) Average Precision (AP) и Mean Average Precision (MAP). 3) Normalized Discounted Cumulative Gain (NDCG@k). Объяснить, в каких сценариях какая метрика более важна (например, для поиска документов в юриспруденции важна высокая полнота, а для поиска товаров - точность первых результатов).

Также необходимо продемонстрировать работающий код выполненного проекта преподавателю для получения обратной связи и оценки, а также вносить правки в свою работу на основе комментариев преподавателя.
