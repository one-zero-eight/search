## 1. Краткая характеристика дисциплины (модуля)

Изучение дисциплины (модуля) «High Dimentional Data Analysis / Анализ многомерных данных» обеспечивает формирование и развитие компетенций обучающихся в области анализа больших данных, в частности выбора алгоритмов анализа данных, проектирования хранилищ данных, оценки качеств решений, их применение для решения различных прикладных задач в рамках профессиональной деятельности. В ходе освоения дисциплины обучающиеся в процессе решения различных задач получают навыки обработки больших данных, способов их предоставления и хранения.

## 2. Перечень планируемых результатов обучения

Вопросы/Задания к промежуточной аттестации в устной/письменной форме: Выберите правильный вариант ответа.

**1.** Какова основная цель концепции высокоразмерных данных (ХД)?

- a) Оптимизация баз данных

- b) Анализ и визуализация многомерных данных

- c) Упрощение хранения данных

- d) Увеличение скорости обработки данных

Правильный ответ: b) Анализ и визуализация многомерных данных

**2.** Какие из следующих идей лежат в основе концепции ХД?

- a) Снижение размерности и обработка временных рядов

- b) Моделирование линейных зависимостей

- c) Обработка данных с учетом их многомерной структуры

- d) Упрощение сложных вычислений

Правильный ответ: c) Обработка данных с учетом их многомерной структуры

**3.** Какое из следующих требований является ключевым для данных в контексте высокоразмерного анализа?

- a) Данные должны быть структурированными и одномерными

- b) Данные должны содержать минимальное количество пропусков

- c) Данные должны поддерживать различные форматы и типы

- d) Данные должны быть доступны в реальном времени

Правильный ответ: b) Данные должны содержать минимальное количество пропусков

**4.** Какое требование к данным в ХД связано с их качеством?

- a) Данные должны иметь высокую степень многомерности

- d) Данные должны иметь фиксированное количество измерений

Правильный ответ: b) Данные должны быть согласованными и актуальными

**5.** Какова основная функция витрины данных в системе аналитики?
