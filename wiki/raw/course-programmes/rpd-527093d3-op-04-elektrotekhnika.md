| 2.1. Экзамен |
| Экзамен проводится в устной и письменной форме с целью оценки уровня и |
| качества усвоенных умений и знаний в конце изучения дисциплины в 4 семестре. |
| Из фонда заданий формируются варианты экзаменационных заданий (билеты), |
| включающие тест из 30 заданий, 1 теоретический вопрос, 3 практических задачи (1 из |
| 5 вариантов). Задания дифференцируются по уровню сложности. Варианты заданий |
| равноценны по трудности, одинаковы по структуре. |
| На выполнение экзаменационного задания отводится 90 минут. |
| Примеры теоретических вопросов для экзамена: |
| 1. Электрическая энергия, её свойства и значение для мехатронных систем. |
| 2. Закон Ома для участка и полной цепи. Пример расчета цепи датчика. |
| 3. Первый и второй законы Кирхгофа. Применение для расчета цепей питания |
| робота. |
| 4. Последовательное, параллельное и смешанное соединение резисторов. |
| Пример для делителя напряжения в системе управления. |
| 5. Режимы работы электрической цепи: холостой ход, короткое замыкание, |
| номинальный. Последствия КЗ в робототехническом устройстве. |
| 6. Нелинейные элементы: диод, стабилитрон, варистор. Их применение в |
| схемах защиты мехатронных модулей. |
| 7. Переменный ток: действующее значение, частота, период. Сдвиг фаз в цепях |
| с R, L, C. |
| 8. Резонанс напряжений и токов. Использование в фильтрах и датчиках |
| приближения. |
| 9. Трехфазные цепи: схемы соединения звезда и треугольник. Питание |
| промышленных роботов. |
| 10. Назначение нулевого провода. Перекос фаз и его влияние на работу |
| электроники. |
| 11. Магнитное поле, закон Ампера, сила Лоренца. Применение в линейных |
| приводах. |
| 12. Магнитные цепи, аналогия с электрическими. Потери в стали, шихтовка |
| сердечников. |
| 13. Классификация электроизмерительных приборов. Выбор прибора для |
| измерения параметров датчиков. |
| 14. Магнитоэлектрические и электромагнитные приборы: достоинства и |
| --- |
| недостатки. |
| 15. Цифровые измерительные приборы: мультиметр, осциллограф. Настройка и |
| использование при отладке мехатронных систем. |
| 16. Измерение неэлектрических величин: датчики температуры (термопары, |
| термосопротивления), давления, перемещения (LVDT, энкодеры). |
| 17. Полупроводниковые диоды, выпрямители. Схемы питания контроллеров |
| роботов. |
| 18. Сглаживающие фильтры. Зачем нужен конденсатор на выходе |
| выпрямителя? |
| 19. Биполярные и полевые транзисторы. Режим ключа – основа силовой |
| электроники роботов. |
| 20. Усилители сигналов датчиков. Операционные усилители в системах |
| управления. |
| 21. Электронные генераторы. Тактовые генераторы микроконтроллеров. |
| 22. Стабилизаторы напряжения: линейные и импульсные. Применение в |
| источниках питания мехатронных устройств. |
| 23. Трансформаторы: принцип действия, коэффициент трансформации. |
| Питание цепей управления. |
| 24. Характеристики трансформатора: ХХ и КЗ. Потери и КПД. |
| 25. Асинхронные двигатели: устройство, принцип действия, механическая |
| характеристика. Использование в кранах-манипуляторах, конвейерах. |
| 26. Пуск и регулирование скорости асинхронного двигателя. Частотные |
| преобразователи в робототехнике. |
| 27. Синхронные двигатели. Серводвигатели с постоянными магнитами – основа |
| современных роботов. |
| 28. Машины постоянного тока: генераторы и двигатели. Регулирование |
| скорости изменением напряжения якоря. |
| 29. Двигатели постоянного тока в мобильной робототехнике. Коллекторные и |

| трансформаторном принципе.) |

| --- |
| пульсаций вдвое выше, пауз нет.) |

| 5. Где в робототехнике применяются усилители? (В цепях датчиков – усиление |

| 3. Для чего нужен кварцевый резонатор? (Для получения стабильной частоты.) |
| 4. Какой параметр стабилизирует линейный стабилизатор напряжения? |
| (Выходное напряжение при изменении входного или тока нагрузки.) |

| 5. Где применяются измерительные трансформаторы? (Для включения |
| приборов в цепи высокого напряжения и тока.) |

| 1. Что такое опыт холостого хода? (Вторичная обмотка разомкнута, измеряется |
| ток холостого хода и потери в стали.) |
| 2. Что такое опыт короткого замыкания? (Вторичная обмотка замкнута |

| 4. Почему Uкз (напряжение короткого замыкания) выражают в процентах от |

| 5. Какие потери в трансформаторе не зависят от нагрузки? (Потери в стали – на |
| гистерезис и вихревые токи.) |

| 5. Как изменяется пусковой момент при уменьшении напряжения? (Момент |

| 4. Как осуществить реверс трехфазного АД? (Поменять местами любые две |
