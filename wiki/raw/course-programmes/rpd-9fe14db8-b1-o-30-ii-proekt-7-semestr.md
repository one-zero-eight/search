## 1. Краткая характеристика дисциплины (модуля)

Дисциплина (модуль) «ИИ проект» является продолжением цикла проектного обучения по программе AI360 и фокусируется на углублении компетенций в области инженерии данных, этики ИИ и интеграции данных из разнородных источников, что готовит обучающихся к выполнению профессиональных ролей Data Engineer (Инженера данных), ИИ‑аналитика и Технического лидера проектов. Освоение дисциплины направлено на формирование обширного комплекса компетенций. В рамках профессиональных компетенций (ПК‑1, ПК‑2, ПК‑5) студенты развивают способность применять современные математические методы оптимизации для эффективного обучения моделей, выполнять полный цикл работы с данными (поиск, сбор, очистку, трансформацию, разметку, валидацию), проектировать системы хранения данных (реляционные и нереляционные БД) и реализовывать интеграционные решения на Python и C++. Общепрофессиональные компетенции (ОПК‑4–ОПК‑9) обеспечивают навыки разработки технической документации, инсталляции и настройки программно‑аппаратных комплексов, составления технических заданий, отладки и тестирования решений в области ИИ, а также использования современных инструментов и методов разработки. Универсальные компетенции (УК‑2–УК‑6) формируют способность к управлению проектами с учётом правовых норм (GDPR), командному взаимодействию, деловой коммуникации на русском и английском языках, саморазвитию и рациональному управлению временем. Содержание дисциплины в 7 семестре структурировано вокруг трёх ключевых тем. Раздел «Инструменты для работы с данными» охватывает сравнительный анализ языков программирования Python и R, использование SQL для работы с реляционными базами данных, ETL‑процессы (Extract, Transform, Load) и инструменты визуализации (Tableau). Раздел «Этика и безопасность данных» посвящён проблемам конфиденциальности и защиты персональных данных, изучению этических аспектов применения ИИ (bias, transparency) и регуляторных требований (GDPR). Раздел «Интеграция данных из разных источников» фокусируется на методах интеграции структурированных и неструктурированных данных (API, файловые форматы CSV/JSON/XML), устранении дублирования записей и разрешении конфликтов при объединении информации из разнородных источников. Для успешного изучения дисциплины обучающимся необходимо: владеть языками программирования Python и SQL на уровне, достаточном для анализа и обработки данных; знать основы теории вероятностей, математической статистики и методов оптимизации; понимать принципы работы реляционных баз данных, алгоритмы машинного обучения и иметь опыт командной работы в рамках ИИ‑проектов на предыдущих курсах.

## 2. Перечень планируемых результатов обучения

Целью освоения дисциплины (модуля) является формирование знаний, умений и навыков в рамках профессиональной деятельности, позволяющих успешно работать в избранной отрасли, а также обладать компетенциями, способствующими социальной мобильности, устойчивости и конкурентоспособности обучающегося в условиях современных рыночных отношений. Задачами дисциплины являются исследовать основные концепции и принципы инженерии данных, определив её значение в современном контексте разработки систем искусственного интеллекта; анализировать существующие методы и технологии сбора данных, а также оценить их эффективность и безопасность при хранении больших объемов информации; разработать и протестировать методики очистки и трансформации данных для повышения их качества и готовности к анализу; исследовать современные инструменты и техники визуализации данных, оценив их влияние на интерпретацию результатов анализа; сравнить различные подходы к моделированию данных и разработать рекомендацию по выбору наиболее подходящей модели для конкретного бизнес-кейса; проанализировать эффективность различных алгоритмов машинного обучения на реальных наборах данных, определив лучшие практики их применения; оценить функциональные возможности современных инструментов для обработки и анализа данных, выявив их сильные и слабые стороны; исследовать этические аспекты работы с данными, включая вопросы конфиденциальности и защиты персональной информации, и разработать рекомендации по соблюдению норм; разработать стратегию интеграции данных из различных источников, обеспечивающую согласованность и целостность информации в единой системе; оценить преимущества и недостатки использования облачных технологий для хранения и обработки данных в контексте масштабируемости и доступности; исследовать принципы проектирования архитектуры данных, разработав архитектурное решение для конкретного приложения в области искусственного интеллекта; организовать и провести практический проект по инженерии данных, позволяющий применить теоретические знания на практике, а также оценить полученные результаты и выявить области для улучшения. Реализовать алгоритм решения (метаэвристики) и визуализировать построенные маршруты на карте в демо-интерфейсе.

**2.** Разработка интеллектуального чат-бота для технической поддержки IT-отдела компании Описание: Сотрудники компании часто обращаются в IT-отдел с однотипными проблемами: сброс пароля, настройка почты, проблемы с доступом. Чат-бот должен понимать запрос на естественном языке, находить решение в базе знаний и либо давать инструкцию, либо автоматически выполнять действие через API. Цель: создать чат-бот с RAG-архитектурой для поиска в IT-базе знаний и интеграцией с простыми внешними API (например, для имитации сброса пароля). Реализовать интерфейс общения (Telegram-бот или веб-чат).

**3.** Система автоматического рецензирования кода (Code Review) на основе анализа стиля и поиска паттернов уязвимостей Описание: Система анализирует pull request в репозитории кода (Python/Java), проверяет соответствие PEP8/стандартам, ищет потенциальные баги (например, утечки ресурсов, возможные Null Pointer Exception), анти-паттерны и предлагает улучшения. Цель: использовать статический анализ кода (AST) и ML-модели (обученные на датасетах коммитов с код-ревью) для генерации комментариев к коду. Интегрировать решение в демо-версию CI/CD пайплайна (например, через GitHub Actions).

**4.** Создание сервиса подбора похожих вакансий для кандидатов на основе анализа резюме и текстов вакансий Описание: Пользователь загружает резюме в формате PDF. Система извлекает из него текст, структурирует (навыки, опыт, должность) и ищет наиболее подходящие вакансии из базы, используя семантический поиск и сравнение эмбеддингов. Цель: реализовать пайплайн парсинга PDF, извлечения сущностей (NER), векторного представления текстов и поискового движка. Создать веб-интерфейс для загрузки резюме и просмотра подобранных вакансий с объяснением сходства.

**5.** Модель для прогнозирования популярности контента (постов, видео) в социальных сетях на основе анализа ранних метрик Описание: По первым часам жизни поста (количество лайков, репостов, комментариев, скорость роста) и его контенту (текст, изображение, теги) спрогнозировать итоговую популярность через сутки/неделю. Цель: собрать симулированный датасет или использовать открытый (например, с Reddit). Обучить модель (LSTM/Transformer для временных рядов ранних метрик + NLP/CV для анализа контента) для регрессии/классификации финальной популярности.
