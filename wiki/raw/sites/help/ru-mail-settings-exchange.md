Настройка подключения Exchange

Адрес почтового сервиса - [mail.innopolis.ru](http://mail.innopolis.ru)

Рекомендуемые клиенты для подключения:

- Microsoft Outlook 2016-2019

- Microsoft Outlook for mobile

- Outlook for Mac

Клиенты Outlook 2010/2013 сняты с поддержки, поддержка не оказывается.

Так же рекомендуется использовать обновленные приложения.

Основное подключение осуществляется по средствам службы авто-обнаружения (Autodiscover). Т.е. достаточно ввести логин и пароль.

Почта всегда доступна через браузер. [https://mail.innopolis.ru/owa/](https://mail.innopolis.ru/owa/)

![image_1701080746025.png](https://help.university.innopolis.ru/images/image_1701080746025.png)

Для сторонних клиентов, которые не поддерживаю подключения по autodiscover, предусмотрено подключение по IMAP SSL:

- Адрес сервера входящей почты (IMAP): [mail.innopolis.ru](http://mail.innopolis.ru). Порт 993, тип шифрованного подключения SSL.

- Адрес сервера исходящей почты (SMTP): [mail.innopolis.ru](http://mail.innopolis.ru). Порт 587, тип шифрованного подключения: StartTLS. Требуется проверка подлинности.

POP3 - устаревший протокол, служба отключена, подключение невозможно!
