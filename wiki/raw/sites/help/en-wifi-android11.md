Connecting wifi on Android 11

## ¶ Connection for guests

Select "UniversityGuest" from the networks list

![](https://help.university.innopolis.ru/images_en/image_1699446651810.png)

Wait for the lobby page (for ex-ample, Google Chrome, Mozilla Firefox). Enter your mobile phone number in the format +79xxxxxxxxx and click on "Получить код" (Get the code) button.

Enter the code from SMS and click "Ввести код" (Confirm)

Connection is complete.

![](https://help.university.innopolis.ru/images_en/image_1699446667176.png)

## ¶ Connection for employees

For connect to the network, you must download and install the security certificate. It can be downloaded via Wi-Fi "Univer-sityGuest", via wired network or via the network of your mo-bile operator. See the website [http://pki.university.innopolis.ru](http://pki.university.innopolis.ru) and download the "iu_RCA.crt" certificate file (for example, to the Downloads folder). Open the downloaded certificate, you are prompted to install it. Name it, for example, "Innopolis University" and se-lect Wi-Fi from the drop-down menu.

![](https://help.university.innopolis.ru/images_en/image_1699446682900.png)

Next, select the "Univer-sityStaff" from the networks list. Click "Advanced Set-tings" in the appeared window:

- in "EAP Method" field from the drop-down menu, select "PEAP".

- in "2 authentication stage” field, select "MSCHAPV2".

- in "CA certificate" field se-lect previously downloaded and installed certificate "lnnopolis University".

- In «Domain» field enter the «innopolis.university»

- in "User" field, enter the username of your lnnopolis Uni-versity domain account

- in "Password" field, enter ac-count password.

Click "Connect"

Connection is complete.

![](https://help.university.innopolis.ru/images_en/image_1699446968187.png)

## ¶ Connection for students

For connect to the network, you must download and install the security certificate. It can be downloaded via Wi-Fi "Univer-sityGuest", via wired network or via the network of your mo-bile operator. See the website [http://pki.university.innopolis.ru](http://pki.university.innopolis.ru) and download "iu_RCA.crt" certificate file (for example, to Downloads folder). Open the downloaded certificate, you are prompted to install it. Name it, for example, "Innopolis Uni-versity" and select Wi-Fi from the drop-down menu.

![](https://help.university.innopolis.ru/images_en/image_1699446682900.png)

Next, select "UniversityStaff" from the networks list. Click "Advanced Settings" in the ap-peared window:

- in "EAP Method" field from the drop-down menu, select "PEAP".

- in "2 authentication stage" field, select "MSCHAPV2".

- in "CA certificate" field se-lect previously downloaded and installed certificate "lnnopolis University".

- in "User" field, enter the username of your lnnopolis Uni-versity domain account

- in "Password" field, enter the account password.

Click "Connect"

Connection is complete.

![](https://help.university.innopolis.ru/images_en/image_1699447025803.png)
