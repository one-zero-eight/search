Добавление учетной записи Exchange на телефон

1. (Accounts) Необходимо зайти в аккаунты или учетные записи.

2. (Delete old account Exchange) Удалить старую учетную запись.

3. (Create New) Создать новую. Тип Exchange

4. (server) Адрес сервера: mail.innopolis.ru

5. (User Name = email) имя пользователя = адрес почты

6. (Use SSL) Использовать SSL

## ¶ С помощью приложения Microsoft Outlook

- Открываем приложение Outlook и выбираем вариант подключения Exchange

![](https://help.university.innopolis.ru/images/image_1701240936856.png)

- Вводим данные для авторизации

Электронный адрес: Доменный email адрес

Пароль

Описание

Сервер: mail.innopolis.ru

Домен: оставить поле пустым

Имя пользователя: Доменный email адрес
