## ¶ Zoom - Создание конференции

В данной инструкции будут описаны этапы настройки трансляции через Zoom в Youtube.

- Открыть Web интерфейс Zoom, и выполнить вход в учетную запись

![](https://help.university.innopolis.ru/images/image_1699338422383.png)

- В верхней части панели выбрать пункт «Запланировать трансляцию»

![](https://help.university.innopolis.ru/images/image_1699338430179.png)

- Заполнить поля для создания конференции.

![](https://help.university.innopolis.ru/images/image_1699338461705.png)

- Зал ожидания.

- Если ее отключить, то к конференции сможет подключиться любой человек, без подтверждения.

- Если включить данную опцию, то все подключившиеся пользователи будут ожидать в зале ожидания, пока администратор не примет их, нажав на кнопку «Принять»

![](https://help.university.innopolis.ru/images/image_1699338465742.png)

- Обязательно отметить пункт «Выключать звук участников при входе». Автоматическая запись конференции (по желанию)

![](https://help.university.innopolis.ru/images/image_1699338471451.png)

- После заполнения всех полей нажать кнопку «Сохранить». Трансляция появится в личном кабинете.

![](https://help.university.innopolis.ru/images/image_1699338479854.png)

- Скопировать ссылки для приглашения можно перейдя по этой трансляции и нажать кнопку «Копировать приглашение».

![](https://help.university.innopolis.ru/images/image_1699338760860.png)

Запустить Zoom трансляцию по созданной ссылке. Нажать на кнопку «троеточия» и выбрать «Трансляция на Индивидуальная служба потокового вещания»

![](https://help.university.innopolis.ru/images/image_1699338484073.png)

Откроется новая ссылка в браузере, для организации трансляции.

В эти поля необходимо ввести ключи, URL с созданной трансляции на Youtube.

Не закрывая эту вкладку, переходим к следующим шагам.

![](https://help.university.innopolis.ru/images/image_1699338490110.png)

## ¶ Youtube - Создание трансляции

Перейти в свой аккаунт Youtube. Открыть творческую студию.

![](https://help.university.innopolis.ru/images/image_1699338909302.png)

Выбрать «Начать трансляцию»

![](https://help.university.innopolis.ru/images/image_1699338917844.png)

Далее «запланировать трансляцию», откроются настройки создания трансляции на Youtube

![](https://help.university.innopolis.ru/images/image_1699338922285.png)

- Ввести название трансляции

- Доступность:

- Для всех

- Только по ссылке

- Никому, только для этой учетной записи

- Описание.

- Дату и время

- Также можно загрузить превью картинку.

![](https://help.university.innopolis.ru/images/image_1699338926682.png)

Аудиторию выбрать:

Видео не для детей.

И возрастное ограничение:

Нет, видео подходит для зрителей младше 18 лет.

Нажимаем создать трансляцию

![](https://help.university.innopolis.ru/images/image_1699338931176.png)

Трансляция появится в личном кабинете, в творческой студии. Переходим по ней, кликнув на название.

![](https://help.university.innopolis.ru/images/image_1699338935963.png)

Перед нами появится панель управления нашей трансляцией на YouTube.

![](https://help.university.innopolis.ru/images/image_1699339183298.png)

Устанавливаем задержку “Малая”

![](https://help.university.innopolis.ru/images/image_1699338947236.png)

Копируем ключи трансляции.

- Ключи трансляции

- URL трансляции

![](https://help.university.innopolis.ru/images/image_1699338947234.png)

Также копируем адресную строку творческой студии.

![](https://help.university.innopolis.ru/images/image_1699338985013.png)

Вставляем все эти скопированные ключи в окно с Zoom, которое ранее мы открывали.

И жмем Go Live!

![](https://help.university.innopolis.ru/images/image_1699339338901.png)

Ожидаем завершения.

![](https://help.university.innopolis.ru/images/image_1699339343740.png)

В Zoom появится кнопка Live, это говорит о том, что на YouTube идет вещание.

Переходим в Творческую студию YouTube.

![](https://help.university.innopolis.ru/images/image_1699339349235.png)

Как только будете готовы, можете запускать трансляцию нажав на кнопку «Начать эфир»

После окончания трансляции не забудьте завершить трансляцию!

![](https://help.university.innopolis.ru/images/image_1699339397633.png)
