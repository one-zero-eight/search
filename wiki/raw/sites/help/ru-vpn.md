Необходима заявка для получения доступа к VPN:

1.Через почту it@innopolis.ru

2.Через бота [https://t.me/ITHelpFAQ_bot](https://t.me/ITHelpFAQ_bot)

После выдачи прав, воспользоваться одной из инструкций.

Шаблон заявки:

Добрый день, Прошу предоставить VPN доступ: * Для работ с * Для доступа к Обоснование: Учетная запись: Департамент/Центр/Отдел:

Пример заполненной заявки:

Добрый день, Прошу предоставить VPN доступ: * Для подключения к серверам 10.0.0.0, 10.0.0.1, 10.0.0.2 * Для работы с документами на диске Р. Обоснование: хотел бы подключиться к рабочим стендам для работы сервисами проекта "ProjectName" Учетная запись: username@innopolis.ru Департамент/Центр/Отдел: Департамент хорошего настроения
