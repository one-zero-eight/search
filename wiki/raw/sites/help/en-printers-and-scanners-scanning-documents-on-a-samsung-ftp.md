Scanning documents on a Samsung printer via FTP

Make sure that you have a personal folder on drive P, following the path: P:\Scan

![](https://help.university.innopolis.ru/images/image_1698934790638.png)

Note: if there is no personal folder, then in this case you need to write a request to it@innopolis.ru

Click on the button with the scan icon, highlighted in red in the figure below

![](https://help.university.innopolis.ru/images/image_1698934808737.png)

In the menu that opens, use the arrows to scroll to Scan to FTP

![](https://help.university.innopolis.ru/images/image_1698934825371.png)

The list of recipients to whom the scan should be sent will be revealed.

Select the desired recipient using the navigation arrows.

![](https://help.university.innopolis.ru/images/image_1698934840513.png)

Note: If the required recipient is not in the list, in this case, it is necessary to submit a request. it@innopolis.ru

After selecting the address, press the 'OK' button and wait for the document scanning to complete.

![](https://help.university.innopolis.ru/images/image_1698934859880.png)

View the presence of files on drive P.

![](https://help.university.innopolis.ru/images/image_1698934874349.png)
