Outlook application can't open / doesn't accept password

Important! First, check the functionality of your account. This can be checked in the web version of mail - [mail.innopolis.ru](/raw/sites/help/en-mail-mail-innopolis-ru.md)

## ¶ The web version and Outlook application do not work (Does not accept password)

If you were unable to access your email using a browser, and Outlook still does not accept your password, then create a request to [it@innopolis.ru](/raw/sites/help/en-mail-it-innopolis-ru.md), or use a [telegram bot](https://t.me/ITHelpFAQ_bot).

Reasons why you cannot log into the WEB version of mail via a browser ([mail.innopolis.ru](https://mail.innopolis.ru/)):

- Incorrect password

- Your account has been locked due to multiple login attempts

- Other reasons

## ¶ Troubleshooting Outlook desktop version

- Close all MS Office applications (Excel, Word, Outlook, PowerPoint…)

- Open Start menu, enter “Control Panel” and open it

![](https://help.university.innopolis.ru/images_en/image_1699515822456.png)

- Open Mail (Microsoft Outlook)

![](https://help.university.innopolis.ru/images_en/image_1699515938407.png)

- In the new window select “Configurations” and click “Show…”

![](https://help.university.innopolis.ru/images_en/image_1699515995476.png)

- In the mail configuration field, you will see a list (the name may not match the one in the picture below).

- Choose a configuration (possibly few items) and delete it

![](https://help.university.innopolis.ru/images_en/image_1699516232590.png)

- Agree with the warning

![](https://help.university.innopolis.ru/images_en/image_1699516140880.png)

- Create a new configuration. Press "Add.." button and enter a custom name

Important! the new configuration cannot be named the same as the old one

![](https://help.university.innopolis.ru/images_en/image_1699516296583.png)

- Enter your credentials in the new window

- Your name: Name Surname

- E-mail address: (example: n.surname@innopolis.ru)

- Account password (the same as for logging into a computer or portal)

- Confirm password

![](https://help.university.innopolis.ru/images/image_1698927933668.png)

- Please wait until your account setup is complete. Don't close the window

![](https://help.university.innopolis.ru/images/image_1698927953194.png)

- The system will ask you to change the old password to a new one. Enter your new password

![](https://help.university.innopolis.ru/images/image_1698927973833.png)

- If everything was done correctly, you will see this message:

![](https://help.university.innopolis.ru/images/image_1698927993178.png)

Open Outlook application. Windows will inform you that syncing of your mailbox has started. Syncing emails may take some time

![](https://help.university.innopolis.ru/images/image_1698928020085.png)

If none of the methods helped you, please leave a request at [it@innopolis.ru](/raw/sites/help/en-mail-it-innopolis-ru.md) and we will definitely help you!
