Regulations for access permissions to folders on drive P

![](https://help.university.innopolis.ru/images/image_1699350955229.png)

There are rules for issuing access rights to folders on drive P, please read:

1. Public

- ✅ Access for all employees of Innopolis University, with permissions:read, no write

- ✅ Access for employees of this department with the following permissions: read and write

2. Protected

- ❌ Access for all employees of Innopolis University, with permissions: no access

- ✅ Access for employees of this department with the following permissions: read and write

- ✅ Access for the head of this department with permissions: read and write

3. Private

- ✅ Access is only for the head of this department, users can be added by agreement with the head (mail to it@innopolis.ru)

- ❌ Access for all employees of Innopolis University, with permissions: no access

- ❌ Access for employees of this department with the following permissions: no access
