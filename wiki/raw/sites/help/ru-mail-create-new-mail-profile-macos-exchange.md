## ¶ Подключение новой почты в Mail на MacOS

Выполните эти действия для добавления учетной записи Exchange в программу Mail. Можно добавить столько учетных записей Exchange (EWS), сколько нужно.

1. Откройте программу Mail.

2. В меню Mail выберите пункт «Настройки» и раздел «Учетные записи».

3. Для добавления учетной записи нажмите значок плюса (+).

4. Выберите Exchange в списке типов учетных записей и нажмите «Продолжить».

5. Введите свое имя, адрес электронной почты и пароль, затем нажмите кнопку «Продолжить».

6. Если потребуется, введите адрес сервера mail.innopolis.ru, после чего нажмите кнопку «Продолжить».

7. Кроме того, для работы с сервером Exchange можно настроить программы «Контакты» и «Календари». Выберите нужные варианты и нажмите «Продолжить».

8. В более ранних версиях ОС OS X после завершения настройки появится сводка данных. Если сводка данных верна, нажмите «Создать». Если потребуется внести изменения, нажмите кнопку «Назад». Выберите команду «Подключиться к учетной записи», чтобы начать пользоваться учетной записью Exchange.

## ¶ Подключение новой почты в Outlook на MacOS

- Откройте Outlook 2011/2016 для Mac

- Откройте Tools (Сервис) > Accounts (Учетные записи).

![](https://help.university.innopolis.ru/images/image_1699010115897.png)

- В открывшемся окне нажмите на значок + в левом нижнем углу, затем нажмите Exchange....

- Заполните следующие поля:

Введите E-mail address (Адрес электронной почты).

В выпадающем списке Method (Метод) выберите User Name and Password (Имя пользователя и пароль).

Введите Имя пользователя.

Введите свой пароль ******** в поле Password (Пароль).

Адрес сервера: mail.innopolis.ru

Имя пользователя = адрес почты

Использовать SSL: ДА

- Нажмите Add Account (Добавить учетную запись).

- Если появится запрос Outlook was redirected to the server..., поставьте галочку Always use my response for this server (Всегда использовать мой ответ для этого сервера) и нажмите Allow (Разрешить).

- Введите свое имя в поле Account description (Описание учетной записи)
