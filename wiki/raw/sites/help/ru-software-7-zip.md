Автоматическое открытие архивов с помощью 7-Zip

Выбираем программу по умолчанию

Чтобы настроить программу 7-Zip для автоматического открытия архивов выполните следующие шаги:

1. Откройте 7-Zip: Запустите программу 7-Zip на вашем компьютере. Откройте меню пуск -> в поиске введите 7-Zip

![](https://help.university.innopolis.ru/images/image_1702380584685.png)

2. Настройка ассоциаций файлов:

- В меню программы 7-Zip выберите "Service" (Сервис) > "Options" (Настройки).

![](https://help.university.innopolis.ru/images/image_1702380611742.png)

- В открывшемся окне перейдите на вкладку "System" (Система).

3. Установка ассоциаций файлов:

- Нажмите кнопку "+", чтобы все типы расширений ассоциировались

- Нажмите "OK", чтобы сохранить изменения.

![](https://help.university.innopolis.ru/images/image_1702380403032.png)

4. Проверка:

- Попробуйте открыть архивы выбранных расширений, и теперь они должны автоматически запускаться через 7-Zip.
