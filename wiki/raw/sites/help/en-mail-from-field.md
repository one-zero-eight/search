Adding the FROM field Outlook

Compose a new email. If the From field is not already visible (above the To:.. field) select Options > From within the new email window.

Select 'Other E-mail Address' in the 'From' field

![](https://help.university.innopolis.ru/images/image_1701081013607.png)

Select the From field > Other Email Address... When prompted enter the Display Name or email address of the shared mailbox and select OK. When the From field is selected this should now display the email address of the shared mailbox as an available option.

![](https://help.university.innopolis.ru/images/image_1701081109030.png)

Send from Other E-mail Address window. The new message window can now be closed. If prompted to save the message as a draft select No, as the ‘From’ setting has already been applied.
