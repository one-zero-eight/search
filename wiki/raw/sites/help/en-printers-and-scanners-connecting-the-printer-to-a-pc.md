Connecting the printer to a PC

It is necessary that the PC is connected to the Innopolis University network.

- Via cable uni.innopolis.ru

- If via WIFI, then University Staff.

## ¶ Connecting a printer via FS

Hold down the Windows Key and Press R on your keyboard.

![](https://help.university.innopolis.ru/images_en/image_1699523228519.png)

The run dialog box will open

![](https://help.university.innopolis.ru/images_en/image_1699521737916.png)

Type in the program’s name: you want to run \\fs and press Enter

A list of printers will open. Find your printer in this list

![](https://help.university.innopolis.ru/images_en/image_1699521776764.png)

Example: you need to add a printer in office 451.

To do this, find the printer 451_Kyocera_3645 in the list.

The first characters are the cabinet number, then the printer model.

Right-click on the printer and “Connect”.

![](https://help.university.innopolis.ru/images_en/image_1699522016311.png)

## ¶ Connecting the printer manually

This option is needed if your computer is not in the uni.innopolis.ru domain

Click on the magnifying glass in the bottom-left corner of your screen. Type in “Control panel” and open.

![](https://help.university.innopolis.ru/images_en/image_1699515822456.png)

Open the Control Panel and choose Large icons under the View by drop-down list. Click on Devices and Printers.

![](https://help.university.innopolis.ru/images_en/image_1699521914236.png)

Toward the top left of the dialogue that appears select Add A Printer.

![](https://help.university.innopolis.ru/images_en/image_1699521963110.png)

Proceed to “The printer that I want isn’t listed” on the same tab.

![](https://help.university.innopolis.ru/images_en/image_1699522109287.png)

Click on “Add a printer using a TCP/IP address or hostname.” Go to “Next” in the bottom-right corner of the window.

![](https://help.university.innopolis.ru/images_en/image_1699522258646.png)

Under “Device type,” choose “TCP/IP Device.”

Next to “Hostname or the IP address,” type in your IP address.

Note: Don’t uncheck the “Query the printer and automatically select the driver to use” box.

![](https://help.university.innopolis.ru/images_en/image_1699522306326.png)

## ¶ Advanced manual driver configuration

You should be able to add the printer by following the above instructions. Rarely, the method may not work. In that situation, try these steps:

- You should now see the Install the printer driver dialog box.

![](https://help.university.innopolis.ru/images_en/image_1699523074833.png)

- You can download drivers from the official website of the printer, choose Have Disk.

- If you don’t have any driver, click on Windows Update. Windows will now walk you through the device driver installation process. Once it’s done, you’ll see a final Add Printer dialog box that shows the Print a test page button. Click this button to check if printing is okay or not.
