Create new mail Profile on macOS

Add an Exchange (EWS) account to Mail

Follow these steps to add an Exchange account to Mail. You can add as many Exchange (EWS) accounts as you want.

1. Open Mail.

2. From the Mail menu, choose Preferences, then click Accounts.

![](https://help.university.innopolis.ru/images_en/image_1699447978446.png)

Click the the Add button (+) to add an account.

![](https://help.university.innopolis.ru/images_en/image_1699448008397.png)

4. Select Exchange from the list of account types, then click Continue.

5. Enter your name, email address, and password, then click Continue.

![](https://help.university.innopolis.ru/images_en/image_1699448060789.png)

6. If Autodiscovery isn't enabled on your Exchange server, you're asked to enter your server address, then click Continue. Please, type mail.innopolis.ru on server address filed.

7. Features such as contacts and calendars can also be used with Exchange. Select the options you want to use, then click Continue.

![](https://help.university.innopolis.ru/images_en/image_1699448090830.png)

8. In earlier versions of OS X, a summary sheet appears when you complete setup. If the summary is correct, click Create. If you need to make changes, click Go Back. Select "Take account online" to start using the Exchange account.

Server: mail.innopolis.ru

User name = email

SSL = yes

![](https://help.university.innopolis.ru/images_en/image_1699447851992.png)

Click “Finish”

![](https://help.university.innopolis.ru/images_en/image_1699447872968.png)

Under When starting Microsoft Outlook, use this profile, click Always use this profile.

![](https://help.university.innopolis.ru/images_en/image_1699447900026.png)
