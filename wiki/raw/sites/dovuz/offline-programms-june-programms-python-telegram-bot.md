## Курс «Разработка Telegram-ботов на Python»

Первый поток

Слушатели курса изучат принципы построения и создания telegram-ботов на Python, научатся регистрировать, настраивать взаимодействие, загружать и запускать telegram-бота; познакомятся с такими же увлеченными программированием ребятами и заведут новые знакомства, а также погрузятся на две недели в жизнь Университета Иннополис.

Для 8-11 классов.

8 июня – 21 июня

Программирование на языке Python – это ключ к открытию мира технологий уже на самых ранних этапах обучения для школьников.

Не обойдётся без домашек и самообразования

Курс предназначен для школьников, освоивших базовый курс по изучению языка программирования Python. Слушатели научатся использовать ООП при написании проекта, работать с Git, GitHub, API Telegram. Школьники создадут и запустят telegram-бота на сервере, получат навыки для дальнейшего развития проекта.

Участникам необходимо пройти предварительный контест, на обучение будут приглашены школьники, владеющие базовыми знаниями языка программирования Python.
