## Курс «Программирование на Python. Базовый уровень»

Первый поток

Слушатели курса изучат базовые алгоритмические конструкции, основы языка Python, понятия типов данных, основы построения и описания алгоритмов, научатся решать простые задачи и реализуют небольшие проекты.

Для 7-11 классов.

7 - 20 июня

Программирование на языке Python – это ключ к открытию мира технологий уже на самых ранних этапах обучения для школьников.

Почему Python так привлекателен сейчас?

- Он подходит для создания разнообразных проектов, от игр до приложений, что позволяет реализовывать любые идеи.

- Python - это язык, который дружелюбен к начинающим благодаря своей простой и понятной структуре.
