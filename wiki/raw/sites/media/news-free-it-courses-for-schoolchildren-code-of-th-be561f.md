# Университет Иннополис открыл дополнительный набор на бесплатные ИТ-курсы для школьников по проекту «Код будущего»

> Страница относится к 2023 году: сведения на ней могли устареть.

2 февраля 2023

Учащиеся 8—11 классов изучат современные языки программирования за счёт государства в рамках федерального проекта «Развитие кадрового потенциала ИТ-отрасли» национальной программы «Цифровая экономика РФ». Сейчас на курсах обучается 132 тысячи человек. Новые участники могут присоединиться к проекту в течение февраля.

![](https://media.innopolis.university/upload/iblock/189/n1q1znqwvkx6mgicsqvcxwxuezq4udw5/i-0098%20%281%29.jpg)

Школьники научатся разрабатывать 2D-игры, напишут программу парсера с возможностью сборки и выгрузки HTML-файла, создадут консольное приложение с применением регулярных выражений для поиска данных, запустят Telegram-бота на Python и реализуют его функциональные возможности. По итогам обучения выпускники получат сертификат.

Слушатели дополнительного набора приступят к групповым занятиям со второго модуля, изучив материалы первого модуля по ускоренной программе и сдав промежуточную аттестацию. Курсы доступны в онлайн и офлайн-форматах. Продолжительность — 148 академических часов. Можно выбрать один из курсов:

— [Telegram-боты на Python](https://www.gosuslugi.ru/futurecode/23959?view=online&utm_source=pr&utm_medium=mediaiu&utm_campaign=codefuture&utm_content=donabor)

— [Разработка 2D-игр на Python](https://www.gosuslugi.ru/futurecode/23881?view=online&utm_source=pr&utm_medium=mediaiu&utm_campaign=codefuture&utm_content=donabor)

— [Разработка графических интерфейсов](https://www.gosuslugi.ru/futurecode/23948?view=online&utm_source=pr&utm_medium=mediaiu&utm_campaign=codefuture&utm_content=donabor)

— [Разработка парсеров](https://www.gosuslugi.ru/futurecode/23963?view=online&utm_source=pr&utm_medium=mediaiu&utm_campaign=codefuture&utm_content=donabor)

Для участия нужно подать заявку на портале [Госуслуг](https://www.gosuslugi.ru/futurecode?view=online&organization=44&region=45000000000)
