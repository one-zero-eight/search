# Бесплатное обучение школьников программированию на летних курсах «Кода будущего»

> Страница относится к 2023 году: сведения на ней могли устареть.

24 апреля 2023

Пройти один из двух курсов Университета Иннополис могут учащиеся 8—11 классов в рамках летних образовательных программ проекта «Код будущего». На онлайн-занятиях старшеклассники изучат Python, базовые алгоритмические конструкции и основы построения алгоритмов. Приём заявок открыт до 31 мая.

![](https://media.innopolis.university/upload/iblock/59b/ter1hfvcv2gnr61oja3vxyp6u6gnrvk9/i-67%202.png)

Слушатели курса [«Разработка 2D-игр на Python»](https://www.gosuslugi.ru/futurecode/27326?view=online) создадут видеоигру со звуками, световыми эффектами, анимацией персонажа в библиотеках Arcade и PyGame и разработкой собственного пользовательского интерфейса с меню и дополнительными всплывающими окнами.

Курс [«Telegram-боты на Python»](https://www.gosuslugi.ru/futurecode/27325?view=online) рассчитан на новичков в ИТ, которые научатся настраивать функции, регистрировать чат-боты, а в финале обучения — разработают собственного Telegram-бота с помощью Python.

Курсы состоят из четырёх модулей по 36 академических часов. Летом в ускоренном формате можно освоить первые 2—3 модуля обучения, остальные — завершить осенью. После итоговой аттестации школьники получат сертификаты. Для участников программ Университета Иннополис пройдут дополнительные вебинары с разбором задач ЕГЭ и ОГЭ по информатике.

Для участия нужно выбрать один из двух курсов Университета Иннополис на [Госуслугах](https://www.gosuslugi.ru/futurecode?view=online&organization=44&region=45000000000), подать заявление и пройти вступительное испытание.

«Код будущего» — проект для учеников 8—11 классов по освоению современных языков программирования. Проект организован Минцифры России под эгидой федерального проекта «Развитие кадрового потенциала ИТ-отрасли» национальной программы «Цифровая экономика». С 2022 года 330 участников «Кода будущего» стали победителями и призёрами Всероссийской олимпиады по информатике, Национальной технологической олимпиады, Всероссийского конкурса научно‑технологических проектов «Большие вызовы», Национальной олимпиады по анализу данных DANO и других конкурсов для школьников.
