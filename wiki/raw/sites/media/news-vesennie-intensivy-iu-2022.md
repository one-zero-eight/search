# Открыта регистрация на весенние интенсивы по программированию и подготовке к ЕГЭ Университета Иннополис

> Страница относится к 2022 году: сведения на ней могли устареть.

3 февраля 2022

Специалисты Центра подготовки и привлечения абитуриентов российского ИТ-вуза проведут онлайн-интенсивы по программированию и подготовке к ЕГЭ по информатике и математике для учащихся 7–11 классов. Курсы пройдут 26 марта — 2 апреля. Слушатели могут выбрать один или несколько предметов.

![](https://media.innopolis.university/upload/iblock/051/IMG_1790.JPG)

Программирование на C++

Для учащихся 7—11 классов.

Интенсив по программированию на C++ подойдёт для начинающих и для тех, кто уже знаком с программированием на языке C++. За неделю участники научатся писать код на C++, получат базовые знания и опыт для дальнейшего развития в сфере ИТ.

Подробности и регистрация: [https://dovuz.innopolis.university/prog-cpp/](https://dovuz.innopolis.university/prog-cpp/)

Разработка 2D-игр

Для учащихся 7—11 классов.

На курсе участники научатся писать 2D-игры на Python. В программе: повторение базы языка программирования, знакомство с библиотекой PyGame, работа со шрифтами, изображениями и звуком, обработка движений взаимодействия. За неделю участники интенсива самостоятельно создадут две игры.

Подробности и регистрация: [https://dovuz.innopolis.university/2d-game/](https://dovuz.innopolis.university/2d-game/)

Чат-боты

Для учащихся 7—11 классов.

На интенсиве по разработке чат-ботов участники научатся создавать Telegram-ботов с помощью языка Python. В программе: знакомство со структурой проекта, создание меню команд в боте, работа с машиной состояний, работа с платежами. В конце курса каждый участник под контролем преподавателя напишет бота для Telegram.

Подробности и регистрация: [https://dovuz.innopolis.university/chatbot/](https://dovuz.innopolis.university/chatbot/)

Фреймворк Django

Для учащихся 7—11 классов.

На курсе участники научатся создавать веб-приложения на Python, используя фреймворк Django. В программе: повторение базы языка Python, изучение HTML, CSS, Javascript, закрепление ООП, навыки работы с git и github, основы Django, шаблоны, формы, база данных, связка базы данных с программой ORM, представления на основе классов. В конце интенсива участники создадут собственные сайты.

Подробности и регистрация: [https://dovuz.innopolis.university/django/](https://dovuz.innopolis.university/django/)

Подготовка к ЕГЭ по математике

Для учащихся 10—11 классов.

Онлайн-интенсив посвящен заданиям второй части ЕГЭ. На занятиях подробно разберут тригонометрические, логарифмические, показательные уравнения (№12) и неравенства (№14), а также задачи по стереометрии (№13) и финансовая задача (№15).

Подробности и регистрация: [https://dovuz.innopolis.university/intensiv-ege-matem/](https://dovuz.innopolis.university/intensiv-ege-matem/)

Подготовка к ЕГЭ по информатике

Для учащихся 10—11 классов.

Курс поможет подтянуть знания по информатике и программированию. Участники поработают с графами, рекурсивными алгоритмами, научатся анализировать чужой код. В программе: программирование (№27), построение дерева решений (№23), рекурсивные алгоритмы (№16), анализ кода (№22), обработка символьной и целочисленной информации (№24—26), числовой последовательности (№17).

Подробности и регистрация: [https://dovuz.innopolis.university/intensiv-ege-informatika/](https://dovuz.innopolis.university/intensiv-ege-informatika/)

Заявки принимаются до 21 марта. Количество мест ограничено.
