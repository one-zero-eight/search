# Создание веб-приложения для заметок на Spring Boot

> Страница относится к 2022 году: сведения на ней могли устареть.

[Мероприятия](/raw/sites/media/events.md)

31 октября 2022

![](https://media.innopolis.university/upload/iblock/fa2/ce6qvk0ep3d77van1q9vzq7ttagk5wvw/Timepad%2018.png)

Центр специализированной ИТ-подготовки Университета Иннополис приглашает на бесплатный практический интенсив «Создание веб-приложения для заметок на Spring Boot».

Что вас ждет на интенсиве:

— познакомимся ближе с разработкой корпоративных приложений на Java

— узнаем особенности работы на Spring Boot

— попробуем создать свое веб-приложение для заметок на Spring Boot

— изучим карьерный путь в этом направлении

Проведет интенсив Марсель Сидиков, опыт программирования и преподавания программ по разработке корпоративных систем на Java 11 лет.

— руководитель направления стажировок компании Akvelon

— руководитель лаборатории JavaLab Института ИТИС Казанского Федерального Университета

— разработчик проектов для Министерств молодежи, культуры и образования Республики Татарстан

— преподаватель курсов по Java в Университете Иннополис и IT-академии IT-парка г. Казань

Вебинар проходит в рамках курса «Введение в разработку корпоративных приложений на Java». Участвуйте в федеральном проекте «Цифровые профессии», который даёт возможность обучиться со скидкой 50%, 75% или бесплатно. Зарегистрируйтесь на мероприятие, чтобы познакомиться с условиями участия в проекте.

Зарегистрироваться на интенсив по ссылке: [https://stc.innopolis.university/java-junior_webinar](https://stc.innopolis.university/java-junior_webinar?utm_source=media&utm_medium=link&utm_campaign=from-main-site)
