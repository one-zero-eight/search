# Университет Иннополис открыл регистрацию на бесплатный марафон по созданию игр на Python

> Страница относится к 2021 году: сведения на ней могли устареть.

28 мая 2021

9—11 июня слушатели изучат объектно–ориентированное программирование, научатся создавать объекты и события, строить уровни, меню и физику движений. Заявку на участие могут подать школьники от 10 лет. Марафон пройдёт онлайн.

![](https://media.innopolis.university/upload/iblock/e31/IMG_2400.jpg)

Работа с преподавателем будет длиться по 4 часа в день, учитывая перерывы. Обучать школьников будет методист ИТ-школы Университета Иннополис Максим Латников. Он провёл 2500 онлайн-уроков для школьников по Scratch, Python, Unity, ai2, ue4, thunkable + Web, разработчик образовательных программ по Scratch и Python.

По итогам 3 дней у каждого участника будут 3 игры и сертификат о прохождении курса. Для участия нужно зарегистрироваться на [сайте](https://vk.cc/c2oXlG) марафона и подготовить любой работающий компьютер с выходом в интернет. Марафон подойдёт даже для тех, кто никогда не программировал.

Создатели самых лучших игр, которых отберут преподаватели курса, получат скидку 10—100 % на полноценное месячное [обучение](https://vk.cc/c2oXbx) по созданию игр на Python, который стартует 15 июня.
