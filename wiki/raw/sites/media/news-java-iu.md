# Курсы по Java: новый набор

> Страница относится к 2019 году: сведения на ней могли устареть.

30 июля 2019

- [Индустрия](/raw/sites/media/home.md)

Университет Иннополис помогает развивать профессиональные компетенции в области промышленной разработки на Java в рамках собственных курсов повышения квалификации.

![](https://media.innopolis.university/upload/iblock/557/java.jpg)

По опросам Stack Overflow и GitHub, Java продолжает оставаться одним из самых популярных языков программирования в мире. Компании испытывают нарастающий дефицит java-специалистов и на рынке труда складывается ситуация, в которой спрос на разработчиков этого стека кратно превышает количество самих разработчиков.

## Начинающим

Онлайн-курс по основам промышленной разработки на Java подойдет начинающим специалистам и послужит крепким фундаментом для изучения и практического применения Enterprise инструментов. Продолжительность — 3,5 месяца. Начало — 2 сентября: [stc.innopolis.university/java-developer/](https://stc.innopolis.university/java-developer/)

## Опытным

Курс Java Enterprise разработан для специалистов с опытом программирования от 1 года на языках с C-подобным синтаксисом. Курс доступен в двух форматах:

онлайн-обучение продолжительностью 4 месяца. Начало — 28 октября: [stc.innopolis.university/middle-online/](https://stc.innopolis.university/middle-online/);

очное обучение на территории ИТ-вуза длительностью 2 месяца. Начало — январь 2020 года: [stc.innopolis.university/middle-full-time/;](https://stc.innopolis.university/middle-full-time/)

Участники курсов получают удостоверение о повышении квалификации установленного образца, сведения о котором вносятся в федеральный реестр документов об образовании, что официально подтверждает получение новой профессии.
