# ПИШ Университета Иннополис создала ИИ-сервис для безопасной разработки ПО

> Страница относится к 2025 году: сведения на ней могли устареть.

2 июля 2025

- [Индустрия](/raw/sites/media/home.md)

Ассистент Inspecto с использованием ML-технологий автоматизирует и ускоряет разработку программного обеспечения, защищает данные, а также позволяет обнаружить 15 типов уязвимостей в коде для 5 языков программирования Go, Python, JavaScript, TypeScript и Docker. Продукт стал частью сервиса версионного хранения кода GitFlame разработки ПИШ российского ИТ-вуза.

![](https://media.innopolis.university/upload/iblock/f36/blnwgqnuh4627df0jv2gmfopobchfv1a/IMG_6420.JPG)

ИИ-ассистент Inspecto предназначен для статического анализа и непрерывной интеграции кода, дополнительно предоставляет разработчикам приложений обучающие материалы, сгенерированные с помощью искусственного интеллекта, и поддерживает настройку условий под специфические требования пользователя.

Искандер Бариев, директор Университета Иннополис, руководитель Передовой инженерной школы: «Современные технологии разработки программного обеспечения испытывают необходимость в автоматизации рутинных задач, связанных с написанием кода. Решением этой задачи и занимается наша Передовая инженерная школа. Команда старается сделать разработку ПО безопаснее через внедрение инструментов, которые анализируют качество кода в реальном времени, в том числе с помощью ассистента Inspecto. Он помогает разработчикам получать немедленную обратную связь о потенциальных уязвимостях и ошибках в их коде, например о наличии циклических зависимостей или небезопасном хранении информации».

Сервис способен вести логирование активности разработчиков, формировать отчётность по метрикам производительности и выдать рекомендации по исправлению ошибок. Теперь руководители команд разработки могут оценивать эффективность работы над продуктом и вклад каждого сотрудника в проект. По словам экспертов Университета Иннополис, гибкая конфигурация системы позволяет интегрировать Inspecto в среды разработки VS Code и встроенный редактор GitFlame и масштабировать ИИ-ассистента на другие цифровые продукты и приложения.
