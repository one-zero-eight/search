# Стартовал приём заявок на бесплатные курсы по программированию для школьников и студентов

> Страница относится к 2024 году: сведения на ней могли устареть.

11 августа 2023

Учащиеся 8—11 классов и студенты колледжей изучат языки программирования в рамках проекта «Код будущего». Заявки на 2023 / 2024 учебный год принимаются до 30 сентября. Университет Иннополис — один из провайдеров проекта.

![](https://media.innopolis.university/upload/iblock/fbb/t73aafpljck7bg1ixzv7rqsgyjm3ji9o/i-0115.jpg)

Российский ИТ-вуз проведёт 5 программ обучения:

Разработка 2D-игр на Python

Telegram-боты на Python

Приручи искусственный интеллект на Python

Создание графических интерфейсов и парсеров на Python

Этичный хакинг на Python

Для обучающихся пройдут дополнительные вебинары с разбором задач ЕГЭ и ОГЭ по информатике. Обучение проходит в онлайн и в офлайн-формате и длится 144 часа.

После подачи заявки необходимо пройти вступительное испытание в течение 10 рабочих дней и заключить договор с образовательной организацией на бесплатное обучение. Успешно сдав итоговую аттестацию, школьники и студенты колледжей получат сертификат об окончании курса. Подробности и регистрация на курсы Университета Иннополис: [stc.innopolis.university/codeschool](/raw/sites/stc/codeschool.md)

Мария Образцова, директор Института дополнительного образования Университета Иннополис: «Интерес к ИТ среди подростков становится только сильнее. Наши курсы в рамках проекта “Код будущего” в 2022 / 2023 учебном году прошли 7683 учащихся из 88 регионов РФ. Университет Иннополис предлагает участникам проекта познакомиться с курсами на Python. В каталоге представлены программы начального и базового уровней. По итогам обучения школьники и студенты достигают первых результатов — разрабатывают собственные проекты».

Подробнее обо всех курсах проекта «Код будущего»: [gosuslugi.ru/futurecode](https://www.gosuslugi.ru/futurecode)

«Код будущего» — проект для учащихся 8—11 классов и студентов колледжей по освоению современных языков программирования. Проект организован Минцифры России под эгидой федерального проекта «Развитие кадрового потенциала ИТ-отрасли» национальной программы «Цифровая экономика».
