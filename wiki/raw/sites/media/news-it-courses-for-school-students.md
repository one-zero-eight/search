# ИТ-школа Университета Иннополис приглашает школьников на курсы со скидкой до 15 %

> Страница относится к 2022 году: сведения на ней могли устареть.

28 декабря 2022

- [Образование](/raw/sites/media/home.md)

- [Школа](/raw/sites/media/home.md)

Максимально выгодно можно забронировать онлайн-обучение по программированию на Scratch, разработке игр и изучению языков Python, С++ и Java до 31 декабря. Новогодняя акция «Прогматики» действует на все курсы для школьников 2—11 классов и продлится до 8 января.

![](https://media.innopolis.university/upload/iblock/d41/kfto3ywip5f07c9mnwi8ymzpwp5jiv7u/qp-jRl7PLDA.jpg)

Занятия проходят в группах или индивидуально с преподавателем в прямом эфире. Записи уроков будут доступны участникам и после прохождения курса. В конце обучения школьники подготовят итоговый проект и получат сертификат, подтверждающий обучение в ИТ-школе Университета Иннополис.

Во время новогодней акции [«Прогматики»](https://progmatica.ru/) скидка 15 % действует на любой курс в формате групповых занятий при полной оплате 64 или 128 академических часов обучения:

— Программирование на Scratch для 2—4 классов

— Разработка игр на Roblox для 4—6 классов

— Программирование на Python для 6—11 классов

— Программирование на С++ для 6—11 классов

— Программирование на Java для 6—11 классов

— Веб-разработка на HTML, CSS, JavaScript для 6—11 классов

— Олимпиадное программирование для 6—11 классов

Для участия в акции необходимо [забронировать](https://vk.cc/ck8Vg3) скидку на обучение. Перед выбором курса доступно бесплатное пробное занятие. Скидка 10 % при выборе индивидуального курса на 64 академических часа и 15 % — на 128 академических часов распространяется на все направления, кроме олимпиадного программирования.
