# Митап для технических писателей, аналитиков и разработчиков документации

> Страница относится к 2019 году: сведения на ней могли устареть.

[Мероприятия](/raw/sites/media/events.md)

23 марта 2019

![](https://media.innopolis.university/upload/iblock/350/13.03_.png)

Спикеры из Университета Иннополис и компаний Ростелеком ИТ, Центр финансовых технологий, Тензор и ICL-КПО ВС расскажут о методах и инструментах разработки документации, преимуществах обучающих видео и практике использования стандартов SCORM и Tin Can API при создании обучающих курсов в государственных учреждениях.

Программа:

10:00—11:00 — Регистрация, приветственный кофе-брейк

11:00—11:40 — «ЦФТ: «Тексты в интерфейсах» (Татьяна Фокина, UX аналитик, Центр Финансовых Технологий / Новосибирск)

11:40—12:20 — «Ведение документации в крупных проектах: опыт Ростелеком ИТ» (Константин Валеев, руководитель отдела системной аналитики и документации Ростелеком ИТ / Москва)

12:20—13:20 — Обед

13:20—14:00 — «Переиспользование артефактов аналитики и проблемы с этим связанные» (Джамал Алишев, бизнес-аналитик лаборатории облачных систем и виртуализации сервисов Университета Иннополис / Иннополис)

14:00—14:40 — «Опыт создания обучающих видео. Новый взгляд на печатные инструкции» (Антон Телин, руководитель отдела технических писателей компании Тензор / Ярославль)

14:40—15:20 — «Использование SCORM и Tin Can API в крупных государственных учреждениях» (Булат Хафизов, руководитель проектов ICL-КПО ВС / Казань)

15:20—15:40 — Подведение итогов

23 марта, 10:00, аудитория 106, Университет Иннополс (г. Иннополис, ул. Университетская д. 1)

Стоимость участия — 500 ₽, регистрация обязательна.

[Ссылка](https://media.innopolis.university/files/events/payment-order1.docx) на реквизиты для оплаты. На регистрации необходимо предоставить факт оплаты.

Дата

23 марта — 23 марта 2019

Время

Начало в 10:00

Место

Университет Иннополис, 106 ауд.
