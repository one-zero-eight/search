# Онлайн-курсы Университета Иннополис по Python, Java, Scratch и soft skills для школьников

> Страница относится к 2020 году: сведения на ней могли устареть.

1 июня 2020

Курсы рассчитаны на учащихся 3—10 класса, начало занятий в июне.

![](https://media.innopolis.university/upload/iblock/d6b/photo_2020-05-31_11-22-09.jpg)

## Программирование

Школа довузовской подготовки InnoStar принимает заявки до 7 июня. Обучение будет проходить 8—19 июня на платформе Zoom и займет всего 3 часа в день.

### Python

Школьники 7—10 классов освоят основы программирования на языке Python, алгоритмы и структуры данных, а также создадут игру на PyGame.

Регистрация: [https://vk.cc/auVCGJ](https://vk.cc/auVCGJ)

### Java Start

Обучение для 5—6 классов проходит в игровой форме, все задачи пользователя выполняет робот Карел. Участник будет писать программы, в которых Карел ищет сокровища, проходит лабиринты, становится грузчиком и так далее.

Регистрация: [https://vk.cc/auVCs2](https://vk.cc/auVCs2)

### Java Intensive

Курс рассчитан для учащихся 7—10 класса, у которых уже есть базовый опыт работы с языком программирования Java. Школьники изучат синтаксис, алгоритмы, структуры данных и объектно-ориентированное программирование. Во время обучения они смогут разработать проекты разного уровня сложности.

Регистрация: [https://vk.cc/auVCPD](https://vk.cc/auVCs2)

### Программирование на Scratch

Первый шаг в программирование для младшеклассников 3—4 класса. Слушатели будут работать с переменными, формулами, циклами, сенсорами и инструментами для создания изображений, звуков, фонов. В конце курса школьники защитят свои проекты, разработанные во время обучения.

Регистрация: [https://vk.cc/auVCYu](https://vk.cc/auVCYu)

## Soft Skills Online 1.0

Онлайн-смена по soft skills пройдёт 22—26 июня и рассчитана на школьников 12—17 лет. День на смене начинается с планирования, утренней мотивации с историями успеха известных личностей и зарядки. Занятия по тайм-менеджменту, эмоциональному интеллекту, публичным выступлениям и навыкам коммуникации проходят онлайн в Zoom, а само общение между участниками проходит в Telegram — в мессенджере школьники получают расписание, творческие домашния задания на день и следят за результатами друг друга. В конце дня — разговорный клуб “5 o'clock tea”.

Регистрация до 22 июня: [https://vk.cc/auVDcV](https://vk.cc/auVDcV)
