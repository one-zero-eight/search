# Открыт набор на весенние образовательные смены по программированию и робототехнике Университета Иннополис

> Страница относится к 2020 году: сведения на ней могли устареть.

29 января 2020

- [Школа](/raw/sites/media/home.md)

- [Индустрия](/raw/sites/media/home.md)

Учащиеся 5—11 классов научатся верстать сайты, программировать роботов и изучат языки программирования, востребованные в Google, Яндекс, HP и Intel. Полученные знания помогут школьникам подготовиться к всероссийским и международным олимпиадам.

![](https://media.innopolis.university/upload/iblock/8a0/IMG_4244.jpg)

Сотрудники Университета Иннополис подготовили 5 курсов: Python, Java start, Java intensive, Web programming и Робототехника. Регистрация на курс Python открыта до 20 февраля, на остальные курсы — до 8 марта. В стоимость всех смен входит обучение, питание и проживание в кампусе, развлекательные программы, трансфер из Казани в Иннополис и обратно.

Курс: Python

Python — универсальный язык программирования с большим количеством инструментов для решения задач. На этом языке работают сотрудники Google, Facebook, Yandex, Intel и HP. На нём написаны игры World of Tanks, Battlefield 2, Civilization 4, а также Instagram.

Даты: 6—9 марта

Участники: 8—11 класс

Стоимость: 10 000 рублей

Подробно:[http://innostar.innopolis.university/kurspython](https://vk.com/away.php?to=http%3A%2F%2Finnostar.innopolis.university%2Fkurspython%3Futm_source%3Dvkpost17")

Курс: Java start

Участники изучат основы языка Java, базовые алгоритмические конструкции, типы данных, основы построения и описания алгоритмов, а также решат простейшие задачи.

Даты: 21—28 марта

Участники: 5—7 класс

Стоимость: 15 000 рублей

Подробно:[http://innostar.innopolis.university/startjava](https://vk.com/away.php?to=http%3A%2F%2Finnostar.innopolis.university%2Fstartjava%3Futm_source%3Dvkpost17")

Курс:Java intensive

Слушатели познакомятся с основными способами представления алгоритмов, научатся программировать на Java, разрабатывать проекты разной сложности.

Даты: 21—28 марта

Участники: 7—11 класс

Стоимость: 20 000 рублей

Подробно:[http://innostar.innopolis.university/javaintensive](https://vk.com/away.php?to=http%3A%2F%2Finnostar.innopolis.university%2Fjavaintensive%3Futm_source%3Dvkpost17");

Курс:Web programming

Школьники научатся создавать и верстать сайты, используя веб-инструменты. Познакомятся с языком Java Script, HTML и CSS, получат знания и навыки, необходимые для фронтенд-разработки.

Даты: 21—28 марта

Участники: 8—11 класс

Стоимость: 20 000 рублей

Подробно:[http://innostar.innopolis.university/webprogramming](https://vk.com/away.php?to=http%3A%2F%2Finnostar.innopolis.university%2Fwebprogramming%3Futm_source%3Dvkpost17");

Курс: Робототехника

Эксперты российского ИТ-вуза помогут участникам подготовиться к всероссийским и международным соревнованиям по робототехнике, развить компетенции в области робототехники, программирования и конструирования.

Даты: 21—28 марта

Участники: 5—6 класс

Стоимость: 15 000 рублей

Подробно:[http://innostar.innopolis.university/robosmena](https://vk.com/away.php?to=http%3A%2F%2Finnostar.innopolis.university%2Frobosmena%3Futm_source%3Dvkpost17");
