# Бесплатные курсы по Java

> Страница относится к 2020 году: сведения на ней могли устареть.

29 июля 2020

Выпускники курса получат приглашение на работу в московскую ИТ-компанию «Инновационный центр Ай-Теко». Обучение начнётся 17 августа.

![](https://media.innopolis.university/upload/iblock/b61/IMG_9781%20%281%29.jpg)

Занятия пройдут в очной форме в Университете Иннополис: пять раз в неделю, занятость от шести часов в день. Слушатели курса смогут бесплатно жить в кампусе университета.

За двухмесячный курс участники освоят Java Core, научатся работать с фреймворком Spring и изучат паттерны проектирования, инструменты и технологии промышленной разработки на Java: JMS, NoSQL, Apache Ignite.

Выпускники получат приглашение на работу в должности стажера-разработчика ПО с релокацией в Москву (компенсация стоимости билетов и аренды жилья на первое время). По условиям ученического договора студенты должны будут отработать 1,5 года в одном из московских офисов компании «Инновационный центр Ай-Теко».

Регистрация: [careerdev.ru](https://vk.cc/axuE7d)
