# Университет Иннополис обучит школьников программировать на Python и C++

> Страница относится к 2023 году: сведения на ней могли устареть.

20 февраля 2023

26 марта — 1 апреля пройдут очные интенсивы по программированию для школьников 5—11 классов в ДОЛ «Заречье» под Казанью. С учащимися будут заниматься тренеры по программированию Университета Иннополис. Приём заявок открыт до 16 марта.

![](https://media.innopolis.university/upload/iblock/de3/1vzywlc034cdecx6deqr0t7xev3l9o8a/0kln4mXO2wg.png)

## Программирование на языке Python

Для кого: учащиеся 5—11 классов

Python подходит для старта в проектном и индустриальном программировании. Слушатели курса изучат основы языка, базовые алгоритмические конструкции, понятия типов данных, основы построения и описания алгоритмов, научатся решать простые задачи и реализуют несколько проектов для своего портфолио.

Подробности и регистрация: [https://dovuz.innopolis.university/spring-in-camp-python/](https://dovuz.innopolis.university/spring-in-camp-python/)

## Олимпиадное программирование

Для кого: учащиеся 6—11 классов

В зависимости от уровня подготовки школьники выберут одно из перечисленных направлений: C++ — погружение в олимпиадное программирование для начинающих; группа C — базовые алгоритмы и структуры данных для продолжающих; группа B — подготовка ко всероссийским олимпиадами и олимпиадам перечня РСОШ.

Подробности и регистрация: [https://dovuz.innopolis.university/spring-in-camp-olymp/](https://dovuz.innopolis.university/spring-in-camp-olymp/)

Также в программе будут спортивные и развлекательные мероприятия и экскурсия в Университет Иннополис.
