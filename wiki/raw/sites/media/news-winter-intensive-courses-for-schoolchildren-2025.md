# ИТ-школа Университета Иннополис открыла регистрацию на зимние интенсивы для школьников

> Страница относится к 2025 году: сведения на ней могли устареть.

20 декабря 2024

4—8 января «Прогматика» проведёт для учащихся 1—11 классов онлайн-курсы по разработке игр на Roblox, программированию на Python, 3D-моделированию в Blender, искусственному интеллекту и компьютерной грамотности. По итогам обучения слушатели создадут проекты для портфолио.

![](https://media.innopolis.university/upload/iblock/187/pbv37lnw43gmlbt6j4ek8abe6rqr1wko/IMG_9526.png)

Образовательные программы на 20 академических часов включают поддержку преподавателей, домашние задания с проверкой, итоговый проект. После завершения курса слушатели получат сертификаты и доступ к записям уроков. Доступно два варианта обучения: ежедневные онлайн-уроки в группе по расписанию и видеоуроки с поддержкой преподавателя в телеграм-чате.

Направления:

— Компьютерная грамотность для 1—4 классов

Участники изучат функции компьютера и освоят базовые навыки: работу с операционной системой, интернет-безопасность, основы офисных программ, алгоритмизации и программирования.

— Разработка игр на Roblox для 3—6 классов

Школьники познакомятся со средой разработки Roblox, изучат базовый синтаксис программирования. В программе: работа с переменными, циклами и функциями, создание сложных 3D-моделей.

— Программирование на языке Python для 6—11 классов

Слушатели изучат основы языка программирования Python и научатся использовать его для решения различных задач. В программе: знакомство с переменными, условиями, циклами и с коллекциями данных, работа с особым модулем для создания телеграм-бота.

— Искусственный интеллект для 6—11 классов

Участники научатся писать запросы к нейронным сетям и применять ИИ в повседневных задачах. В программе: области использования и работа с нейронными сетями.

— 3D-моделирование в Blender для 7—11 классов

Школьники изучат в программе Blender 3D-моделирование и текстурирование объектов, познакомятся с основными принципами проектирования, научатся работать с референсом, настраивать материалы, свет и камеру.

Регистрация открыта до 29 декабря: [progmatica.innopolis.university/w_intensive25](https://progmatica.innopolis.university/w_intensive25)

Скидка 30% на курс видеоуроков при приобретении двух интенсивов разных форматов.
