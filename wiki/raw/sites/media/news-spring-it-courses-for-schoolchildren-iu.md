# Университет Иннополис открыл регистрацию на весенние интенсивы для школьников по ИТ-направлениям

> Страница относится к 2024 году: сведения на ней могли устареть.

19 февраля 2024

25—29 марта ИТ-школа российского ИТ-вуза проведёт онлайн-курсы для учащихся 3—11 классов по разработке игр на Roblox, программированию на Python, 3D-моделированию в Blender и искусственному интеллекту. В конце обучения слушатели создадут свой проект в портфолио.

![](https://media.innopolis.university/upload/iblock/037/vpinwfr4jdwybj9iuciy44zlsai9cbpb/DSCF0251.png)

Курсы доступны в двух формах: ежедневные онлайн-уроки по расписанию и самостоятельное изучение материала по видеоурокам с поддержкой преподавателя в телеграм-чате. По итогам все слушатели получат сертификат о прохождении интенсива и вечный доступ к записям уроков.

Направления интенсивов:

— Разработка игр на Roblox для 3—6 классов

Школьники познакомятся со средой разработки Roblox, научатся использовать её для решения различных задач изучат базовый синтаксис программирования. В программе: работа с переменными, циклами и функциями, создание сложных 3D-моделей и ресурсов для сбора для разработки проекта в Roblox.

— Программирование на языке Python для 6—11 классов

Слушатели разберут основы языка программирования Python и научатся использовать его для решения различных задач. В программе: знакомство с переменными, условиями, циклами и с коллекциями данных, работа с особым модулем для создания телеграм-бота.

— Искусственный интеллект для 6—11 классов

Учащиеся узнают, как работают актуальные нейронные сети. В программе: запросы к нейронным сетям и применение ИИ в повседневных задачах.

— 3D-моделирование в Blender для 7—11 классов

Участники изучат 3D-моделирование и текстурирование объектов в программе Blender. В программе: основные принципы проектирования, работа с референсом, настройка материалов, света и камеры.

[Регистрация](https://innopolis.university/bitrix/admin/%20https://progmatica.innopolis.university/spring_intensive24) открыта до 22 марта
