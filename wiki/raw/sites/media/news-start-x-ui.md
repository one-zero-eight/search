# Первый в России хакатон по продуктам и технологиям для онлайн-кинотеатров

> Страница относится к 2021 году: сведения на ней могли устареть.

22 марта 2021

Университет Иннополис и видеосервис START проведут хакатон для студентов российского ИТ-вуза с призовым фондом 250 000 рублей. Хакатон стартует 27 марта в онлайн-формате и завершится очной защитой проектов в Иннополисе 3 апреля.

![](https://media.innopolis.university/upload/iblock/e84/on%20stream_%D0%B0%D1%84%D0%B8%D1%88%D0%B0_2.png)

В первый день соревнования директор по продукту START Михаил Бондар и технический директор видеосервиса Кирилл Евсеенко расскажут, какие ИТ-технологии применяются в стриминговых сервисах и как развивается эта отрасль. На митапе участники получат задачи по двум направлениям на выбор:

— Задача по разработке: интерфейс мониторинга качества доставки контента.

— Бизнес-задача: аналитика с ответом на вопрос «Какими будут видеосервисы через 10 лет?».

На решение задач отводится 7 дней. Участники объединятся в команды из 2—5 человек. По правилам хакатона каждая команда единожды может попросить помощь у экспертов: дополнительную информацию, статистику или подсказку.

Регистрация до 27 марта (14:00): [http://hack.innopolis.university/onstreamhack](http://hack.innopolis.university/onstreamhack)
