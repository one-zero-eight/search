# «Web-разработчик» — новый курс Университета Иннополис

> Страница относится к 2019 году: сведения на ней могли устареть.

25 июля 2019

- [Образование](/raw/sites/media/home.md)

- [Индустрия](/raw/sites/media/home.md)

За 4 месяца слушатели освоят веб-разработку с нуля под руководством наставника, научатся самостоятельно верстать и программировать сайты и получат навыки применения JavaScript в работе. В программу курса входят вебинары с преподавателями, еженедельные персональные консультации с личным наставником и практика, которая составляет 70 % обучения.

![](https://media.innopolis.university/upload/iblock/271/IMG_4632.jpg)

«В рамках образовательного процесса на наших курсах за каждым учеником закрепляется наставник-консультант, который будет проверять домашние задания, давать полноценную обратную связь во время еженедельных персональных консультаций. Также ученики смогут задавать вопросы наставникам и преподавателям в учебном телеграм-чате курса», — пояснил руководитель Центра специализированной ИТ-подготовки Университета Иннополис Александр Долгобородов.

Краткая программа:

Введение, обзор инструментария разработчика и основы Git.HTML;

Практическое применение HTML. Подключение CSS и JavaScript на странице;

Подходы к верстке страниц. Возможности CSS3;

JavaScript — синтаксис и основные конструкции языка;

Новшества в JavaScript. Современный стандарт ES6;

DOM API, событийная модель;

Web-сервер, AJAX, REST API;

Основы серверного программирования на PHP;

Модули JavaScript. Препроцессоры CSS. Системы сборки проектов.

В конце курса слушатели разрабатывают дипломный проект для портфолио, получают записи вебинаров и официальные документы, подтверждающие получение профессии. Над программой работали преподаватели Университета Иннополис и практикующие эксперты в веб-разработке.

Обучение первого потока начнётся 2 сентября.

Подробности и регистрация: [https://stc.innopolis.university/web-developer-junior/](https://stc.innopolis.university/web-developer-junior/)
