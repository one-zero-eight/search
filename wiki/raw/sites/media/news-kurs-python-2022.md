# Онлайн-курс по Python для школьников

> Страница относится к 2022 году: сведения на ней могли устареть.

11 марта 2022

- [Школа](/raw/sites/media/home.md)

- [Образование](/raw/sites/media/home.md)

ИТ-школа «‎Прогматика» Университета Иннополис приглашает на онлайн-интенсив по Python для школьников 6—11 классов. Трехмесячный курс для начинающих программистов стартует 21 марта.

![](https://media.innopolis.university/upload/iblock/045/hyk2jg6sq7hwcprqnawsngeo9ey76yy6/DSCF0090.jpg)

В программе курса 5 обучающих модулей:

Установка и запуск Python

Переменные, операторы, строки и коллекции данные

Словари и строки в Python

Функции-генераторы

Создание и импорт модулей и пакетов

2 раза в неделю преподаватели будут выходить по видеосвязи, объяснять темы и отвечать на вопросы. Домашние задания закрепят теорию на практике.

Ирина Андреева, 7 класс: «Курс помог разобраться в основах программирования на Python, лучше понять то, как устроен сам язык. Преподаватель очень понятно объяснял, постоянно уточнял, понятен ли новый материал. Если человек хочет научиться программированию с нуля, то я бы посоветовала этот курс».

Елизавета Загурских, 9 класс: «Занятия дали мотивацию продолжать обучение. Преподаватель компетентный, все понятно объяснял, отвечал на все вопросы».

Подробности и регистрация: [https://progmatica.ru/intensive_python](https://progmatica.ru/intensive_python)

В рейтинге [PYPL](http://pypl.github.io/PYPL.html) Python обгоняет языки программирования Java, JavaScript и С#. По прогнозам [SkillFactory](http://blog.skillfactory.ru/samye-populyarnye-yazyki-programmirovaniya-2021-goda/), Python будет популярен в ближайшие годы в Data Science. С его помощью техногиганты анализируют предпочтения в кино (Netflix) и музыке (Spotify), предлагают покупки (Amazon).
