# Открыта регистрация на интенсивы по олимпиадному программированию на C++ и Python для школьников

> Страница относится к 2021 году: сведения на ней могли устареть.

15 декабря 2021

Специалисты ИТ-школы «Прогматика» Университета Иннополис подготовили зимние образовательные интенсивы для учащихся 7—11 классов. Курсы пройдут 5—9 января.

![](https://media.innopolis.university/upload/iblock/3aa/_MG_3761.JPG)

Интенсив по олимпиадному программированию на C++ подойдёт для начинающих и для тех, кто уже знаком с программированием на языке C++ и хочет подтянуть свои навыки. В программе: введение в олимпиадное программирование, базовые конструкции и алгоритмы для начинающих и алгоритмы и структуры данных для продолжающих.

На курсе программирование на Python участники узнают об одном из самых популярных языков программирования, на котором работают сотрудники Google, Facebook, Yandex, Intel и HP. Интенсив подойдет школьникам, которые хотят программировать на популярном языке и быстро запустить свою первую работающую программу.

— Олимпиадное программирование на С++ для 8—11 классов

Продолжительность: 25 академических часов

Подробности и регистрация: [https://progmatica.ru/winter_intensive/olymp](https://progmatica.ru/winter_intensive/olymp)

— Программирование на Python для 7—11 классов

Продолжительность: 25 академических часов

Подробности и регистрация: [https://progmatica.ru/winter_intensive/python](https://progmatica.ru/winter_intensive/python)

После обучения участники получат сертификат и проект в портфолио в зависимости от программы обучения.
