# Набор на курсы Java Enterprise Developer

> Страница относится к 2018 году: сведения на ней могли устареть.

5 июля 2018

- [Индустрия](/raw/sites/media/home.md)

Центр специализированной ИТ-подготовки Университета Иннополис объявляет набор на курс повышения квалификации. В программе: 4 месяца обучения, практическая работа над проектами, индивидуальные консультации с преподавателями, семинары по трудоустройству и подготовка студентов к собеседованиям в индустрии.

![](https://media.innopolis.university/upload/iblock/974/696061426.jpg)

Курсы рассчитаны на разработчиков с опытом программирования на Java, С#, С++, PHP и других языках с С-подобным синтаксисом, желающих улучшить навыки и получить практический опыт применения специализированных библиотек и фреймворков.

Программа составлена экспертами Университета Иннополис при участии специалистов ИТ-компаний и включает в себя 15 основных блоков:

- Java core;

- Фреймворки логгирования;

- Основы языка моделирования UML;

- Модульное тестирование на базе JUnit5;

- Инструменты промышленной разработки;

- Паттерны GoF;

- JDBC и работа с БД;

- JPA и Hibernet;

- Not only SQL;

- Архитектура современных ИС и методологии разработки;

- Spring;

- Async communitation, messeging;

- Архитектура отказоустойчивых систем;

- Архитектура высоконагруженных систем;

- Apache Ignite.

Выпускники курсов получат официальное удостоверение о повышении квалификации установленного образца с занесением в федеральный реестр.

По результатам прошлых выпусков 80% специалистов, окончивших курсы, трудоустроились в ИТ-компаниях.

Подробная информация о курсе повышения квалификации и регистрация: [https://stc.innopolis.university/middle-online/](https://stc.innopolis.university/middle-online/)
