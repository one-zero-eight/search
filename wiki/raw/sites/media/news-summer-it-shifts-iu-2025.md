# Университет Иннополис приглашает школьников на летние ИТ-смены

> Страница относится к 2025 году: сведения на ней могли устареть.

18 апреля 2025

Двухнедельные образовательные программы для учащихся 3—11 классов с проживанием и питанием в кампусе российского ИТ-вуза включают занятия по Python и C++, 3D-моделированию, олимпиадному программированию, разработке Telegram-ботов и видеоигр. Также на сменах — квесты, квизы, игры и спортивные мероприятия. Открыта регистрация на 14 программ в июне и июле, количество мест ограничено.

![](https://media.innopolis.university/upload/iblock/e47/mbewp0lr2j6uvx8qzd97pv2zggdck0in/IMG_3579.JPG)

В стоимость программы входят занятия, проживание в жилых корпусах Университета Иннополис и пятиразовое питание. Обучение займет по 4—5 часов в день, в остальное время участников ждут развлекательные мероприятия. По окончании курса каждый школьник получит сертификат участника.

Программы первой смены 8—21 июня:

— Создание игр в Roblox Studio для 3—5 классов

— Python. Базовый уровень для 6—11 классов— Олимпиадное программирование для 6—11 классов

— Основы 3D-моделирования и создание игр в Unity для 7—11 классов

— Разработка Telegram-ботов на Python для 8—11 классов

[Программа и регистрация](https://dovuz.innopolis.university/offline-programms/june-programms)

Программы второй смены 22 июня — 5 июля:

— Создание игр в Roblox Studio для 3—5 классов

— Python. Базовый уровень для 6—11 классов

— Олимпиадное программирование для 6—11 классов

— Разработка Telegram-ботов на Python для 8—11 классов

— Gamedev на Unity. Разработка игры и путь на рынок для 9—11 классов

[Программа и регистрация](https://dovuz.innopolis.university/offline-programms/june-le-programms)

Программы третьей смены 6—19 июля:

— Олимпиадное программирование для 6—11 классов

— Python. Базовый уровень для 6—11 классов

— Разработка Telegram-ботов на Python для 8—11 классов

— Искусственный интеллект: от теории к применению для 9—11 классов

[Программа и регистрация](https://dovuz.innopolis.university/offline-programms/july-programms)
