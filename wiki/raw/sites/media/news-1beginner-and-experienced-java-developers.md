# Новый набор на онлайн-курсы для начинающих и опытных Java-разработчиков

> Страница относится к 2020 году: сведения на ней могли устареть.

27 января 2020

Обучение проведут специалисты Университета Иннополис. Курсы «Разработчик ПО с применением технологий Java Enterprise Edition» и «Основы промышленной разработки ПО на Java» начнутся в марте.

![](https://media.innopolis.university/upload/iblock/366/696061426.jpg)

Курс «Основы промышленной разработки ПО на Java» составлен для начинающих разработчиков и людей без опыта, желающих построить ИТ-карьеру. Занятия начнутся 16 марта и будут проходить 3 раза в неделю. За 3,5 месяца обучения участники научатся работать с базовым окружением, изучат структуру данных, алгоритмистику, рефакторинг и базы данных.

Стоимость обучения 56 тысяч рублей. Регистрация открыта до 16 марта: [https://stc.innopolis.university/Java-online](http://stc.innopolis.university/Java-online)

«Разработчик ПО с применением технологий Java Enterprise Edition» для разработчиков с опытом программирования от 1 года на Java, PHP, C++, C# или других языках с С-подобным синтаксисом. Обучение стартует 11 марта. В онлайн-формате в течение 4 месяцев участники пройдут 15 блоков, которые помогут углубить и систематизировать предметные знания, освоить практическое применение специализированных библиотек и фреймворков.

Стоимость обучения 64 тысячи рублей. Регистрация открыта до 11 марта: [http://stc.innopolis.university/JavaEE-online](http://stc.innopolis.university/JavaEE-online)

Выпускники обоих курсов получат удостоверение о повышении квалификации, сведения о котором вносятся в федеральный реестр документов об образовании.
