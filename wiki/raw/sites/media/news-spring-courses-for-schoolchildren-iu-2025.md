# ИТ-школа Университета Иннополис открыла регистрацию на весенние курсы для школьников

> Страница относится к 2025 году: сведения на ней могли устареть.

11 февраля 2025

24—28 марта «Прогматика» проведёт для учащихся 1—11 классов онлайн-обучение по программированию, разработке игр и кроссплатформенных приложений, 3D-моделированию, искусственному интеллекту и компьютерной грамотности. По итогам занятий слушатели создадут проекты для портфолио, получат сертификаты и вечный доступ к записям лекций. Регистрация открыта до 21 марта.

![](https://media.innopolis.university/upload/iblock/891/irnpu2xez2k3tfmlvamzvr523aay3nn3/mm0It1ht5oWmvoSVoSEIpkjayteN_zPX5zL31HXrP-jGlHaKxtnIMRLCLwS57MJ78yTXnNOAucB1VJMA4USWMQ==.jpg)

Интенсивы рассчитаны на 20 академических часов, включают проверку домашних заданий, обратную связь от преподавателей и итоговые проекты. Обучение доступно в двух форматах: ежедневные онлайн-уроки по расписанию или видеоуроки с поддержкой педагогов в Telegram-чате.

Направления обучения:

— Компьютерная грамотность для 1—4 классов

В программе интенсива — основы работы с компьютером, операционной системой и офисными программами. Слушатели узнают как безопасно пользоваться интернетом и сделают первые шаги в программировании.

— Разработка игр на Roblox для 3—6 классов

Школьники познакомятся со средой разработки Roblox, изучат базовый синтаксис программирования и научатся создавать сложные 3D-модели.

— Программирование на языке Python для 6—11 классов

Слушатели изучат основы языка программирования Python и смогут использовать его для решения разных задач, в том числе для разработки собственного итогового проекта — консольного приложения-магазина.

— Искусственный интеллект для 6—11 классов

Участники интенсива научатся писать запросы для нейросетей и применять искусственный интеллект в повседневных задачах.

— 3D-моделирование в Blender для 7—11 классов

Школьники изучат 3D-моделирование и текстурирование объектов в программе Blender, познакомятся с основными принципами проектирования, научатся работать с референсом, настраивать материалы, свет и камеру.

— Разработка кроссплатформенных приложений на Flutter для 8—11 классов

В программе курса — основы Flutter, создание с его помощью приложения для различных платформ и операционных систем и разработка приложение для Android и iOS.

Регистрация: [progmatica.innopolis.university/s_intensive25](https://progmatica.innopolis.university/s_intensive25)

При приобретении любых двух курсов на интенсив в формате видеоуроков доступна скидка 30%.
