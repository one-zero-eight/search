# Университет Иннополис открыл регистрацию на летние ИТ-интенсивы для школьников

> Страница относится к 2024 году: сведения на ней могли устареть.

6 июня 2024

ИТ-школа «Прогматика» приглашает учащихся 1—11 классов на онлайн-курсы по разработке игр на Roblox и кроссплатформенных приложений на Flutter, программированию на Python, 3D-моделированию в Blender, искусственному интеллекту, компьютерной грамотности. В конце обучения слушатели создадут свой проект для портфолио.

![](https://media.innopolis.university/upload/iblock/9cf/ymnqbhuon35hsx2k215akvws3oe47njb/IMG_5005.JPG)

Интенсивы доступны в двух форматах: ежедневные онлайн-уроки с преподавателем и самостоятельное изучение материала по видеоурокам с поддержкой преподавателя. По итогам слушатели получат сертификаты и доступ к записям уроков.

Направления обучения:

— Разработка игр на Roblox для 3—6 классов

Школьники познакомятся со средой разработки Roblox и изучат базовый синтаксис программирования. В программе: работа с переменными, циклами и функциями, создание сложных 3D-моделей и ресурсов для сбора для разработки проекта в Roblox.

— Программирование на языке Python для 6—11 классов

Слушатели изучат основы языка программирования Python и научатся использовать его для решения разных задач. В программе: знакомство с переменными, условиями, циклами и с коллекциями данных, работа с особым модулем для создания телеграм-бота.

— Искусственный интеллект для 6—11 классов

Учащиеся научатся писать запросы к нейронным сетям и применять ИИ в повседневных задачах. В программе: области использования и работа с нейронными сетями.

— 3D-моделирование в Blender для 7—11 классов

Участники интенсива изучат в программе Blender 3D-моделирование и текстурирование объектов, познакомятся с основными принципами проектирования, научатся работать с референсом, настраивать материалы, свет и камеру.

— Компьютерная грамотность для 1—4 классов

Школьники познакомятся с функционалом компьютера и освоят базовые навыки: работу с операционной системой, основы офисных программ, интернет-безопасность, основы алгоритмизации и программирования.

— Разработка кроссплатформенных приложений на Flutter для 8—11 классов

Слушатели изучат основы Flutter, научатся создавать приложения для разных платформ и операционных систем, а в завершении напишут собственное приложение для Android и iOS.

Первый поток обучения пройдёт с 8 по 14 июля, второй — с 12 по 18 августа. Присоединиться к видеоурокам можно в течение всего лета.
