# Разработка системы ассистирование хирургам во время операции и при подготовке к операции через смешанную реальность

Проект по разработке системы для визуализации данных пациента при подготовке и во время хирургической операции на базе смешанной реальности. Особенно важный функционал – пространственная визуализация 3Д-реконструкции органов пациента. В рамках проекта разработан программный комплекс для подготовки, хранения и визуализации данных пациента. Программный комплекс состоит из веб части, облачного хранилища и приложения для очков смешанной реальности HoloLens 2. Веб часть отвечает за загрузку и подготовку данных к визуализации моделей органов в очках. Сервер хранит и обрабатывает данные пациента и предоставляет доступ к ним. Приложение смешанной реальности отвечает за визуализацию данных и предоставляет бесконтактный интерфейс взаимодействия, основанный на жестах, что позволяет использовать приложение прямо в операционной.
