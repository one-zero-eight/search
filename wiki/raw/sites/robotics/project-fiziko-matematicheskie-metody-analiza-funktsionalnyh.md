# Физико-математические методы анализа функциональных связей головного мозга для диагностики моторных функций человека

[Вернуться](/raw/sites/robotics/projects.md)

![](https://robotics.innopolis.university/wp-content/uploads/2019/05/Nikita-Frolov-300x300.jpg)

Фролов Никита

руководитель проекта

| Финансирование: | Грант Президента РФ-МК |

| Статус: | Выполняется |

Настоящий проект направлен на проведение междисциплинарных научных исследований, основной целью которого является разработка новых методов анализа функциональных связей в распределенной нейронной сети коры головного мозга с упором на детектирование и диагностику состояний головного мозга, ассоциированных с двигательной активностью человека. Особое внимание в проекте будет уделено проведению серии нейрофизиологических экспериментов по регистрации электрической активности головного мозга и его гемодинамического отклика при выполнении испытуемым моторных функций по специально разработанному дизайну.

[Новые физико-математические методы, основанные на машинном обучении и рекуррентном анализе, для изучения нейронной активности человека при когнитивных процессах](/raw/sites/robotics/project-novye-fiziko-matematicheskie-metody-osnovannye-na-ma.md)
