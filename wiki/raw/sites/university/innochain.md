# Система распределенного реестра «InnoСhain»

![Семенихин](https://innopolis.university/upload/landing/672/photo_2020-06-02_10-02-44@2x.png)

[ЛИДИРУЮЩИЙ ИССЛЕДОВАТЕЛЬСКИЙ ЦЕНТР В ОБЛАСТИ СИСТЕМ РАСПРЕДЕЛЕННОГО РЕЕСТРА](/raw/sites/university/center-blockchain.md)

Система распределенного реестра «InnoChain» (далее - СРР «InnoChain») представляет собой программное обеспечение, которое устанавливается на каждый компьютер в сети для взаимодействия по специально разработанному протоколу на базе TCP/IP с целью обеспечения целостности и доступности общих данных. Таким образом система предназначена для использования в качестве базового слоя для работы децентрализованных приложений.

&nbsp;

## Функциональные возможности СРР «InnoChain»

## 01.

Создание пользовательского аккаунта

## 02.

Создание аккаунта администратора

## 03.

Блокировка/разблокировка аккаунтов пользователей администратором

## 04.

Управление набором публичных ключей, ассоциированных с аккаунтом

## 05.

Сохранение/изменение данных, ассоциированных с аккаунтом

## 06.

Загрузка смарт-контракта

## 07.

Вызов функций смарт-контракта
