# Browser extension

Extension

What is it?

InNoHassle Tools is a browser extension that provides convenient tools for Moodle, InNoHassle and other services at Innopolis University.

Features:

🔄 Autologin to Moodle without entering credentials

🔗 Quick links to your courses and IU resources

🔍 Integrated AI search engine for all Moodle materials

[Chrome extension](https://chromewebstore.google.com/detail/innohassle-tools/cbeffcchbpgcmaphbpnnnjbaighmobmn)

[Install the extension for Chromium-based browsers (Chrome, Edge, Yandex Browser, Arc) from the Chrome Web Store.](https://chromewebstore.google.com/detail/innohassle-tools/cbeffcchbpgcmaphbpnnnjbaighmobmn)

[Firefox extension](https://api.innohassle.ru/extension/latest-firefox.xpi)

[Install the extension for Firefox-based browsers from our servers (supports automatic updates).](https://api.innohassle.ru/extension/latest-firefox.xpi)

[GitHub](https://github.com/one-zero-eight/browser-extension)

[Check out the source code, report issues and contribute to the project on GitHub.](https://github.com/one-zero-eight/browser-extension)
