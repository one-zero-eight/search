# Синтез+| Как с помощью одного сервиса сделать дешевле и эффективнее геофизические исследования

![](https://static.tildacdn.com/tild3261-3834-4332-b363-356635373239/Frame_1119.png)

КЕЙС

Как с помощью одного сервиса сделать дешевле

и эффективнее бизнес-процессы компании

Делимся опытом разработки платформы, которая может заменить и объединить все корпоративные сервисы заказчика. Продукт «Синтез+» предназначен для автоматизации бизнес-процессов и эффективной коммуникации между подразделениями.

Рассказываем подробнее на примере нефтегазовой компании.

Задача

Работа на скважине начинается с геофизических исследований — ГИС. В процессе этих исследований на одном объекте в разное время могут трудиться около 100 человек различных специальностей, работа которых взаимосвязана между собой.

Раньше отчетность бригад происходила разрозненно: по телефону, в письмах

и корпоративных системах. Это затрудняло поиск необходимых данных, создавало накладки по времени в работе подрядчиков. Такие осложнения приводили к затягиванию сроков, простою оборудования и, как следствие, финансовым убыткам. Нефтегазовая компания обратилась к нам для решения этих проблем.

Решение «Синтез+»

Чтобы сделать коммуникацию прозрачной мы создали платформу «Синтез+», объединив корпоративные сервисы заказчика. При создании использовали стек технологий: Active MQ 5.15, Java 8, Spring Framework 5, Apache Camel 3.10, PostgreSQL 13.3, Tomcat 9, Nginx 1.18.

Платформа состоит из нескольких компонентов:

1. Интеграционная шина — помогает собирать данные

из разных источников, трансформировать

их в необходимый вид и передавать в нужные процессы и системы, обеспечивая обмен информацией между всеми системами предприятия.

2.Система автоматизации бизнес-процессов — low-code система управления процессами (BPMS)

для описания последовательности выполнения работ и формирования инструкций. Увеличивает скорость работы, повышает прозрачность и предсказуемость рабочих процессов.

3.Система аналитики производственной деятельности и отчетности — дает возможность

в реальном времени отображать информацию

по производственным процессам в графическом представлении дашбордов, а также быстро создавать функциональные и эффективные отчеты для широкого круга пользователей.

![](https://static.tildacdn.com/tild3339-3735-4566-b339-646664356532/noroot.jpg)

«Синтез+» помогает оптимизировать работу предприятия, повышает эффективность бизнес-процессов, сокращает затраты и улучшает контроль над выполнением задач

для достижения ключевых показателей предприятия.

Платформа решает задачи:

- Сокращение затрат человеческих ресурсов на выполнение рутинных операций (калькуляция, отчеты, документооборот)

- Оценка, стандартизация и повышение эффективности имеющихся процессов

- Анализ целевых показателей и выдача рекомендаций о производственных процессах

- Создание единого информационного пространства с полной и достоверной информацией о деятельности компании

Доработка платформы

под нефтегазовую компанию

Одно из преимуществ решения «Синтез+» — его легко дополнить специализированными блоками под нужды разных отраслей. Так, для задач нефтегазовой компании мы создали ряд модулей, среди которых: прогноз и оценка технического состояния скважин, автоматизация заполнения заявок на проведение ГИС, подбор скважин для геолого-технологических мероприятий, оцифровка аналогового каротажа, онлайн диспетчерская.

Теперь данные, связанные с подготовкой к ГИС, а также результаты исследований автоматически поступают, обрабатываются и хранятся в платформе «Синтез+». Также здесь есть автоматические шаблоны, возможность быстро визуализировать данные

и другие опции, которые экономят время сотрудников и снижают человеческий фактор.

Мы достигли поставленной задачи на двух уровнях: сделали эффективнее работу подрядчиков и снизили операционные затраты заказчика.

![](https://static.tildacdn.com/tild3636-3437-4532-a465-343332633061/Artboard_2_copy_5.png)

Преимущества «Синтез+»

в работе нефтегазовой компании:

1. Каждый участник команды владеет всей информацией по скважине. Он знает, какие работы ведутся сегодня и какие будут результаты. Это способствует лучшему планированию.

2. Бригада и оборудование используются в полную силу. Не будет простоя и связанных

с ним расходов — в сервисе есть понятный каждому график, когда выходить.

3. Заявка на геофизические исследования оформляется в два клика. Достаточно зайти

в сервис и заполнить нужные поля. Документооборот упрощается.

4. Акты на работы формируются автоматически вместе с запросом на ГИС.

5. Нет ограничений по интеграции сервисов. Подключить можно сколько угодно сторонних приложений, они будут синхронизироваться внутри платформы.

Эффекты от внедрения

30%

снижение непроизводительного времени рабочих бригад при разработке месторождений

50%

снижение холостых выездов

25%

автоматизация операционных функций специалистов при реализации ГИС

Развитие проекта

Мы продолжаем дорабатывать продукт под задачи нефтегазового сектора. Например, внедряем систему аналитики производственной деятельности и отчетности, функционал которой включает: мониторинг данных по ключевым показателям, прогнозирование тенденций ГИС, автоматизацию лабораторных исследований.

Сейчас работаем над блоком предиктивной аналитики для прогнозирования ремонта скважины, чтобы осуществлять ремонт по мере необходимости, а не по усредненным нормативам. Таким образом, поможем экономить время и деньги заказчика, сохраняя безопасность.

В будущем предполагаем тиражировать решение «Синтез+» под разные отрасли: функционал актуален для любых компаний, где много сотрудников, процессов и информации.
