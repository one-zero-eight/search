# Учебный план [2._Учебный_план_ПП_Программная_инженерия_и_новые_технологии]

УТВЕРЖДЕНО приказом АНО ВО «Университет Иннополис» от 13 февраля 2023 года № ОД/ДПО-15/2023/02/13 Директор МЭПБариев И.И. Бариев Учебный план программы профессиональной переподготовки «Программная инженерия и новые технологии разработки ПО» Объем Программы составляет 256 часов. Учебный план Программы определяет перечень, последовательность, общую трудоемкость разделов и формы контроля знаний. Образовательная деятельность слушателей предусматривает следующие виды учебных занятий и учебных работ:

| - лекции; |
| --- |
| - семинары (практические занятия); |
| - самостоятельная работа; |
| - итоговая аттестация (в форме защиты выпускной аттестационной |
| (квалификационной) работы - защиты проектной работы). |
