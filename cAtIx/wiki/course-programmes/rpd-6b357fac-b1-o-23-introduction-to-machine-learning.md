## 1. Краткая характеристика дисциплины (модуля)

Дисциплина (модуль) «Introduction to Machine Learning / Введение в машин- ное обучение» посвящена изучению фундаментальных парадигм, алгоритмов и ма- тематических основ машинного обучения, являющихся базой для создания систем искусственного интеллекта. Курс охватывает весь спектр классических методов обу- чения с учителем (Supervised Learning) и без учителя (Unsupervised Learning), а также вводит в основы глубокого обучения (Deep Learning). В ходе освоения дисциплины обучающиеся изучают линейные модели, ме- тод опорных векторов (SVM), деревья решений и ансамблевые методы (бэггинг, бу- стинг), а также алгоритмы кластеризации. Особое внимание уделяется методологии построения ML-пайплайнов: от предобработки данных и отбора признаков до оценки качества моделей, борьбы с переобучением и настройки гиперпараметров. Практическая часть курса реализуется на языке Python с использованием современ- ных библиотек (Scikit-learn, PyTorch). Требования к «входным» знаниям, умениям и навыкам: Изучение дисци- плины базируется на компетенциях, сформированных в ходе освоения следующих дисциплин: «Probability and Statistics / Теория вероятности и статистика» - знание байесовского вывода, распределений и проверки гипотез необходимо для понима- ния вероятностных моделей ML; «Introduction to Optimization / Введение в оптими- зацию» - понимание градиентного спуска и выпуклой оптимизации критически важно для обучения нейросетей и линейных моделей; «Linear Algebra / Линейная алгебра» - операции с матрицами и векторами лежат в основе всех вычислений в ML (Vectorization); «Introduction to Programming / Введение в программирование» - уверенное владение Python и библиотеками NumPy/Pandas. Дисциплины, для кото- рых данная дисциплина является предшествующей: Компетенции, знания и навыки, приобретенные в результате освоения дисциплины «Введение в машинное обуче- ние», являются необходимой базой для: «Big Data Technologies and Analytics / Тех- нологии и анализ больших данных» - масштабирование алгоритмов ML (Spark MLlib) требует понимания их работы на одной машине; «Practicum Project / Прикладной проект» - для реализации интеллектуальных компонентов в командных проектах; «Game Theory / Теория игр» - алгоритмы обучения с подкреплением (RL) для муль- тиагентных систем которые используют концепции ML.

Для применения теоретических знаний на практике, а также для развития критического мышления и навыков решения реальных проблем обучающимся предлагаются кейсы, разработанные партнерскими организациями. Примеры кейсов представлены ниже:

**1.** Прогнозирование оттока абонентов (churn prediction) на основе данных об использовании услуг Описание: для телеком-оператора критически важно удерживать абонентов. Необходимо построить модель, которая на основе исторических данных (актив- ность, трафик, обращения в поддержку, платежная дисциплина) предсказывает ве- роятность того, что конкретный абонент расторгнет договор в течение следующего расчетного периода. Это позволит запускать для «группы риска» целевые про- граммы лояльности. Цель: провести полный цикл ML-проекта: ETL данных, feature engineering (со- здание признаков, например, «снижение активности за последний месяц»), обуче- ние моделей бинарной классификации (логистическая регрессия, случайный лес, градиентный бустинг). Оценить модели по метрикам Precision, Recall, AUC-ROC и бизнес-метрикам (стоимость удержания vs. потери от оттока). Определить наибо- лее важные признаки, влияющие на отток.

**2.** Классификация типов сетевого трафика (VoIP, Streaming, Browsing, P2P) для обеспечения качества обслуживания (QoS) и выявления аномалий Описание: для приоритизации критического трафика (например, видеозвон- ков) и обнаружения нехарактерной активности (возможные атаки) необходимо ав- томатически классифицировать типы трафика на основе статистических признаков пакетов (размер пакетов, интервалы между ними, продолжительность потока), не прибегая к глубокому анализу содержимого (Deep Packet Inspection) из-за приват- ности. Цель: на основе открытого датасета сетевого трафика (например, UNSW-NB15 или собранного в симуляторе) извлечь признаки из сетевых потоков. Обучить мо- дель многоклассовой классификации (например, Random Forest или XGBoost) для определения типа сервиса/приложения. Оценить точность модели, особенно на смешанном трафике. Проанализировать, какие признаки наиболее значимы для различения, например, VoIP и стримингового видео.

**3.** Обучение модели линейной регрессии для прогнозирования стоимости до- мов на основе их характеристик (датасет Boston Housing или California Housing) Описание: Классическая задача регрессии. На основе таких характеристик дома, как средний доход в районе, количество комнат, возраст дома, необходимо построить модель, предсказывающую его медианную стоимость. Цель: реализовать метод наименьших квадратов для нахождения парамет- ров линейной модели. Провести предобработку данных (масштабирование призна- ков). Оценить качество модели с помощью метрик MSE, RMSE, R². Визуализировать зависимость предсказаний от истинных значений и остатки (residual plots). Исследо- вать влияние выбросов на модель.

**4.** Построение модели k ближайших соседей (k-NN) для задачи классифика- ции изображений рукописных цифр (MNIST) Описание: Алгоритм k-NN - один из простейших и интуитивно понятных алго- ритмов классификации. Его можно применить для распознавания рукописных цифр, представляя каждое изображение (28x28 пикселей) как точку в 784-мерном про- странстве. Цель: реализовать алгоритм k-NN «с нуля» (или с использованием библиотек для вычисления расстояний). Поэкспериментировать с различными метриками рас- стояния (Евклидово, Манхэттенское, косинусное). Исследовать влияние параметра k и метрики на точность классификации на тестовой выборке датасета MNIST. По- строить график зависимости точности от k. Визуализировать случаи, когда алгоритм ошибается.

Видеопрезентации продолжительностью около 5 минут (300 се- кунд) должны быть подготовлены в группах, определяемых преподавателем. Не- смотря на то, что это групповая работа, должен явно присутствовать вклад каждого члена группы. |
| Доклад | Публичное, развернутое сообщение по определенной теме или вопросу, основан- ное на документальных данных. При подготовке доклада рекомендуется использо- вать разнообразные источники, позволяющие глубже разобраться в теме. Учебную литературу можно найти в электронных библиотечных системах, на которые подпи- сан АНО Университет Иннополис. |
| Дискуссия | Публичное обсуждение спорного вопроса, проблемы. Каждая сторона должна оп- понировать мнение собеседника, аргументируя свою позицию. |
| Контрольная работа | При подготовке к контрольной работе необходимо проработать материалы лекций, семинаров, основной и дополнительной литературы по заданной теме. |
| Тестирование (уст- ное/письменное) | При подготовке к тестированию необходимо проработать материалы лекций, семи- наров, основной и дополнительной литературы по заданной теме. Основная цель тестирования – показать уровень сформированности знаний по конкретной теме или ее части. |
| Индивидуальная ра- бота | При выполнение индивидуальной работы необходимо взять задание у преподава- теля, ознакомиться с требованиями к выполнению работы, изучить поставленную проблему, найти решение проблемы. Если самостоятельно не удается разобраться в материале, необходимо сформулировать вопрос и задать преподавателю на кон- сультации, во время семинарского (практического) занятия. Оформить результаты работы. |
| Разработка отдельных частей кода | Разработать часть кода, исходя из поставленной задачи и рекомендаций препода- вателя. При выполнении работы рекомендуется обращаться к материалам лекций и семинарских (практических) занятий. Если возникают затруднения, необходимо проконсультироваться с преподавателем. |
| Выполнение домаш- них заданий и группо- вых проектов | Для выполнения домашних заданий и групповых проектов необходимо получить формулировку задания от преподавателя и убедиться в понимании задания. При выполнение домашних заданий и групповых проектов необходимо проработать ма- териалы лекций, основной и дополнительной литературы по заданной теме. |

Для подготовки к занятиям рекомендуется использовать представленные ис- точники в электронных форматах и дополнительную литературу.
