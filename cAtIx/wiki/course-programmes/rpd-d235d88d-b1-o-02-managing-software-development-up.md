## 1. Краткая характеристика дисциплины (модуля)

Изучение дисциплины (модуля) «Managing Software Development / Управление разработкой ПО» обеспечивает формирование и развитие компетенций обучающихся в области управления процессом разработки программного обеспечения, в частности управление содержанием проекта, сроками, качеством, человеческими ресурсами, коммуникациями, рисками, поставками, их применение для решения различных прикладных задач в рамках профессиональной деятельности. В ходе освоения дисциплины обучающиеся получают навыки составления плана управления проектом разработки программного обеспечения, понимания циклов разработки программного обеспечения.

## 2. Перечень планируемых результатов обучения

Задачами дисциплины являются изучение стандартов и жизненных циклов разработки программного обеспечения, принципов управления человеческими ресурсами, составление плана управления проектами.
