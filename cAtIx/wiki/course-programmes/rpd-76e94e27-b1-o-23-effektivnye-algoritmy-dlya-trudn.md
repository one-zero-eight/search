## 1. Краткая характеристика дисциплины (модуля)

Дисциплина (модуль) «Эффективные алгоритмы для труднорешаемых задач» занимает центральное место в формировании алгоритмической культуры выпускников программы AI360, готовя их к ролям Исследователя машинного обучения и Архитектора систем искусственного интеллекта. Курс направлен на развитие двух ключевых компетенций. В рамках ПК-1 студенты овладевают методами анализа вычислительной сложности (классы P, NP, BPP, PSPACE) и разработки приближенных и вероятностных алгоритмов для задач, возникающих при оптимизации нейросетевых моделей и работе с большими данными (индикаторы ПК-1.1, ПК-1.2). Компетенция ОПК-1 реализуется через формирование способности применять строгие математические модели (машины Тьюринга, RAM-модели) и методы дерандомизации для решения профессиональных задач, требующих оценки временной и пространственной эффективности программных решений (индикатор ОПК-1.1). Содержание дисциплины охватывает широкий спектр подходов к решению NP- трудных задач. Изучаются полиномиальные сводимости (по Куку и Карпу), жадные алгоритмы с оценкой качества (для задач покрытия и рюкзака), полностью полиномиальные аппроксимационные схемы (FPTAS), а также алгоритмы, полиномиальные в среднем. Особое внимание уделяется вероятностным методам (алгоритмы Монте-Карло, Лас-Вегас, вероятностное округление для MAX-SAT и MAX- CUT) и техникам дерандомизации, позволяющим преобразовывать стохастические алгоритмы в детерминированные. Рассматривается также теория PCP (вероятностно проверяемых доказательств) и границы аппроксимируемости, что критически важно для понимания теоретических пределов эффективности алгоритмов ИИ. Для успешного изучения дисциплины обучающимся необходимо: обладать глубокими знаниями дискретной математики (теория графов, комбинаторика) и теории вероятностей (случайные величины, марковские неравенства); владеть основами теории алгоритмов и структур данных; иметь навыки программирования на Python для реализации приближенных алгоритмов и использования современных инструментов оптимизации (солверы Pyomo, SAT-солверы).

Для применения теоретических знаний на практике, а также для развития критического мышления и навыков решения реальных проблем обучающимся предлагаются кейсы, разработанные партнерскими организациями. Примеры кейсов представлены ниже:

**1.** Оптимизация размещения банкоматов и отделений в городской сети (Задача о p-медиане) Описание: Банк планирует открыть N новых точек (банкоматов или отделений) в городе с целью минимизировать среднее расстояние от клиентов (проживающих в районах с известной плотностью) до ближайшей точки. Потенциальных мест для размещения - M, расстояния между всеми районами и точками известны. Цель: сформулировать задачу как NP-трудную задачу о p-медиане. Применить метаэвристический алгоритм (например, метод имитации отжига или генетический алгоритм) для поиска субоптимального набора из N точек. Оценить качество решения по сравнению с жадной эвристикой (последовательный выбор точки, максимально уменьшающей среднее расстояние).

**2.** Задача упаковки виртуальных машин на физические серверы в облачном дата- центре (Bin Packing с ограничениями) Описание: для экономии энергии и ресурсов необходимо разместить набор виртуальных машин (ВМ) с разными требованиями к CPU, RAM и дисковому пространству на минимальном количестве физических серверов (хостов), у каждого из которых есть ограничения по этим ресурсам. ВМ нельзя делить между серверами. Цель: сформулировать задачу как многомерную задачу об упаковке в контейнеры (Multidimensional Bin Packing). Реализовать и сравнить эвристические алгоритмы: First- Fit Decreasing (FFD) по доминирующему ресурсу и более продвинутые метаэвристики. Цель - минимизировать количество задействованных хостов при соблюдении всех ограничений.

**3.** Составление оптимального расписания сдачи студенческих проектов (Задача раскраски графа) Описание: Группа студентов должна защитить индивидуальные проекты перед комиссией. Каждый член комиссии может оценивать только определенный набор проектов (по своей специализации). Необходимо составить расписание защит, минимизирующее общее количество временных слотов, так чтобы у членов комиссии не было наложений, а у студентов - только одна защита. Цель: представить задачу как задачу раскраски вершин графа, где вершины - проекты, а ребро между двумя вершинами существует, если для их оценки требуется общий член комиссии. Применить жадный алгоритм раскраски (например, с упорядочиванием вершин по убыванию степени) и оценить полученное хроматическое число. Сравнить с нижней оценкой (размер максимальной клики).

**4.** Выбор наиболее информативного подмножества признаков для модели при ограничении на стоимость вычислений (Упрощенная задача о рюкзаке) Описание: при развертывании ML-модели в production важен баланс между точностью и временем/стоимостью предсказания. Каждый признак имеет «цену» (время извлечения/вычисления) и «ценность» (вклад в точность модели, оцененный через feature importance). Общий бюджет на инференс ограничен. Цель: сформулировать задачу выбора подмножества признаков как задачу о рюкзаке 0/1, где вес - стоимость признака, ценность - его важность. Решить задачу для небольшого числа признаков с помощью динамического программирования. Для большего набора признаков применить жадный приближенный алгоритм (выбор по соотношению ценность/вес) и оценить потерю в точности относительно оптимального решения.

| B «Хорошо» | Обучающийся владеет знаниями предмета практически в полном объеме рабочей программы; самостоятельно, в логической последовательности и исчерпывающе отвечает на все вопросы, подчеркивая при этом самое существенное, умеет анализировать, сравнивать, классифицировать, обобщать, конкретизировать и систематизировать изученный материал, выделять в нем главное: устанавливать причинно-следственные связи; четко формирует ответы, свободно читает результаты анализов и других исследований и решает ситуационные задачи повышенной сложности; хорошо знаком с основной литературой и методами исследования большого объема, необходимым для практической деятельности; увязывает теоретические аспекты предмета с задачами практического значения. |
| C «Удовлетворительно» | Обучающийся владеет основным объемом знаний по дисциплине; проявляет затруднения в самостоятельных ответах, оперирует неточными формулировками; в процессе ответов допускаются ошибки по существу вопросов. Студент способен решать лишь наиболее легкие задачи, владеет только обязательным минимумом методов исследований. |
| D «Неудовлетворительно» | Обучающийся не освоил обязательного минимума знаний предмета, не способен ответить на вопросы даже при дополнительных наводящих вопросах преподавателя. |

Также необходимо продемонстрировать работающий код выполненного проекта преподавателю для получения обратной связи и оценки, а также вносить правки в свою работу на основе комментариев преподавателя. Все написанные коды, созданные файлы проектов, скрипты должны быть сохранены. Также необходимо конспектировать советы преподавателя, лучшие практики, которые не были очевидны до занятия. |
