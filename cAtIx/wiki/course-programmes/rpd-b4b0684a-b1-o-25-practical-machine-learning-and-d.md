## 1. Краткая характеристика дисциплины (модуля)

Изучение дисциплины (модуля) «Practical Machine Learning and Deep Learning / Прикладные технологии машинного и глубокого обучения» обеспечивает формирование и развитие компетенций обучающихся в области программного обеспечения компьютерных вычислительных систем и сетей, автоматизированных систем обработки информации и управления с использованием вычислительных методов, их применение для решения различных прикладных задач в рамках профессиональной деятельности. В ходе освоения дисциплины обучающиеся рассматривают различные теоретические основы машинного и глубокого обучения и алгоритмы для решения прикладных задач, таких как распознавание текстов и изображений. Формируемые профессиональные компетенции: ПК-4. Способен применять и (или) разрабатывать архитектуры глубоких нейронных сетей, современные архитектуры генеративных глубоких сетей, алгоритмы, методы и технологии компьютерного зрения, технологии обработки естественного языка. Для успешного изучения дисциплины обучающимся необходимо освоить курс машинного обучения, владеть основами алгоритмов и структур данных и иметь навык программирования на языке python.

Для применения теоретических знаний на практике, а также для развития критического мышления и навыков решения реальных проблем обучающимся предлагаются кейсы, разработанные партнерскими организациями. Примеры кейсов представлены ниже:

**1.** Построение пайплайна для прогнозирования пиковой нагрузки на сетевые элементы (BRAS, агрегаторы) с использованием LSTM/Transformer Описание: для предотвращения деградации качества услуг и планирования ресурсов необходимо прогнозировать нагрузку (трафик, количество сессий) на ключевых сетевых устройствах. Нагрузка имеет сложную временную структуру: суточные, недельные, сезонные циклы, влияние праздников. Необходимо построить модель, способную уловить эти долгосрочные зависимости. Цель: собрать и подготовить временные ряды исторической нагрузки. Разработать и обучить модель прогнозирования на несколько шагов вперед (например, на 24 часа), используя архитектуры для временных рядов: LSTM, GRU или Transformer (например, Informer). Внедрить пайплайн регулярного ретренинга модели и инференса. Оценить качество прогноза с помощью метрик RMSE, MAE и сравнить с простыми baseline-моделями (скользящее среднее, Prophet).

**2.** Разработка системы семантической сегментации спутниковых/аэрофотоснимков для инвентаризации и мониторинга объектов телеком- инфраструктуры Описание: для актуализации карт сети, планирования строительства и анализа зон покрытия необходимо автоматически находить и классифицировать объекты инфраструктуры на спутниковых снимках и данных ДЗЗ: вышки сотовой связи, опоры ЛЭП, телеком-здания, а также выделять области с различным типом земного покрова (лес, город, поле), влияющими на распространение сигнала. Цель: подготовить датасет с размеченными снимками. Обучить модель семантической сегментации (архитектуры U-Net, DeepLabV3+ с предобученным бэкбоном) для присвоения каждому пикселю класса. Решить проблему несбалансированности классов (редкие объекты, такие как вышки). Оценить качество по метрике IoU (Intersection over Union) для каждого класса. Интегрировать модель в геоинформационную систему (ГИС) для визуализации результатов.

**3.** Fine-tuning предобученной сверточной нейронной сети (например, ResNet50) для задачи классификации изображений собак и кошек Описание: Обучение CNN с нуля на небольших датасетах часто приводит к переобучению. Трансферное обучение позволяет использовать знания, полученные моделью на огромном датасете ImageNet, и адаптировать её для конкретной задачи с малым объемом данных. Цель: взять предобученную на ImageNet модель ResNet50. «Заморозить» веса её начальных сверточных слоев (которые извлекают общие признаки), заменить и обучить только последние полносвязные слои на датасете «Cats vs Dogs». Сравнить точность и время обучения с моделью, обученной с нуля. Поэкспериментировать с разными стратегиями: fine-tuning всех слоев или только части.

**4.** Создание текстовой модели с вниманием (Attention) для задачи суммаризации новостных статей Описание: Задача генеративного суммаризации (abstractive summarization) состоит в создании краткого, связного резюме исходного текста, а не просто в выделении ключевых предложений. Архитектура Encoder-Decoder с механизмом внимания позволяет модели «фокусироваться» на разных частях исходного текста при генерации каждого слова итоговой выжимки. Цель: реализовать модель на основе RNN (GRU/LSTM) или трансформера с механизмом внимания. Обучить её на датасете пар «статья — аннотация» (например, CNN/Daily Mail). Использовать техники teacher forcing и beam search при генерации. Оценить качество суммаризации с помощью метрик ROUGE и визуального сравнения с человеческими аннотациями.

Также необходимо продемонстрировать работающий код выполненного проекта преподавателю для получения обратной связи и оценки, а также вносить правки в свою работу на основе комментариев преподавателя.
