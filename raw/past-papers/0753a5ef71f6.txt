(a) Adding more polynomial terms
(b) Using Ridge Regression (L2 regularization)
(c) Using Lasso Regression (L1 regularization)
(d) Increasing the number of features
Answer: (b) Using Ridge Regression (L2 regularization)
Explanation:
Multicollinearity occurs when two or more predictor variables in a linear
regression model are highly correlated with each other, which can lead to unreliable estimates of the regression coefficients. In such situations, the model’s
coefficients can become very sensitive to small changes in the data, causing issues
in interpretation and prediction. To mitigate this, regularization techniques are
commonly used.
Option Breakdown:
(a) Adding more polynomial terms
False - Adding more polynomial terms (i.e., creating more complex features)
can exacerbate the problem of multicollinearity, especially when the new terms
are highly correlated with the existing features. This doesn’t solve the issue;
rather, it may increase it by introducing even more multicollinearity.
(b) Using Ridge Regression (L2 regularization)
True - Ridge Regression (L2 regularization) is a technique designed to address multicollinearity by adding a penalty term to the linear regression cost
function proportional to the square of the magnitude of the coefficients. This
penalty shrinks the coefficients towards zero, which helps stabilize the model
when predictors are highly correlated. Ridge regression can handle multicollinearity by reducing the impact of correlated features.
(c) Using Lasso Regression (L1 regularization)
True - Lasso Regression (L1 regularization) also helps with multicollinearity,
but in a different way. Lasso adds a penalty term proportional to the absolute
value of the coefficients. This regularization can shrink some coefficients exactly
to zero, effectively performing feature selection. In cases of multicollinearity,
Lasso tends to select one feature from a group of correlated features and set the
others to zero, helping to reduce redundancy in the model.

instances correctly, which implies that it is making very few false negatives

which the data varies the most. These directions are chosen such that they are
orthogonal (perpendicular) to each other. PCA transforms the original dataset
into a new coordinate system where the axes are the principal components, and
the variance of the data along each component is maximized.
