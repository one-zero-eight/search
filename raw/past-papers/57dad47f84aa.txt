while i < A.size():

if A.get(i) == A.get(j):
A.remove(j)

j = j + 1

Solution. We can solve this problem recursively, by considering, for each
region, how many teams we will send there. The subproblems will take as
input the number of leftover teams and number of regions we consider. To
solve a problem with 5 teams and 3 regions (A, B, C) we need to consider
subproblems with k teams and 2 regions (A, B) for all k from 0 to 5. For each
k we need to compute solution of the subproblem and add to that value the
estimated performance of sending n − k teams to region C. Out of 6 options
we will choose the maximum one and that will give us the solution.
Bottom-up implementation for the algorithm:
# M — number of available medical teams
# R — number of regions
# E is a given R×(M+1) array with estimated performance
solve(E, M, R)
A = new R×(M+1) array
for i from 0 to R-1:
for j from 0 to M:
if i == 0:
A[i][j] = E[i][j]
else:
max_performance = A[i-1][j]
for k from 0 to j-1:
performance = A[i-1][k] + E[i][M-k-1]
if performance > max_performance:
max_performance = performance
A[i][j] = max_performance
return A[R-1][M-1]
Let M be the number of available teams and R — the number of regions to
consider. Then for each cell in an M × R table, we will compute its value
in O(M ) time since we will compare M + 1 solutions. This means that the
overall complexity of Dynamic Programming algorithm will be O(M 2 R).
Applying the algorithm to the instance of the problem above we get maximum
performance of 170:
