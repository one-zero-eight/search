Question 5. (2 points) What is the key purpose of the Network Address Translation (NAT) mechanism, and
what does the term “translation” actually mean? For a diagram below, which illustrates the key steps of
the NAT translation, fill-in the “Source” (S) and “Destination” (D) addresses for the packets at steps 2,3,
and 4.
Answer for Key NAT purpose:
The NAT mechanism allows to use a single public IP address for identifying a private network hidden
behind a NAT-enabled router.
The meaning of “translation”: private IP addresses are translated into public IP address(-es) through using
a NAT translation table typically managed by a NAT-enabled gateway router.
