Question 1. (1 point) What information is used by a process running on one host to communicate
(over the network) with another process running on another host?
Solution: The IP address of the destination host and the port number of the socket in the destination
process.

Question 4. (1 point) Describe at least one key service provided by the Domain Name System (DNS)
of the Internet.
Solution: DNS provides IP address/hostname resolution (translation), host aliasing, and load
balancing. (Mentioning at least one of the three services is sufficient).

Question 5. (2 points) Do FTP, SMTP, and HTTP application-layer protocols run on top of TCP or
UDP transport layer protocol? Why media streaming protocols, such as Voice-over-IP (VoIP) or the
ones used for streaming videos run on the top of a different transport layer protocol? Provide a
brief explanation.
Solution:
FTP, SMTP, and HTTP protocols run on top of TCP, while media streaming protocols run on top of UDP
instead (1 point).
The applications associated with FTP, SMTP, and HTTP protocols require that all application data be
received in the correct order and without gaps (HTTP/3 is an exception). TCP provides this service
whereas UDP does not. For media streaming protocols, some data loss (such as a video frame) is
tolerable .

Question 7. (3 points) Describe at least three major differences between HTTP and FTP application
layer protocols.
Some correct answers:
- FTP is used for file transfer, while HTTP is used mainly for retrieving web pages.
- FTP uses two TCP connections, while HTTP uses only one TCP connection
- FTP is less widely used, while HTTP is in wide use.
- HTTP uses port 80, while FTP uses port 20 and 21
* Mentioning other correct differences is also accepted.
