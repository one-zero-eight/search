Question 6. (2 points) Illustrate graphically the architecture of a router with its five key components.
For each component, specify at least one its key function.
Answer:
The diagram:

The functions description of router components:
5 key components of a router:
- Input lines
- Output lines
- Switching fabric
- Router processor (CPU)
- Forwarding table
Input Link Functions:
- Storing arriving data packets into its local buffers (physical link termination function);
- Data extraction from packet header (de-encapsulation);
- Determination of appropriate output links;
- Verification of packets correctness (typically limited to packet headers, by using checksum
method);
- Control of Time-to-Live (the maximum number of routers, or hops, allowed to pass through);
- Collecting statistics;
Switching Fabric function:
to propagate data packets from input to output ports (connection)
Routing Processor functions:
- Maintenance of forwarding tables;
- Execution of routing protocols;
- Other management functions
Forwarding Table function:
To provide data/information for a lookup process, forwarding function implementation, and similar
Output Link functions:
- To store packets received from a switching fabric into a local buffer;
- To encapsulate necessary data into packet headers;
- To transmit packets from a buffer into a physical link
