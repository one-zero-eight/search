Question 5. (1 point) What data is needed to identify a network process running on a remote host?
Why an IP address of a remote host is not sufficient?
Answer:
An IP address + the port number of a network process;
The IP address of a network host is not sufficient in case of multiple network processes running on
the same host; thus, the port is used as an additional identifier for a process.
Grading:
(+0.5) for mentioning the port identifier of a process;
