## Разработка модульной системы дистанционного и автономного управления коммерческим транспортом совместно с комплексом аэроразведки маршрута движения на базе отечественных компонентов
![](https://robotics.innopolis.university/wp-content/uploads/2019/05/Klimchik-Aleksandr-300x300.jpg)
Климчик Александр
руководитель проекта
| Партнеры: | KAMAZ |
| --- | --- |
| Финансирование: | FTP |
| Лаборатория: | [Лаборатория автономных транспортных систем](https://robotics.innopolis.university/?post_type=labs&p=96) |
| Статус: | Завершен |
Основная проблема, на решение которой направлен реализуемый проект, заключается в обеспечении безопасности дорожного движения автомобильных транспортных средств с использованием автоматизированных процессов управления ТС. Научная новизна предлагаемого проекта заключается в быстросъёмном модуле автономности для грузового транспорта с функцией аэроразведки, который позволяет получить трёхмерную карту местности с помощью БПЛА для беспилотного грузового автомобиля, что позволяет внести существенный вклад в решение задач по автоматизации процессов управления транспортными средствами
