## Разработка системы и алгоритмической базы для интерактивного управления роботами через интерфейсы дополненной, смешанной и виртуальной реальности
![](https://robotics.innopolis.university/wp-content/uploads/2019/05/Mihail-Ostanin-2-300x300.jpg)

Проект по разработке многопользовательской системы для взаимодействия с роботами и группами роботов основанная на технологиях дополненной, смешанной и виртуальной реальности. Цель – создания нового интерфейса между человеком и роботом. В рамках проекта разработан программный комплекс для управления коллаборативными роботами через очки смешанной реальности. В него входит приложения для очков Microsoft HoloLens 2, модуль планирования траектории на базе ROS и контролеры роботов UR10e и KUKA IIWA. Программный комплекс позволяет программировать роботов при помощи голографического интерфейса в очках HoloLens 2, c возможностями визуализации состояния робота, воспроизведения виртуальной симуляции движения в смешанной реальности, автоматической построения траектории в обход препятствий.
