Описание процесса изготовления оснастки для литья с помощью ПАК ИМО:

  • ● Экспорт модели детали в ПАК ИМО для изготовления литейной оснастки.
  • ● Формирование оптимальной заготовки (с точки зрения использования материала) из кубиков модельного пластика размером 100x100.
  • ● Передача полученной заготовки на участок сборки на участок фрезерования.
  • ● Формирование исполнительной программы для операции фрезерования.
  • ● Фрезерование детали из заготовки.
