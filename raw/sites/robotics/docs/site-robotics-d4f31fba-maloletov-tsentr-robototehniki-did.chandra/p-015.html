Коллаборативная робототехника

DID

Цель проекта:

Определение точки приложения внешней силы по информации с внутренних силомоментных датчиков. Аналог «искусственной кожи». За счет использование информации о геометрии поверхности и усилия в суставах для локализации в точке воздействия.

Результаты проекта могут быть использованы:

  1. 1. Для корректировки конфигурации коллаборативного робота при движении в сложной окружающей среде.
  2. 2. Для создания интерфейса взаимодействия робота. Анализ тактильных воздействий на робота для управления его поведением.
