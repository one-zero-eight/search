В настоящий момент в робототехнике нет операционной системы роботов, предназначенной для использования
разнообразными роботами (в парадигме «готовое решение из коробки», принятой в ИТ-индустрии). В большинстве
случаев используются open-source фреймворки, включающие набор программных библиотек и средств разработки и
моделирования робота, например, ROS (Robot Operating System, 2007). Также имеются проприетарные системы с
закрытым кодом (BrainOS).
Примеры:

• ROS (для академических исследований)

• ROS-2 (для индустрии, включая IoT)

• OROCOS

• OpenCOG (для робота Софии)

• NAOQI (для робота NAO)

• BrainOS (для роботов от BrainCorp)

Цель проекта по разработке ОС xoRDE
Цель проекта

✓Разработка операционной системы роботов с поддержкой технологий самообучения на
основе Искусственного Интеллекта (ОСР-ИИ).

✓Создание такой ОС, которую могут использовать разработчики с минимальными навыками
программирования, например, с использованием графического редактора для соединения
компонентов программы.

✓Такую ОСР-ИИ можно будет использовать на роботах различных производителей с
различными кинематическими и динамическими свойствами, без сложного процесса
разработки специализированного программного обеспечения для конкретного робота.

Достижимый эффект

✓Появление такой ОСР-ИИ в робототехнике будет иметь эффект, схожий с появлением ОС UNIX
на рынке компьютеров – стандартизация, снижение порога входа на рынок для новых игроков
и стимулирование развития отрасли робототехники в целом.

Архитектура и основные преимущества xoRDE

1. Быстрый старт - xoRDE является
полноценной операционной системой,
поставляемой в скомпилированном
виде (набор EXE и DLL) и готовой к
использованию «из коробки», в отличие
от аналогов типа Robot Operating System.

2. Мульти-платформенность - xoRDE
состоит из набора скомпилированных
программных модулей и стеков
протоколов для управления
разнообразным «железом» робота,
которые запускаются на разных
компьютерных платформах (Windows,
Linux, maсOS, Android).

3. Скорость - протокол ONB обеспечивает
обмен между модулями и компонентами
ОС xoRDE в режиме реального времени
(real-time operation).

4. Распределенность – модули ОС могут
быть развернуты на разных
компьютерах. Супер-важно для IoT!

Конкурентные преимущества xoRDE для пользователей

✓ Не нужно быть программистом (и пользователем UBUNTU), что обеспечивает «взрывной рост» клиентской
базы

✓ Легкость развертывания и использования на уже подключенных роботов на разных платформах –
скомпилированный EXE с набором модулей, графический редактор для сборки схем робота.

✓ Легкость добавления новых РТУ - достаточно реализовать ONB-драйвера.

✓ Встроенное программирование на JavaScript

✓ Возможность использования распределённых модулей, запускаемых на разных компьютерах и операционных
системах

✓ Интеграция с нейросетью Yolo распознавания образов

✓ Интеграция с самообучающейся сетью OgmaNeo2

✓ Возможность общения роботом с помощи речи

✓ Open-source ядро и SDK

✓ Документация

Конкурентные преимущества xoRDE для разработчиков

✓ Быстрый протокол обмена данными вида Издатель-Подписчик, реализованный через WebSocket

✓ Мультиплатформенное использование (Windows, Linux, maсOS, Android)

✓ Возможность использовать любой язык для написания компонентов c API и SDK для распространённых языков
программирования (C++, Java, Python, C#)

✓ Менеджер компонентов, производящий их запуск и слежение за жизненным циклом

✓ Браузерная IDE для настройки и управления (снижает нагрузку на систему, что важно для IoT)

✓ Визуальное программирование (Drag’n’Drop’n’Connect)

✓ Универсализированная разметка для обмена и визуального интерфейса

✓ Репозитарная система для компонентов (включая платные опции) с платформой для разработчиков

✓ Низкий порог вхождения, так как не требует навыков написания кода

✓ Каталог готовых драйверов для сенсоров, моторов, приводов, камер, микрофонов, LEGO EV3
