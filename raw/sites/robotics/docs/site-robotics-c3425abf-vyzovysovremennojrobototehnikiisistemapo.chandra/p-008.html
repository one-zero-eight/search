Технологические барьеры (из ДК НТИ)

  1. 1. Потребность в повышении автономности БАС (требуется разработки из области робототехники, создания нового поколения авионики)
  2. 2. Отсутствие доступных по цене (десятки долларов) автомобильных бортовых устройства с функционалом, достаточным для предоставления услуг в области: электронные компоненты и встроенное программное обеспечение транспортных средств различных уровней автоматизации; вспомогательные системы активной безопасности (ассистенты) водителя (ADAS), телематические устройства, головные устройства, решения для реализации человеко-машинного интерфейса, системы удаленной диагностики транспортных средств, компоненты систем экмониторинга, дорожной и придорожной инфраструктуры
  3. 3. Отсутствуют эффективные роботизированные беспилотные системы производственной и складской логики, позволяющие повысить производительность труда на 50% и выше.
  4. 4. Новые двигатели и манипуляторы для автономных необитаемых аппаратов, потребляющие кратно (в 2 и более раз) меньше энергии, чем существующее оборудование, при сохранении уровня производительности и управляемости.
  5. 5. Технологии медицинской и ассистивной робототехники, мониторинга пациентов для нейрохирургии и нейрофизиологии.
  6. 6. Системы пропорционального управления в контурах интерфейсов мозг-компьютер на основе выделения и классификации градаций ЭЭГ паттернов (для максимального приближения динамики управления исполнительными устройствами в контурах ИМК к темпам естественного (антропоморфного) управления с помощью мышечных усилий)
