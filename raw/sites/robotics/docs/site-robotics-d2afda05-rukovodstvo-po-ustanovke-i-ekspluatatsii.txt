1. Введение

1.1 Описание функциональных характеристик ПО

Автоматизированная платформа сопровождения процесса строительства
скважины «DrillFlow» (далее по тексту – ЦП «DrillFlow») представляет собой веб
приложения для планирования и мониторинга процессов строительства скважин. Основные
функциональные модули ЦП «DrillFlow» - формирование проектной документации на
скважину. Данный модуль позволяет создавать разделы программы бурения (конструкция
скважины, траектория, стратиграфия, осложнения, компоновки низа бурильной колонны,
буровые растворы и др.) в автоматическом режиме благодаря алгоритмам машинного
обучения.

Модуль «Инженерных расчетов» позволяет рассчитывать режимы бурения, строить
траекторию скважины, проводить расчет пересечения с соседними скважинами, определить
моменты и натяжения, необходимые для бурения скважины.

Модуль «Ковер бурения» позволяет планировать очередность бурения скважин на год,
а также отслеживать состояние скважины, в частности имеется ли доступ к ЛЭП, проведены
ли подготовительные работы и имеется ли отклонение от плановых показателей.

Модуль «Мониторинга скважин» позволяет в режиме реального времени получать
данные с буровой по протоколу WITSML, анализировать их с помощью искусственного
интеллекта и прогнозировать возможные инциденты.

1.2 О системе

Платформа «DrillFlow» — программное обеспечение для объединения разрозненных
процессов и данных компании. ЦП «DrillFlow» позволяет управлять различными процессами
организации.
В ней доступны:

● загрузка данных из различных источников;

● выгрузка данных в форматы .xls, .pdf, .doc;

● прием данных по протоколу WITSML.

ПО является веб-приложением, которое предоставляет пользователям интерфейс для работы
с основыми инструментами продукта (формирование проектной документации, инженерные
расчеты, ковер бурения, мониторинг скважин).

1.3 Системные требования
ЦП «DrillFlow» может быть поставлено заказчику в двух форматах:

• облачное решение;

• серверное решение.
Настройка ПО в формате облачного решения и предоставление ресурсов для его
функционирования обеспечивается компанией-производителем. При установке серверного
решения на локальных серверах заказчика не требуется установка дополнительных
компонентов, поскольку ПО для установки включает требуемые компоненты.

Минимальные системные требования для установки:

● 4 Гбайт (GB) RAM;

● 30 Гбайт (GB) свободного дискового пространства.

проверки.

1.6 Модули системы

Основные функции для реализации процессов присутствуют в стандартных модулях и
включены в базовую сборку ЦП.

Примеры доступных модулей:

● Модуль «Формирование проектной документации» — используется для
автоматического формирования программы бурения скважины;

● Модуль «Инженерных расчетов» — используется для расчета режимов бурения
скважины;

● Модуль «Ковер бурения» — используется для планирования работ на заданный
интервал и контроля операций;

● Модуль «Мониторинг скважин» — используется для отслеживания текущего статуса
и прогнозирования осложнений в режиме реального времени.

Другие дополнительные функции могут быть добавлены в ЦП «DrillFlow» с
использованием комбинаций перечисленных модулей, а также в формате новых модулей, в
том числе содержащих такие скрипты, процедуру и т.д.
