## Development of a modular system for remote and autonomous control of commercial vehicles in conjunction with a complex of aerial reconnaissance of the traffic route based on components
![](https://robotics.innopolis.university/wp-content/uploads/2019/05/Klimchik-Aleksandr-300x300.jpg)
Alexandr Klimchick
project lead
| Partners: | KAMAZ |
| --- | --- |
| Financing: | FTP |
| Laboratory: | [Autonomous Transportation Systems Lab](https://robotics.innopolis.university/en/?post_type=labs&p=96) |
| Status: | Завершен |
The main problem, which the project is aimed at, is to ensure the road safety of automobile vehicles using automated vehicle control processes. The scientific novelty of the proposed project lies in a quick-detachable autonomy module for freight vehicles with aerial reconnaissance function, which allows you to get a three-dimensional map of the area using a UAV for an unmanned truck, which allows you to make a significant contribution to solving problems in automating vehicle control processes.
