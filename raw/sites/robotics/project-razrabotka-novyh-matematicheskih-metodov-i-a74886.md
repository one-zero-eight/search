## Разработка новых математических методов и алгоритмов анализа рентгеновских изображений органов грудной полости для автоматизации диагностики заболеваний легких с помощью решения задачи классификации изображений с высокой внутриклассовой и низкой межклассовой дисперсией
![](https://robotics.innopolis.university/wp-content/uploads/2022/11/pershin-ilya-1-150x150.png)
Першин Илья
руководитель проекта
| Партнеры: | РНФ |
| --- | --- |
| Лаборатория: | [Лаборатория искусственного интеллекта](https://robotics.innopolis.university/labs/laboratoriya-iskusstvennogo-intellekta/) |
| Статус: | Выполняется |
Стандартный подход к диагностике легочных заболеваний, осуществляемый через анализ рентгеновских снимков сверточными нейронными сетями, походит к уровню максимально достижимого качества результатов. В рамках проекта разрабатываются подходы, использующие другие источники информации для повышения точности диагностики решений ИИ. Например, анализ движений глаз рентгенолога с помощью ИИ. Это направление исследований можно охарактеризовать термином «анализ взаимодействия врача и ИИ», которое представляет чрезвычайный интерес для крупных промышленных и исследовательских институтов мира. Научная часть проекта естественным образом превратилась в практическое решение, которое было реализовано и апробировано в больницах Москвы и Казани.
