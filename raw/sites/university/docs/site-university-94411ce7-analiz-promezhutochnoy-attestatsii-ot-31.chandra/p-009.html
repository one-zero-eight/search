Отмечена неявка двух обучающихся на промежуточную аттестацию по указанной дисциплине. При этом неявка обучающихся по данной образовательной программе по другим промежуточным аттестациям отсутствует.

По итогам промежуточной аттестации 1 курса в осеннем семестре 2021/2022 учебного года освоение указанных выше дисциплин также вызвало наибольшие затруднения, но статистические показатели были выше:

  • - средний балл составил 3.73;
  • - абсолютная успеваемость – 68%;
  • - качественная успеваемость – 68%.

Отдел контроля образовательной деятельности рекомендует пересмотреть оценочные средства по видам текущего контроля успеваемости, промежуточной аттестации по дисциплине «Эмпирические методы для инженеров ПО и инженеров данных / Empirical Methods for Software Engineers and Data Scientists» в соответствии с уровнем подготовки обучающихся 1 курса по программе магистратуры.
