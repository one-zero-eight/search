5. ВЗАИМОДЕЙСТВИЕ С ДРУГИМИ СТРУКТУРНЫМИ ПОДРАЗДЕЛЕНИЯМИ
УНИВЕРСИТЕТА

5.1. Взаимодействие Центра с другими структурными подразделениями Университета определяется задачами и функциями, возложенными на него настоящим Положением.

5.2. Взаимодействие с финансово-экономическим отделом осуществляется по вопросам: порядка применения законодательства и локальных актов Университета, регулирующих оплату труда в Университете, подготовки проектов локальных актов, регулирующих финансовую деятельность Университета, по проведению юридической экспертизы ситуации с привлечением работников Университета к материальной ответственности, подготовке и передаче необходимых материалов в судебные органы по взысканию дебиторской задолженности с организаций, налоговым спорам.

5.3. Взаимодействие с отделом учета и движения персонала осуществляется по вопросам порядка применения законодательства и локальных актов Университета, регулирующих трудовые отношения, по вопросам предоставления информации, необходимой для выполнения задач Центра.

5.4. Взаимодействие с организационно-техническим отделом осуществляется по вопросам обеспечения площадей и материально технического обеспечения для проведения мероприятий Центра.

5.5. Взаимодействие с отделом информационных технологий по вопросам технического оснащения Центра и вновь принимаемых сотрудников.

5.6. Взаимодействие с отделом по связям с общественностью по вопросам освещения проводимых Центром мероприятий, а также по вопросам разработки дизайна и другим вопросам, связанным с деятельностью Центра.

5.7. Взаимодействие с другими структурными подразделениями осуществляется в ходе подготовки проектов локальных актов, приказов, инструкций, договоров и других документов; подготовки заключений, письменных и устных справок по вопросам, относящимся к компетенциям Центра, а также в ходе подготовки к различным мероприятиям, связанным с деятельностью Центра.

5.8. Центр может быть базой для проведения практической подготовки обучающихся Университета.
