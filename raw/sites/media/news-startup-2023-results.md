## Объявлены победители четвёртого всероссийского акселератора «Дом университетских стартапов»
12 октября 2023
Генеративный ИИ для логистики кораблей, образовательный сервис для молодых айтишников и патчи от прыщей стали лучшими среди 55 стартапов из 17 вузов России. Победителей выбрали члены жюри, среди которых представители Додо Пиццы, Яндекса, Mighty Angels VC, АО «Татхимфармпрепараты», MOFL, «Базелевс», Евразийского центра инноваций, Союза организаций бизнес-ангелов, СИНДИКАТ. Организатор — Университет Иннополис.
![](https://media.innopolis.university/upload/iblock/ca8/bwn272o3p8yk6td1due9gk8dnb1y3fl1/IMG_2899.JPG)
1 место — сервис Naval Sheep, который с помощью ChatGPT и математической оптимизации помогает составить логистику водного транспорта (проект из Сколтеха)
2 место — телеграм-ботом Innoprog, который помогает составить индивидуальную образовательную траекторию в ИТ (студент Университета Иннополис)
3 место — патчи от прыщей на основе нафталанового масла Naftalanpatch, которые подходят для любого типа кожи (студенты КНИТУ)
Также жюри выделили 4 проекта по номинациям:
— «Актуальность и технологичность стартапа» — проект студентов из ИТМО Smart membrane — разработка умной полимерной мембраны с pH-моделирующими свойствами для компаний, развивающих переработку пластовых рассолов на территории своих нефтедобывающих предприятий;
— «Проработанный бизнес-план» — проект студентов из Университета Иннополис PetConnect — приложение для владельцев домашних питомцев, в котором можно экстренно получить онлайн-консультацию ветеринара, найти своего питомца, проконсультироваться с кинологом;
— «Уровень презентации» — проект студентов из Университета Иннополис TuneLike — сервис знакомств и подбора мероприятий на основе музыкальных вкусов;
— «Потенциал коммерциализации»— проект студентов из ИТМО, МГТУ им. Н.Э. Баумана и СПбГУ PatentCore.ru — платформа для простой генерации патентов с помощью ИИ.
