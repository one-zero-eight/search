## Круглый стол на тему создания Центра компетенций по робототехнике, мехатронике и сенсорике
![](https://media.innopolis.university/upload/iblock/24d/photo_2017-04-04_17-54-49.jpg)
В целях поддержки предприятий отрасли новыми знаниями и информационными ресурсами мы планируем создать на базе Университета Центр компетенций по робототехнике, мехатронике и сенсорике.
Приглашаем Вас принять участие в круглом столе для обсуждения возможных направлений развития Центра.
**Программа мероприятия**
| Время | Мероприятие |
| --- | --- |
| 10:00 - 10:15 | Открытие мероприятия |
| 10:15 - 11:45 | Выступление представителей приглашенных организаций по теме «Сенсорика и Мехатроника» |
| 11:45 - 12:00 | Кофе брейк |
| 12:00 - 13:30 | Выступление представителей приглашенных организаций по теме «Беспилотные летательные аппараты, подводные и мобильные роботы» |
| 13:30-14:30 | Перерыв на обед |
| 14:30 - 16:00 | Выступление представителей приглашенных организаций по теме «Промышленные и сервисные роботы» |
| 16:00 - 16:15 | Кофе брейк |
| 16:15 - 17:45 | Выступление представителей приглашенных организаций по теме «Прочие робототехнические комплексы гражданского, военного и двойного назначения» |
| 17:45 - 18:45 | Обсуждение и подведение итогов |
| 18:45 – 19:00 | Закрытие мероприятия |
По всем вопросам обращаться к Отарашвили Зурабу Автандиловичу - советнику ректора, z.otarashvili@innopolis.ru, +7 (916) 824-04-11.
