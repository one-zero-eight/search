## Университет Иннополис открыл регистрацию на онлайн-курсы по Python, Java и веб-программированию
18 мая 2020
- [Школа](https://media.innopolis.university/?TAGS=Школа)
- [Образование](https://media.innopolis.university/?TAGS=%20Образование)
Курсы пройдут 1—5 июня, они рассчитаны на школьников 5—11 класса и студентов 1—2 курса. На каждое направление принимается по 20 человек. Приём заявок открыт до 28 мая.
![](https://media.innopolis.university/upload/iblock/ba1/online%20courses.jpg)
Пять дней участники будут учиться программировать, используя виртуальную площадку Университета Иннополис в игровой среде Minecraft. Подобный формат обучения уже успешно протестирован на онлайн-курсе по Python 2—5 мая, в котором участвовали 24 школьника из разных городов России и Эстонии.
Онлайн-курсы в Minecraft выступают как пилотный проект перед большой Летней школой олимпиадной подготовки по информатике — [https://vk.cc/aufnJy](https://vk.cc/aufnJy).
«Вселенная Университета Иннополис в Minecraft развивается с каждым днём. Если в начале первой смены были построены несколько этажей ИТ-вуза, то под конец уже был достроен весь корпус, столовая, участники устраивали виртуальные обеды на площади, а вечерами катались на катке и играли в снежки. При этом мы постарались сделать образовательный процесс максимально эффективным. Геймификация помогает лучше усваивать новые знания. Положительные отзывы участников курса по Python и их родителей это подтверждают», — комментирует руководитель Олимпиадного центра Университета Иннополис Владимир Сметанин.
Онлайн-курс по программированию на Python
Регистрация: [https://vk.cc/aufnQh](https://vk.cc/aufnQh)
Знакомство c языком программирования Python в среде разработки Wing IDE и с тестирующей системой PCMS. Изучение переменных, базовых операций и операторов, двумерных массивов (вложенные списки), а также объектно-ориентированное программирование, побитовые операции и двоичное представление числа. С помощью Python участники научатся писать код красиво, быстро запускать простые программы и создавать анимацию.
Онлайн-курс по программированию на Java
Регистрация: [https://vk.cc/aufnQh](https://vk.cc/aufnQh)
Курс поможет освоить азы программирования на языке JAVA. Обучение пройдёт в игровой форме. Все задачи пользователя будет выполнять робот Карел: предстоит написать программы, в которых Карел ищет сокровища, проходит лабиринты, становится грузчиком и так далее. Пошаговое обучение позволит без труда освоить материал. Слушатели изучат темы — логические операции, булевы переменные, операции сравнения, условные операторы, случайные величины, события клавиатуры, анимация, массивы и другие. После курса вы сможете создавать игры, графические приложения и другие программы.
Онлайн-курс по веб-программированию
Регистрация: [https://vk.cc/aufnQh](https://vk.cc/aufnQh)
Курс покрывает основы frontend-разработки — ту часть веб, с которой работают пользователи. На курсе получится изучить основные инструменты, необходимые веб-разработчику: разрабатывать современные веб-страницы с использованием языков HTML и CSS, а также узнать, как сделать так, чтобы сайт красиво отображался на всех типах устройств. В финале программы курса — освоение основ одного из самых популярных языков программирования JavaScript.
