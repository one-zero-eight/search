## ИТ-школа Университета Иннополис «Прогматика» проведёт образовательные интенсивы по программированию для школьников на каникулах
29 октября 2021
Специалисты ИТ-школы подготовили интенсивы для учащихся 6—11 классов по пяти направлениям — олимпиадное программирование, программирование на Java, C++ и на Python, разработка 2D-игр на Python. Курсы пройдут 30 октября — 6 ноября и 17—24 ноября, учитывая графики каникул в школах с разными системами обучения: по триместрам и четвертям.
![](https://media.innopolis.university/upload/iblock/be9/%D0%A4%D0%BE%D1%82%D0%BE_1025.jpg)
«Интенсивы — отличный формат, чтобы за неделю познакомиться с направлением, получить теоретическую базу и сразу закрепить её на практике. После обучения участники получат сертификат и проект в портфолио в зависит от программы обучения», — рассказал директор ИТ-школы Алексей Хабибуллин.
Участие в интенсивах по программированию ориентировано на начинающих, которые хотят познакомиться с выбранным языком. А также на тех, кто хочет закрепить свои знания или изучить новый язык.
В группах по разработке игр школьники смогут познакомиться с основами языка программирования Python и научиться применять его для создания собственных 2D-игр, по итогу участники напишут три рабочие игры с разными механиками и получат знания для дальнейшего самостоятельного создания игр.
Интенсив по олимпиадному программированию подойдёт для тех, кто уже знаком с программированием на одном из языков программирования и хочет начать участвовать в олимпиадах по информатике и программированию. Для участников, которые уже имеют олимпиадный опыт, будет проходить обучение в группе продолжающих с более сложными олимпиадными задачами.
