## Университет Иннополис открыл регистрацию на зимние интенсивы для школьников по ИТ-направлениям
11 декабря 2023
4—8 января ИТ-школа российского ИТ-вуза приглашает учащихся 3—11 классов на онлайн-курсы по разработке игр на Roblox, программированию на Python, 3D-моделированию в Blender и искусственному интеллекту. В конце обучения слушатели создадут свой проект в портфолио.
![](https://media.innopolis.university/upload/iblock/c91/ouvig262sqxb0wokd3gxwlromrywluos/IMG_7615.JPG)
Курсы доступны в двух формах: ежедневные онлайн-уроки по расписанию и самостоятельное изучение материала по видеоурокам с поддержкой преподавателя в телеграм-чате. По итогам все слушатели получат сертификат о прохождении интенсива и вечный доступ к записям уроков.
Направления обучения:
— Разработка игр на Roblox для 3—6 классов
Школьники познакомятся со средой разработки Roblox, научатся использовать её для решения различных задач и изучат базовый синтаксис программирования. В программе: работа с переменными, циклами и функциями, создание сложных 3D-моделей и ресурсов для сбора для разработки проекта в Roblox.
— Программирование на языке Python для 6—11 классов
Слушатели познакомятся с основами языка программирования Python и научатся использовать его для решения различных задач. В программе: знакомство с переменными, условиями, циклами и с коллекциями данных, работа с особым модулем для создания телеграм-бота.
— Искусственный интеллект для 6—11 классов
Учащиеся научатся писать запросы к нейронным сетям и применять ИИ в повседневных задачах. В программе: области использования и работа с нейронными сетями.
— 3D-моделирование в Blender для 7—11 классов
Участники интенсива изучат в программе Blender 3D-моделирование и текстурирование объектов, познакомятся с основными принципами проектирования, научатся работать с референсом, настраивать материалы, свет и камеру.
Регистрация открыта до 29 декабря: [https://progmatica.innopolis.university/winter_intensive24](https://progmatica.innopolis.university/winter_intensive24)
