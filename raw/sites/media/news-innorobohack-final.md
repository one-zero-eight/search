## Участники InnoRoboHack разработали роботов-космонавтов и беспилотные поезда
9 декабря 2019
- [Образование](https://media.innopolis.university/?TAGS=Образование)
- [Индустрия](https://media.innopolis.university/?TAGS=%20Индустрия)
- [Наука](https://media.innopolis.university/?TAGS=%20Наука)
В Университете Иннополис прошёл хакатон по искусственному интеллекту, в котором участвовали 110 разработчиков из Москвы, Санкт-Петербурга, Екатеринбурга, Ижевска, Архангельска, Марий Эл, Уфы, Казани и Иннополиса. В течение 48 часов они создавали прототипы по одному из двух треков — «Антропоморфная робототехника» и «Автономный транспорт».
![](https://media.innopolis.university/upload/iblock/929/Innorobohack%20final.jpg)
В треке «Антропоморфная робототехника» участники решали 2 задания с роботом Фёдором. В первом — робот на борту МКС должен взять со стола и перенести контейнер в специальный бокс. Во втором — Фёдору предстояло на транспортном средстве «Ровер» заехать в гараж на Луне.
Участники написали ПО для обмена данными с роботом, решили задачи прямой и обратной кинематики и технического зрения — поиск объекта в локальной системе координат.
За 2 дня все команды реализовали протоколы передачи данных и запрограммировали движения робота. Двум командам удалось решить задачи по техническому зрению, с задачами кинематики справилась только одна команда — Moscow Statics, она заняла 1 место. Команда Parovozic Thomas из Санкт-Петербурга, занявшая 2 место, единственная использовала в своем решении данные с лидара. Команда Innosteros из Казани и Иннополиса предложила альтернативное решение задачи — через пользовательский интерфейс: решить вопросы кинематики вручную с помощью кнопок. Они заняли 3 место.
В треке по автономному транспорту участники разрабатывали технологии автоматизированного управления железнодорожным составом без участия машиниста. Ключевая задача: найти рельсы с помощью данных, предоставляемых камерами машинного зрения. Для решения участникам предоставили 4000 размеченных вручную изображений железнодорожной колеи Московского Центрального Кольца с камеры на фронтальной части локомотива.
Качество алгоритмов оценивалось по метрике, признанной в мировом сообществе при решении задач семантической сегментации — IoU. Таким образом, 1 место заняла команда innoteam123 из Казани и Иннополиса, второе — Synthesis из Москвы, третье — Clover group из Казани.
За 1 место победители обоих треков выиграли по 100 000 рублей, за 2 место — по 50 000 рублей, за третье — по 30 000 рублей.
