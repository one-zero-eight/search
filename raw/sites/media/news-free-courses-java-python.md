## Университет Иннополис запускает бесплатные курсы по программированию на языках Python и Java для школьников
28 октября 2021
Обучение стартует онлайн 15 ноября в рамках пилотного проекта Минцифры России для учащихся из Республики Татарстан, Белгородской, Новгородской, Пензенской областей и Республики Саха. Оператор проекта — Университет 20.35.
![](https://media.innopolis.university/upload/iblock/5cd/_MG_3989.JPG)
Регистрация открыта для школьников от 14 лет. После выбора программы школьникам предстоит пройти тестирование на профориентацию и мотивацию. Полный курс рассчитан на 144 часа, половина из них – это вебинары с преподавателем. Остальное время на курсе Python отводится на самостоятельное решение задач и индивидуальный проект на курсе Java.
По итогам обучения выдаётся цифровой сертификат о прохождении программы. Учащиеся 10–11 классов, успешно освоившие курсы Университета Иннополис получат преимущества при поступлении в ИТ-вуз: они автоматически перейдут на второй этап грантового конкурса, минуя заочный отбор.
Проект продлится до июня 2022 года, при этом содержание и продолжительность программ будут по итогам курса скорректированы, исходя из отзывов самих школьников, их родителей и учителей. Опыт и результаты пилотного запуска будут учтены во всероссийском проекте, который стартует в следующем году. Обучение входит в список мероприятий федерального проекта «Кадры для цифровой экономики».
Подробности и регистрация: [https://java.innopolis.university/](https://java.innopolis.university/)
