## В нашем лагере дети занимаются по 6 направлениям
## Разработка мобильных приложений
Дети научатся
1. Основам алгоритмизации.
2. Принципам проектирования мобильных приложений.
3. Разрабатывать мобильные приложения в среде «AppInventor» и на текстовом языке Java.
4. Использовать датчики мобильных устройств в своих программах.
5. Создавать игры для мобильных устройств.
## Разработка компьютерных игр
Дети научатся:
1. Алгоритмизировать игровые процессы.
2. Программировать на визуальном языке программирования Scratch и на текстовом языке C#.
3. Создавать анимации с использованием устройств ввода информации компьютера.
4. Создавать свои игры с использованием сторонних датчиков.
5. Декомпозировать сложные задачи.
## Программирование в Minecraft
Дети научатся:
1. Основам программирования.
2. Основам составления алгоритмов для решения задач.
3. Интерпретировать свои задумки в виде кода.
4. Понимать области применения своих навыков.
5. Основам синтаксиса Python и принципам работы с ПО (IDLE).
## Разработка Web-приложений на Python
Дети научатся:
1. Понимать алгоритмы, переменные, типы данных.
2. Узнают ветвления и циклы.
3. Познакомятся с массивами и функциями.
4. Научаться верстать сайты с использованием HTML и CSS.
5. Размещать сайты на хостинге.
## Дизайн и проектирование интерфейсов
Дети научатся:
1. Основам дизайн-мышления и базам продуктового дизайна.
2. Проектировать мобильные интерфейсы.

4. Выстраивать взаимодействие пользователя с продуктом
5. Взаимодействовать с разработчиками внутри команды.
