Вход в Teams и начало работы
## ¶ 1. Запуск Microsoft Teams.
Windows: нажмите кнопку «Пуск» и наберите с помощью клавиатуры приложение Microsoft Teams, далее необходимо запустить
![](https://help.university.innopolis.ru/images/image_1699009623233.png)
- MacOS: перейдите в папку Applications (Приложения) и выберите Microsoft Teams
## ¶ 2. Вход в учетную запись
- Во время первого запуска приложения необходимо ввести свои учётные данные.
![](https://help.university.innopolis.ru/images/image_1699009775229.png)
## ¶ 3. Функционал
- Поисковая строка: в верхней части приложения есть поисковая строка, где Вы можете ввести запрос и получить ответ, например: найти контактные данные коллеги и написать ему.
![](https://help.university.innopolis.ru/images/image_1699009877543.png) ![](https://help.university.innopolis.ru/images/image_1699009895651.png)
- Команды: команда предназначена для объединения группы людей, которые тесно сотрудничают друг с другом для выполнения поставленных задач. В левой части окна приложения выбрать «Команды».
![](https://help.university.innopolis.ru/images/image_1699009941627.png)
Выбрать нужный вариант «Присоединиться» или «Создать команду». Для присоединения к собранию необходимо ввести уникальный код приглашения.
![](https://help.university.innopolis.ru/images/image_1699010020678.png)
- Каналы: внутри каждой Команды можно создавать «Каналы». Каналы – это чаты для общения сотрудников, обсуждение в команде, посвященное отделу, проекту или теме.
![](https://help.university.innopolis.ru/images/image_1699010290523.png)
Данные каналы обладают очень широким спектром возможностей, например: в них можно создавать опросы, делиться файлами, ссылками и т.д.
![](https://help.university.innopolis.ru/images/image_1699010309761.png)
