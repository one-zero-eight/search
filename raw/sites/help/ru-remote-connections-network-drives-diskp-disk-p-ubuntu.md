Disk_P_ubuntu
Подключение диска Р на Linux Ubuntu
В терминале выполнить установку с помощью команды.
sudo apt-get install samba smbclient
- Откройте приложение «Файлы» (проводник)
- В диспетчере файлов нажмите «другие расположения», на боковой панели
- Подключитесь к серверу, введите адрес:
smb://uni.innopolis.ru/dfs
и нажмите "Connect"
Сервер будет также добавлен на боковую панель, чтобы вы могли быстро получить к нему доступ.
