## ¶ Вариант подключения если вы работаете в Университете Иннополис
- Откройте меню Пуск -> Далее с помощью поиска введите в окне поиска "Панель управления"3
![](https://help.university.innopolis.ru/images/image_1699368620508.png)
- В открывшемся окне выберите «Мелкие значки»
![](https://help.university.innopolis.ru/images/image_1699368647050.png)
- Далее откройте подключение к удаленным рабочим столам ->
![](https://help.university.innopolis.ru/images/image_1699368664635.png)
- Возле строки Work Resources (подключение по умолчанию) кликнуть на кнопку "Свойства" ->
![](https://help.university.innopolis.ru/images/image_1699368696987.png)
- Нажать кнопку "Обновить сейчас. Далее на рабочем столе вам в папке Work Resources вам будет доступна база для подключения.
![](https://help.university.innopolis.ru/images/image_1699368722028.png)
## ¶ Вариант для подключения если вы работаете удаленно (к примеру, из дома)
Важно: если вы собираетесь подключаться удаленно, просьба сообщить об этом специалисту ИТ отдела, так как для этого необходимо Вас добавлять в еще одну группу разрешений!
1. Перейти на сайт https://rds.university.innopolis.ru
2. Ввести свои учетные данные
3. Скачать на компьютер нужный ярлык для подключения.
4. Выполнить подключение.
