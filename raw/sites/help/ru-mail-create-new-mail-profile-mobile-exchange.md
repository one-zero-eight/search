Добавление учетной записи Exchange на телефон
1. (Accounts) Необходимо зайти в аккаунты или учетные записи.
2. (Delete old account Exchange) Удалить старую учетную запись.
3. (Create New) Создать новую. Тип Exchange
4. (server) Адрес сервера: mail.innopolis.ru
5. (User Name = email) имя пользователя = адрес почты
6. (Use SSL) Использовать SSL
