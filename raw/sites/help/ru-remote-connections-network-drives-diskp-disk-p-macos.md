Disk_P_macOS
Подключение диска Р на MacOS
Открываем программу Finder, которая обычно располагается в левой части дока, простым нажатием
![](https://help.university.innopolis.ru/images/image_1698935597626.png)
Нажимаем сочетание клавиш Command+K для открытия окна «Подключение к серверу».
В открывшемся окне необходимо будет ввести путь к сетевому серверу, а также к папке, которая будет использоваться в качестве диска:
![](https://help.university.innopolis.ru/images/image_1698935622131.png)
Нужно написать - smb://fs.uni.innopolis.ru/dfs
Система попросит вас ввести имя пользователя и логин для подключения.
![](https://help.university.innopolis.ru/images/image_1698935646070.png)
