Get started with Microsoft Teams
## ¶ Start Teams.
Windows: Open the Start menu and run the application.
![](https://help.university.innopolis.ru/images_en/image_1699456972172.png)
- MacOS: Go to the Applications folder and run Microsoft Teams.
## ¶ Sign in and get started with Teams
- At the first application start you must enter your credentials (username@innopolis.ru, password).
![](https://help.university.innopolis.ru/images_en/image_1699456996064.png)
## ¶ Application functionality
- Search bar: At the top of the window. Use it to get required information. For example: find the contact details of a colleague and write message to him.
![](https://help.university.innopolis.ru/images_en/image_1699457018868.png)
- Teams: This tab is designed to work with people groups and unite them in teams by projects.
Select "Teams" in the left part of the application window.
![](https://help.university.innopolis.ru/images_en/image_1699457040173.png)
Select the "Join or create team" and choose your option. To join the meeting, you must enter a unique invitation code.
![](https://help.university.innopolis.ru/images_en/image_1699457055320.png)
- Channels: Inside “Teams” you can create Channels to have different common conversations.
![](https://help.university.innopolis.ru/images_en/image_1699457099409.png)
- These channels have a very wide range of possibilities, for example: you can create voting, share files, links, etc.
![](https://help.university.innopolis.ru/images_en/image_1699457116815.png)
