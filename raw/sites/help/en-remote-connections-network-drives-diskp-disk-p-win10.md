How to connect to drive P(OS win 10)
## ¶ Connecting drive P to the University network
Open File Explorer from the taskbar or the Start menu, or press the Windows + E..
![](https://help.university.innopolis.ru/images_en/1.jpg)
Select This PC from the left pane. Then, on the Computer tab, select Map network drive.
![](https://help.university.innopolis.ru/images_en/image_1699436398492.png)
In the Drive list, select a drive letter. (Any available letter will do.)
In the Folder list write the address \\UNI\DFS
Select the «Reconnect at sign-in check box»
Select the «Connect using different credentials»
Finish
Enter the credentials from your work computer in the format username@uni.innopolis.ru, password, check the box "Remember account data” and click OK.
![](https://help.university.innopolis.ru/images_en/5.jpg)
- Open File Explorer from the taskbar or the Start menu, or press the Windows + E. and check the connection to drive P.
![image_1699436823272.png](https://help.university.innopolis.ru/images_en/image_1699436823272.png)
## ¶ Connecting drive P to another network
- Open File Explorer from the taskbar or the Start menu, or press the Windows + E..
![](https://help.university.innopolis.ru/images_en/1.jpg)
- Select This PC from the left pane. Then, on the Computer tab, select Map network drive.
![](https://help.university.innopolis.ru/images_en/image_1699436398492.png)
- In the Drive list, select a drive letter. (Any available letter will do.)
- In the Folder list write the address [https://disk.university.innopolis.ru/](https://disk.university.innopolis.ru/)
- Select the «Reconnect at sign-in check box»
- Select the «Connect using different credentials»
- Finish
![](https://help.university.innopolis.ru/images_en/image_1699436433591.png)
- Enter the credentials from your work computer in the format username@uni.innopolis.ru, password, check the box "Remember account data” and click OK.
![](https://help.university.innopolis.ru/images_en/5.jpg)
- Open File Explorer from the taskbar or the Start menu, or press the Windows + E. and check the connection to drive P.
![](https://help.university.innopolis.ru/images_en/7.jpg)
Note: If you can't connect to a network drive, might not have the correct permissions. Please contact the IT department.
