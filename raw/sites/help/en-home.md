We are pleased to inform you about the creation of IT Wiki, which has replaced the section 'IT Services for Employees' on the Portal (Bitrix)
Features of the new IT WIKI include:
- 📰 The information on the site is constantly updated, which allows it to remain always relevant and useful for you!
- 🌐 Also, the wiki has several language versions, which allows it to be accessible to all employees.
- 📱 A mobile version of the site is available, now you can easily find the information you need from your mobile device.
- 🤝 Assistance in adapting new employees to IT services;
- 📚 A knowledge base expediting the search for solutions to common tasks.

To obtain access for non-employees of the IU, you must fill out a form (NDA) and provide the signed form to the IT department. The form can be found on the IU portal in the Local Regulations section.

## ¶ Events, Olympiads, equipment distribution
For upcoming Olympiads, please create requests in advance, at least 2 weeks before the start of the event.
- Equipment distribution
- Laptop disk images
- If you need to get audio and video equipment, then write a request to it@innopolis.ru
- If you need to get a laptop, computer, monitor, etc., then write a request on the portal (Bitrix) in the section [Requests for the provision of goods] [https://portal.university.innopolis.ru/processes/list/189/view/0/](https://portal.university.innopolis.ru/processes/list/189/view/0/)
You can find ready-made images at the following link: [http://10.90.138.111:3000/](http://10.90.138.111:3000/)
- If one of the images suits you, please create a request to it@innopolis.ru with the name of the image
- If none of the images suits you, please create a request to it@innopolis.ru with a detailed description of the functionality of the image
