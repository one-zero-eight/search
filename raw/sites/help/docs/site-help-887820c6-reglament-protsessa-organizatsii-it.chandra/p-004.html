3. Схема процесса

Организация ИТ-поддержки в Университете Иннополис

Swimlanes and Roles:

  • Заявитель (Applicant): Initiates the process by identifying a need for IT support and creating a request.
  • Координатор (Coordinator): Receives the request, processes it, and determines the responsible IT department. It also handles the routing of the request to the appropriate department.
  • ОТРС (OTRS): Manages the request through the system, updates the status, and provides communication to the applicant. It also tracks the planned execution date.
  • Ответственный исполнитель (Responsible Employee): Takes ownership of the request, clarifies details with the applicant, and executes the work. It also handles the resumption of work if necessary.

Key Process Steps:

  • Формирование и направление заявки (Forming and sending the request)
  • Обработка заявки (Request processing)
  • Направление заявки в подразделение, функционал которого включает запрашиваемую поддержку (Routing the request to the department whose functionality includes the requested support)
  • Ознакомление с заявкой, уточнение вопросов у заявителя, определение плана выполнения (Familiarization with the request, clarification of questions with the applicant, determination of the execution plan)
  • Выполнение заявки (Execution of the request)
  • Заккрытие заявки (Closing the request)
  • Возобновление заявки заявителем (Resumption of the request by the applicant)
  • Повторное выполнение заявки (Repeated execution of the request)
