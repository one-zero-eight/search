4.2 Схема процесса

Организация ИТ-поддержки в Университете Иннополис

graph TD
    subgraph Organization
        A[Формирование и направление заявки]
        A --> B[Обработка заявки]
    end

    subgraph Coordinator
        B --> C{ }
        C --> D[Исполнение заявки, связанно с функционалом другого подразделения]
        C --> E[Направление заявки в подразделение, функционал которого включен в запрашиваемую поддержку]
        F[Получена информация о создании новой заявки] --> B
        G[Определен Исполнитель в ОИТ] --> B
    end

    subgraph OTIS
        H[Критерии заявки, постоянная ответственного]
    end

    subgraph IT_Support
        I[Получена информация о поступлении новой заявки (на почту и/или систему)] --> J[Ознакомление с заявкой, уточнение вопросов у заявителя, определение плана выполнения]
        J --> K[Внесение информации по плану выполнения заявки]
        K --> L[Выполнение заявки]
        L --> M[Закрытие заявки]
        M --> N[Возвращение заявки координатору]
        N --> O[Повторное выполнение заявки]
        O --> L
    end

    A -.-> H
    B -.-> H
    E -.-> H
    I -.-> H
    J -.-> H
    K -.-> H
    L -.-> H
    M -.-> H
    N -.-> H
    O -.-> H
