Регламент прав доступа на папки диска P
![](https://help.university.innopolis.ru/images/image_1699350955229.png)
Существует правила по выдачи прав доступа на папки диска Р, просьба ознакомиться:
1. Public ( Папка для хранения файлов с общей информацией отдела , доступная для всех )
Убедительная просьба, не хранить личные и файлы с персональными данными в папках Public
- ✅ Доступ для всех сотрудников Университета Иннополис, с правами: чтение, без записи
- ✅ Доступ для сотрудников этого отдела, с правами: чтение и запись
2. Protected ( Папка для хранения файлов с общей информацией отдела, доступна только внутри отдела )
- ❌ Доступ для всех сотрудников Университета Иннополис: отсутствует
- ✅ Доступ для сотрудников этого отдела с правами: чтение и запись
- ✅ Доступ для руководителя этого отдела с правами: чтение и запись
3. Private ( Папка для хранения данных Руководителя отдела )
- ✅ Доступ только для руководителя этого отдела, добавлять пользователей можно по согласованию с руководителем (заявка на it@innopolis.ru)
- ❌ Доступ для всех сотрудников Университета Иннополис: отсутствует
- ❌ Доступ для сотрудников этого отдела: отсутствует
