If there are problems with the VPN connection
If the VPN server is operating normally and there are no observed issues, here are some solutions for certain problems:
## ¶ Slow VPN speed, poor connection, connection drops:
General recommendations for the user:
1. Check [VPN connection settings](https://help.university.innopolis.ru/en/VPN)
2. Disable or add permitting rules to firewalls.
3. Try connecting using a different protocol [(PPTP, L2TP, SSTP)](https://help.university.innopolis.ru/en/VPN)
If your connection settings are currently set to auto, the VPN will connect by default using the SSTP protocol, which is more demanding on the communication channel.
Shared ipsec key for L2TP connection - q7J>k2%[Lx
4. As a test, attempt to connect from another workstation with a different operating system.
5. Reboot the operating system.
If none of the above options help, submit a request it@innopolis.ru
## ¶ Unable to connect to VPN after changing the password:
After changing the password, you also need to update the password in the VPN settings.
You can follow the [instructions](https://help.university.innopolis.ru/ru/VPN) on setting VPN.
