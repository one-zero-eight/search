Create new mail Profile on Windows
Choose Start > Control Panel > Mail.
![](https://help.university.innopolis.ru/images_en/image_1699447714314.png)
Choose Show Profiles > Add.
![](https://help.university.innopolis.ru/images_en/image_1699447742792.png)
Type any name and click «OK”
![](https://help.university.innopolis.ru/images_en/image_1699447775776.png)
Click “Connect to a different account”
![](https://help.university.innopolis.ru/images_en/image_1699447801746.png)
Check the e-mail address and click “OK”
![](https://help.university.innopolis.ru/images_en/image_1699447825697.png)
Type your e-mail address and password. Click “OK
![](https://help.university.innopolis.ru/images_en/image_1699447851992.png)
Click “Finish”
![](https://help.university.innopolis.ru/images_en/image_1699447872968.png)
Under When starting Microsoft Outlook, use this profile, click Always use this profile.
