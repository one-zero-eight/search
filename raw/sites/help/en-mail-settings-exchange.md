Адрес почтового сервиса - [mail.innopolis.ru](http://mail.innopolis.ru)
Recommended clients for connection:
- Microsoft Outlook 2016-2019
- Microsoft Outlook for mobile
- Outlook for Mac
Outlook 2010/2013 clients are no longer supported and do not receive support.
It is also recommended to use updated applications
The main connection is established through the Autodiscover service. In other words, it is sufficient to enter the login and password.
Email is always accessible via a web browser. [https://mail.innopolis.ru/owa/](https://mail.innopolis.ru/owa/)
![image_1701080746025.png](https://help.university.innopolis.ru/images/image_1701080746025.png)
For third-party clients that do not support connections via Autodiscover, connection via IMAP SSL is provided:
- Incoming Mail Server (IMAP) address: [mail.innopolis.ru](http://mail.innopolis.ru). Port 993, type of encrypted connection: SSL.
- Outgoing Mail Server (SMTP) address: [mail.innopolis.ru](http://mail.innopolis.ru). Port 587, type of encrypted connection: StartTLS. Authentication is required.
Note: POP3 is an outdated protocol, the service is disabled, and connection is not possible.
