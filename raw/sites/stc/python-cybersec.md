## Этичный хакинг

В сфере кибербезопасности Python применяется для обнаружения вредоносных программ, доступа к серверам, отправки и декодирования
пакетов данных, сканирования сети и портов.

## Расписание курса
![](https://static.tildacdn.com/tild3933-6532-4136-b264-303363366263/Group_277132805.png)
1. Что такое информационная (компьютерная) безопасность. Основные виды угроз.
2. Нормативно-правовые основы
3. Основы сетевого взаимодействия и слабые места
4. Что такое инфраструктура, структура данных, базы данных
5. Интернет и распространенные атаки
6. Кибергигиена. Шифрование и генерация паролей. Цифровой след в сети Интернет.
7. OSINT
Промежуточная аттестация
1. Введение в ОП и установка Python
2. IDE для разработки на Python
3. Типы данных Python
4. Переменные и условные
5. Циклы
6. Строки и их методы
7. Коллекции и их методы
Промежуточная аттестация
1. Функции
2. Работа с файлами
3. Основы ООП
4. Написание модулей
5. Генераторы и итераторы
6. Декораторы
Промежуточная аттестация
1. Специализированные инструменты и умение применять базовые алгоритмы. Виртуальные машины
2. Веб-фреймворк Flask, Django
3. OWASP. Веб-уязвимости: HTML Injection, XSS
4. Веб-уязвимости: SSTI, SQL Injection, Information Disclosure
5. Веб-уязвимости: Command Injection, Brute Force, Deserialization
6. Веб-уязвимости: Broken Authentication, DOS, File Upload
Промежуточная аттестация
В конце обучения проводится итоговая аттестация с выдачей сертификата об освоении учебной программы.
На занятиях с преподавателем раскрываются основные понятия и теоретическая база.
Лекции с преподавателем
Особое внимание уделяется практическим знаниям. Слушатели на протяжении всего курса оттачивают изученные навыки.
Практические занятия
После каждого модуля слушатели выполняют домашние задания и получают обратную связь.
Домашние задания
В конце курса участники напишут веб-приложение на Django/Flask вместе с отчетом о его безопасности.

Эффективность курсов доказана результатами участников: более 80% выпускников получили работу в ведущих ИТ-компаниях. Мы работаем с более чем 50 компаниями-партнерами, которые готовы рассмотреть резюме выпускников наших курсов
Эффективность курсов
Курс ведут специалисты высокого уровня, имеющие большой практический опыт работы в индустрии, поэтому на курсе рассматриваются реальные кейсы
Преподаватели
Более 60% учебного плана отводится на выполнение практических проектов и лабораторных работ, максимально приближенных к реальным задачам, с которыми предстоит столкнуться в работе
Практика
Преподаватель ответит на каждый ваш вопрос, объяснит непонятные моменты, даст обратную связь по практическим заданиям
Обратная связь
За каждой учебной группой закреплен куратор, готовый ответить на любые вопросы, поддержать морально и помочь вам в самых разных ситуациях, связанных с обучением
Поддержка и помощь
Наши образовательные программы готовятся специалистами из индустрии. Мы обновляем программы в соответствии с развитием рынка и технологий, поэтому ваше образование будет соответствовать требованиям компаний-работодателей.
