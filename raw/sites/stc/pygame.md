## Расписание курса
![](https://static.tildacdn.com/tild3933-6532-4136-b264-303363366263/Group_277132805.png)
Познакомитесь с языком программирования Python. Установите среду разработки для работы Python. Изучите типы данных Python и их применение в процессе разработки приложения. Начнете использовать строковые методы, операторы ветвления.
Разберетесь в синтаксисе Python. Изучите принципы написания декораторов в языке Python и регулярные выражения
Изучите основы библиотеки Arcade. Начнете реализовывать базовые алгоритмы с использованием стандартных структур управления. Научитесь использовать мультимедиа в библиотеке arcade, создавать дополнительные окна и др.
Изучите основы работы анимации с фигурами в библиотеке PyGame. Начнете реализовывать приложение с использованием пользовательского интерфейса, света, системы частиц.
В конце обучения проводится итоговая аттестация с выдачей сертификата об освоении учебной программы.
На занятиях с преподавателем раскрываются основные понятия и теоретическая база.
Вебинары с преподавателем
Особое внимание уделяется практическим знаниям. Слушатели на протяжении всего курса оттачивают изученные навыки.
Практические занятия
После каждого модуля слушатели выполняют домашние задания и получают обратную связь.
Домашние задания
Результатом обучения станет разработка 2D-игры с анимированным персонажем и реализацией пользовательского интерфейса.
