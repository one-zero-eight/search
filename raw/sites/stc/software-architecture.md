## Преимущество курса

Программа раскрывает такие понятия как:
Основа курса – дисциплина магистерской программы в рамках стратегического партнерства Университета Иннополис и Университета Карнеги-Меллон (США).
Курс также представляет новый подход к "эволюции" устойчивой архитектуры с использованием теории остаточности в архитектуре программного обеспечения Барри М. О'Рейли.
На закрытие каких целей направлен курс?
Понимание сложных программных систем
Научитесь определять ключевые архитектурные структуры, понимать влияние архитектурных факторов на структуру программного обеспечения, понимать принципы архитектурной документации и презентации

Достижение требований к качеству программных систем
Сможете оценивать соответствие архитектурного проекта набору системных требований и компромиссов в отношении качества, научитесь генерировать архитектурные альтернативы в заданном контексте и выбирать между ними
![](https://static.tildacdn.com/tild6630-3866-4665-b365-616632343165/check.png)

- Итеративное улучшение с помощью архитектурных тактик
- Типичные технические и бизнес-ограничения для архитектурной документации
- Важные атрибуты качества архитектурной документации
- Инструменты для изображения различных аспектов архитектурной модели

- Компоненты «изучения проблемного пространства»
- Компоненты «пространства решений»
- Процесс итеративного проектирования
- Знакомство с ключевыми понятиями ADD
- Стадии ADD
- Определение понятия “архитектурная тактика”
- Как связать атрибуты качества с архитектурными тактиками
- Концепция архитектурных паттернов проектирования
- Различные классы паттернов проектирования
- Объектно-ориентированные паттерны (GoF)
- Системы с открытым контуром и системы с закрытым контуром
- Поток данных и компоненты потока данных
- Шаблон Pipes-and-filter
- Вспомните, что несколько доменов из DDD хорошо отображаются на микросервисы
