## Программа обучения
- ИИ и нейросети: основные принципы работы, аналогия с работой мозга: обучение на примерах, обобщение информации и адаптацию к новым данным
- Применение ИИ в разных отраслях. Риски и юридические аспекты защиты авторских прав, информационная безопасность
Ключевые принципы PE (четкость, конкретность, релеватность, консистетность, эмпиризм, итеративность)
- Продвинутые техники Prompt Engineering (краткий обзор, н-р, Few-shot Learning, Chain-of-Thought Prompting, Tree of Thoughts, ReAct,, Self-Consistency, Knowledge Generation)
Основы написания промтов (контекст, роль, формат, ограничения, конкретность)
- Специфика промтов для текстовых моделей
- Язык ввода: Русский vs. Английский и другие
- Трудности перевода (идиомы, культурные отсылки, искажение, «машинный» перевод Формат ответа. Рекомендации по формату ответа: текст, код, изображение
- Тестовые задачи, графические задачи. Галлюцинации в ИИ: виды, причины, как обнаружить, как уменьшить
Практикум по применению PE для анализа своих данных, генерации кода и интерпретации. Промпты для обработки экспериментальных данных.
От научной гипотезы к ИИ-задаче:
- Фреймворк переформулирования исследовательской проблемы в задачу для ИИ (классификация, регрессия, генерация, кластеризация).
- Критерии осуществимости: наличие и качество данных, вычислительная сложность, измеримость результата.
Жизненный цикл исследовательского ИИ-проекта:
- Упрощенная схема: Постановка задачи -> Сбор/разметка данных -> Выбор модели/обучение -> Валидация и интерпретация -> Внедрение в научный процесс.
- Итеративность
Ресурсы и команда:
- Ключевые роли в проекте (исследователь-предметник, data scientist, инженер).
- Вычислительные ресурсы: от Google Colab до университетских кластеров (критерии выбора).
- Данные как главный актив: объем, качество, стратегии разметки.
Управление рисками:
- Технические: "мусор на входе", переобучение, неинтерпретируемость (black box).
- Методологические: неправильная постановка задачи, нерелевантные метрики успеха.
- Ресурсные: нехватка данных, "исчезающие" вычисления.
Практикум: Разбор реальных кейсов из научных исследований; «Гибридный» проект , «Провальный» проект и его причины
- Традиционный подход vs ИИ-подход
- Использование ИИ для генерации гипотез: анализ больших данных, обработка текстов, генерация простых гипотез
- Важность критической оценки, проверка гипотез с помощью ИИ: статистический анализ, машинное обучение, моделирование.
- Ограничения и риски при использовании ИИ для проверки гипотез
- Фактчекинг с ИИ: инструменты для проверки гипотез, фейков, надежности источников и репутации
- Принципы эффективной визуализации: ясность, точность, эстетика. Примеры визуализации для научных публикаций.
- Типы визуализаций: графики (линейные, столбчатые, scatter plot), диаграммы (тепловые, древовидные), инфографика.
- Работа с большими фундаментальными моделями, обрабатывающими изображения, видео, 3D-данные, код.
- Инструменты и сервисы для визуализации
- Создание сложных визуализаций: структурирование запросов, указание формата вывода (JSON, CSV).
- Работа с мультимодальными моделями
- Визуализация для публикаций и презентаций: оптимизация графиков под требования научных публикаций, для печати и носителей в графических редакторах.
