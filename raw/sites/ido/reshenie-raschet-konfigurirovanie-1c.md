О программе
Изучите конфигурирование для автоматизации задач расчета зарплаты и учета персонала. Навыки применимы при конфигурировании «1С:Зарплата и управление персоналом 8». Рекомендуется предварительное прохождение «[Введение в конфигурирование 1С. Основные объекты](https://ido.innopolis.university/vvedenie-konfigurirovanie-1c)». Входит в комплексный курс по программированию 1С.
Результаты обучения
![](https://static.tildacdn.com/tild3861-3337-4062-b263-393439363633/Ellipse_10117.png)
Навыки
Создание и настройка планов видов расчета для раздельного учета начислений и удержаний
Конфигурирование регистров расчета — понимание их логического устройства, структуры полей и настройка под бизнес-задачи
Реализация многошагового сеанса расчета зарплаты с программированием процедур заполнения и записи данных
Разработка документа «Расчет Зарплаты» с алгоритмами первого, второго и третьего шагов расчета
Построение запросов к виртуальным таблицам для получения базы по видам расчета в разрезе необходимых измерений
Создание отчетов по начислениям с использованием механизмов платформы
Обработка корректировок за прошлые периоды — сторнирование, расчет методом «Получить Дополнение», циклы перерасчета
Настройка перерасчетов с использованием стандартных табличных частей и объектной модели «Перерасчет», формирование запросов на пересчет записей
Удостоверение о повышении квалификации + сертификат 1С

Программа
- Строгая периодичность, период регистрации
- Расчетные формулы, базовая зависимость
- Начисления и удержания, период действия, фактический период
- Состав расчетных механизмов платформы
- Техническое задание (первая очередь), исходные данные
- Создание учебной конфигурации
Планы видов расчета, создание плана «Основные Начисления»
- Назначение, логическое устройство, структура полей
- Создание и настройка регистра «Основные Начисления»
Первый, второй, третий шаги, многократность выполнения
- Конфигурирование документа «РасчетЗарплаты»
- Программная работа с регистром расчёта
- Процедура «ЗаполнитьНаборЗаписей», код первого шага
- Особенности метода «Записать»
- Создание документа, ввод вида расчёта «Оклад», проведение
- Код второго и третьего шагов
Создание второй пары объектов
Параметр «Разрезы» виртуальной таблицы «База», разработка запроса
- Невозможность исправления, расчет за прошлый период, сторно
- Средства платформы, метод «Получить Дополнение», цикл обработки
- Зависимость по перерасчету, стандартная табличная часть «Ведущие Виды Расчета»
- Объект «Перерасчет», объектная модель, проблемы реализации
- Запрос для получения записей, подлежащих перерасчету
