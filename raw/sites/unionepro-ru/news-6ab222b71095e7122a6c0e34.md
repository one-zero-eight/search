Открыт набор на бесплатные ИТ-курсы Университета Иннополис для старшеклассников и студентов колледжей
21.09.2026 00:09
![](https://s3-api.unionepro.ru/portal/images/47116242-0f38-4dd4-8a85-4ecb55b76b5a-Frame1321315319.png)
Набор открыт на курсы:
**— Цифровой мозг: разработка ИИ на Python**
Обучение проходит в двух форматах: онлайн и офлайн на 270 площадках по стране. Есть группы для базового и продвинутого уровней подготовки, отдельно для 8—9, 10—11 классов и учащихся колледжей.
На базовом уровне школьники изучат основы искусственного интеллекта и языка программирования Python, обработку и визуализацию данных, а также введение в машинное обучение и создание ИИ-приложений. На продвинутом уровне слушатели освоят ансамблевые алгоритмы, глубокие нейронные сети и трансформеры, попробуют силы в соревнованиях по машинному обучению. В финале каждый участник разработает ИИ-проект для портфолио.
**— Python: от основ к созданию графических приложений**
Офлайн-курс на 270 площадках по стране для студентов колледжей с отдельными группами для базового и продвинутого уровней подготовки.
Программа охватит теорию структуры данных, объектно-ориентированного программирования, работу с программными интерфейсами и инструментами командной разработки. Отдельное внимание преподаватели уделят безопасному использованию ИИ-инструментов при написании кода. В конце обучения участники создадут собственные приложения с графическим интерфейсом.
**— Код защиты: Python для информационной безопасности**
Программа рассчитана на учащихся 8—9 классов и колледжей с базовым и продвинутым уровнями подготовки. Обучение онлайн и офлайн на 270 площадках по стране.
Курс знакомит слушателей с применением Python в задачах цифровой безопасности: обработке журналов событий, поиске подозрительной активности с помощью регулярных выражений, безопасной работе с базами данных и проверкой целостности данных методом хеширования. Группа с базовым уровнем подготовки изучит модели угроз и управление рисками информационной безопасности, Python для анализа безопасности и проверки защищённости. В продвинутой группе слушатели рассмотрят SOC-данные, журналы и аналитику на Python, реагирование на инциденты безопасности и компьютерную криминалистику.
Продолжительность бесплатного обучения зависит от выбранной программы и составляет 144—148 академических часов. Записаться можно только на один курс. Для участия необходимо выбрать программу, подать заявление, дождаться проверки документов и пройти вступительное тестирование.

«Код будущего» — проект по обучению школьников 8—11 классов и студентов колледжей, обучающихся на ИТ-специальностях, на бесплатных курсах по программированию, робототехнике и искусственному интеллекту. Обучение проходит в онлайн- и офлайн-формате. Проект реализуется в рамках федерального проекта «Кадры для цифровой трансформации» национального проекта «Экономика данных».
