1. ВВЕДЕНИЕ

1.1. Область применения
Система представляет собой сервис для работы с персональными данными пользователей

ЕМОП. Основным назначением Системы является обеспечение других сервисов ЕМОП
пользовательскими данными и создание защищенной коммуникации внутри Системы.

1.2. Краткое описание возможностей
Система обеспечивает выполнение следующих основных функций:
­ регистрация новых пользователей ЕМОП;
­ авторизация зарегистрированных пользователей;
­ переадресация неавторизованных пользователей;
­ хранение и управление персональными данными зарегистрированных пользователей.

1.3. Уровень подготовки пользователя

Для эксплуатации Системы пользователю необходимо обладать базовой подготовкой
пользователя персонального компьютера.

1.4. Перечень эксплуатационной документации, с которой необходимо ознакомиться
пользователю
Пользователю необходимо ознакомиться со следующей документацией:
­ Руководство администратора Системы;
­ настоящее Руководство пользователя Системы.

2. НАЗНАЧЕНИЕ И УСЛОВИЯ ПРИМЕНЕНИЯ

2.1. Виды деятельности, функции, для автоматизации которых предназначена Система

Система позволяет:
­ автоматизировать сбор общей персональной информации пользователей;
­ обеспечить взаимодействие с внутренними сервисами ЕМОП, а также с интегрированными
в ЕМОП информационными системами, в частности порталом Единой системы идентификации и
аутентификации (далее – ЕСИА).

2.2. Условия, при соблюдении которых обеспечивается применение Системы
в соответствии с его назначением

Техническое обеспечение, а именно аппаратно-программные средства Системы должны
отвечать следующим требованиям:
­ процессор: не менее 4 процессоров на устройстве, частотой не менее 2 ГГц;
­ оперативная память: не менее 16 Гб;
­ жесткий диск: не менее 500 Гб свободного дискового пространства;
­ операционная система: Windows 10 или выше;
­ браузер: Google Chrome 106.0.5249.119 и выше.

4. ОПИСАНИЕ ОПЕРАЦИЙ

4.1. Авторизация
Для авторизации в Системе необходимо открыть в браузере стартовую страницу и нажать
кнопку «Вход» в правом верхнем углу экрана (см. Рис. 1).
Стартовая страница, кнопка «Вход»

Рис. 1
Пользователю доступны три способа авторизации:
­ по коду верификации, высылаемому на номер телефона;
­ по коду верификации, высылаемому на e-mail;
­ по логину (номеру телефона или e-mail) и паролю.

4.1.1. Авторизация по коду верификации, высылаемому на номер телефона
Для получения кода верификации на номер телефона, указанный при регистрации,
пользователю необходимо указать данные в поле «Введите номер телефона» вкладки «Авторизация
по номеру телефона» окна авторизации в Системе и нажать кнопку «Продолжить» (см. Рис. 2).

Окно авторизации, вкладка авторизации по коду верификации

Рис. 2

Если в Системе находится зарегистрированный с указанным номером телефона
пользователь, то Система отправляет SMS-сообщение со сгенерированным кодом на номер, и
пользователю открывается окно ввода кода (см. Рис. 3).

Окно ввода кода верификации

Рис. 3

Если пользователь ошибся при вводе номера телефона, ему необходимо нажать кнопку
«Изменить номер» и ввести номер телефона заново.

Если SMS-сообщение не пришло на указанный номер телефона в течение 2 минут,
пользователю необходимо проверить корректность введенного номера и нажать кнопку «Отправить
SMS-сообщение с кодом» для повторной отправки кода.

После получения SMS-сообщения с кодом пользователю необходимо ввести его
в соответствующие поля и нажать кнопку «Отправить». Если код введен корректно, пользователь
успешно авторизуется в Системе.

4.1.2. Авторизация по коду верификации, высылаемому на e-mail
Авторизация по коду верификации, высылаемому на e-mail, осуществляется способом,
описанным в п.п. 4.1.1. настоящего документа.

4.1.3. Авторизация по логину и паролю
Для авторизации по логину и паролю, пользователю необходимо указать данные
в соответствующих полях вкладки «Авторизация по паролю» окна авторизации в Системе и нажать
кнопку «Войти» (см. Рис. 4).

Окно авторизации, вкладка авторизации по паролю

Рис. 4
Если пара логин-пароль введен корректно, пользователь успешно авторизуется в Системе.
Если пользователь забыл пароль, необходимо нажать кнопку «Забыли пароль?»;
пользователю будет отображено окно сброса пароля (см. Рис. 5).

Окно сброса пароля

Рис. 5

Для сброса пароля пользователю необходимо ввести номер телефона, указанный при
регистрации, и нажать кнопку «Отправить». Если в Системе находится зарегистрированный
с указанным номером телефона пользователь, то на указанный при регистрации e-mail будет
направлена ссылка для сброса пароля.

Для выхода из Системы после авторизации необходимо перевести курсор мыши на имя

с Системой пользователю нужно будет повторно авторизоваться.

5. АВАРИЙНЫЕ СИТУАЦИИ

5.1. Действия в случае несоблюдения условий выполнения технологического процесса,
в том числе при длительных отказах технических средств

Надежность аппаратной платформы сервера и рабочих станций, операционных систем
серверов и рабочих станций, систем управления базами данных обеспечивается их
производителями.

Надежность аппаратного средства пользователя также обеспечивается его производителем.
Во избежание потери информации, вводимой пользователем, рекомендуется при вводе
большого количества данных выполнять процедуру их сохранения в процессе ввода.

5.2. Действия по восстановлению программ и/или данных при отказе магнитных носителей
или обнаружении ошибок в данных

Выполнение процедуры восстановления программ и/или данных может быть необходимо по
причинам:

­ системного сбоя, который привел к полной или частичной потери данных или нарушению
работы программы;

­ по причине неверных действий пользователя, которые привели к изменению/потери
данных;
­ нарушению работы программы.
В случае необходимости восстановления программ и/или данных системный администратор
проводит процедуру восстановления с резервного носителя.
5.3. Действия в случаях обнаружении несанкционированного доступа к данным
В случаях обнаружения несанкционированного вмешательства в данные необходимо,
не совершая никаких действий в интерфейсе пользователя, сообщить о факте вмешательства
системному администратору.

5.4. Действия в других аварийных ситуациях

При возникновении других аварийных ситуаций пользователю не рекомендуется
самостоятельно пытаться восстановить работоспособность Системы. В случае возникновения
аварийной ситуации необходимо проинформировать системного администратора Системы и/или
обратиться в службу технической поддержки.

6. РЕКОМЕНДАЦИИ ПО ОСВОЕНИЮ

Для успешной эксплуатации Системы пользователю необходимо обладать базовыми
навыками работы с персональным компьютером (или другим аппаратным средством, на котором
осуществляется работа с Системой), а также выбранным браузером.

Перед началом работы необходимо внимательно ознакомиться с документацией,
перечисленной в п.1.4. настоящего документа.
