Месячный курс по программированию на Python
Старт 29 июня
регистрация →
Занятия будут проходить в группах по уровням: начинающие и продолжающие. Школьников ждёт программа из 24 астр. часов, домашние задания, собственный проект на выходе и сертификат о прохождении курса.
Участники курса освоят язык Python, будут работать с переменными, функциями, массивами, циклами и библиотеками. Познакомятся с системой контроля версий Git, научатся писать ботов и поисковых роботов.
А еще узнают про концепцию ООП, про алгоритмы, сортировку и многое другое. Самое классное это проект,
который участники сделают сами.
Месячный курс по программированию 2D игр на Python
Старт 5 июля
регистрация →
Программа курса состоит из 16 астр. часов с домашними задания, в результате школьники разработают собственные 2D игры и получат сертификат.
Участники изучат библиотеку для разработки двухмерных игр и язык программирования Python.
Данный курс станет отличным стартом для карьеры game–разработчика.
