The diagram illustrates the main stages of the 'Digital Departments' project road map, organized into two parallel horizontal tracks. Each track consists of five vertical boxes representing tasks, connected by large right-pointing arrows indicating the flow of the process.

Top Track (Red):

  • Task: Разработка/актуализация концептуальных документов проекта. Responsible: Университет Иннополис.
  • Task: Направление концепции и рекомендации вузам-участникам. Responsible: Минобрнауки России.
  • Task: Подписание/актуализация соглашений. Responsible: Университет Иннополис, вузы-участники.
  • Task: Разработка/актуализация ДПП для обучения на «цифровых кафедрах». Responsible: Вузы-участники.
  • Task: Согласование программ на актуальность отрасли. Responsible: Вузы-участники, Минцифры.

Bottom Track (Purple):

  • Task: Зачисление студентов на ДПП для обучения на «цифровых кафедрах». Responsible: Вузы-участники.
  • Task: Формирование макета программы ДПП на платформе Университета Иннополис. Responsible: Университет Иннополис, вузы-участники.
  • Task: Проведение комплексной оценки (ассесмента). Responsible: Университет Иннополис.
  • Task: Проведение итогового ассесмента. Responsible: Университет Иннополис.
  • Task: Проведение итоговой аттестации студентов. Responsible: Вузы-участники.
