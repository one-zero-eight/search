Разбор задачи «Лист бумаги»

0.1 Полное решение
Всего два положения открыток, разберем каждый:

• Если располагать открытоки вертикально, то по ширине листа умещается w x открыток, а по
высоте h y . Значит всего открыток таким расположением можно добиться w x · h y .

• Если располагать открытоки горизонтально, то по ширине листа умещается h x открыток, а
по высоте w y . Значит всего открыток таким расположением можно добиться h x · w y .

Ответом будет являться наибольшее из двух чисел, то есть max( w x · h y , h x · w y ).
Разбор задачи «Баскетбольный турнир»

0.2 Постановка задачи
Надо научиться разделять две ситуации.

0.3 Полное решение

• Если команды играли круговой турнир, то общее количество матчей будет равно n·(n2−1). Соответственно, суммарное количество побед будет n·(n2−1).

• Если команды играли олимпийскую систему, то общее количество матчей будет равно n − 1.
Соответственно, суммарное количество побед будет n − 1.

Посчитаем суммарное количество побед. Если оно будет равно n·(n2−1), то ответом будет Roundrobin, иначе Olympic.

Разбор задачи «Лифт»

Данная задача связана с моделированием и реализацией функционирования лифтов.
Необходимо провести моделирование работы каждого лифта, разберем основные моменты в реализации:

1. Предположим, что лифт заполняется полностью людьми, которым необходимы этажи с номерами a1,...,ac, и Тимура в лифте нет. Тогда время развозки людей представляет собой сумму
времени, затраченного на остановки на каждом этаже, поездку до максимального этажа и
спуск до первого этажа.

a) Общее количество различных остановок равно количеству уникальных чисел среди
a1,...,ac, обозначим это как cnt_diff. Тогда время, затраченное на остановки на этажах, составляет h · cnt_diff.

b) Время, затраченное на поездку до максимального этажа, равно
lift_time · (max(a1,...,ac) − 1).

c) Время, затраченное на спуск до первого этажа, также равно
lift_time · (max(a1,...,ac) − 1).

В итоге, время развозки людей равно h · cnt_diff + 2 · lift_time · (max(a1,...,ac) − 1).

2. Предположим, что лифт заполняется людьми, которым нужны этажи с номерами a1,...,at,n,
и в лифте присутствует Тимур (которому нужен этаж с номером n).

a) Если лифт посещает этаж n, то время на поездку до этого этажа будет равно сумме времени, затраченного на остановки на этажах до n и времени поездки до n. Количество остановок до этажа n определяется как количество уникальных чисел среди
a1,...,at, меньших n, обозначим это число как q. Время, затраченное на поездку до
этажа n, равно (n − 1) · lift_time. Таким образом, время развозки людей составляет
(q + 1) · h + (n − 1) · lift_time (к q прибавили 1, так как Тимур выходит на n этаже).

b) Если лифт не посещает этаж n, то запустим алгоритм из пункта a) для этажей n − 1
и n + 1 соответственно. В первом случае добавим к ответу timur_up_time, во втором
случае добавим к ответу timur_down_time.

Необходимо также учесть случай, когда Тимур поднимается на n этаж пешком.

Разбор задачи «Треугольники»

Для решения подзадачи, где n 200, достаточно перебрать все тройки чисел 1 a < b < c n,
и для каждой тройки проверить, что a + b > c. Такие решение набирает 10 баллов.

Чтобы ускорить решение, заметим, что при фиксированных 1 a < b n нам подходят все c из
отрезка [b + 1,min(n,a + b − 1)]. Значит, достаточно перебрать a,b и для каждой пары прибавить к
ответу количество подходящих c, то есть max(0,min(n,a + b − 1) − b).

Для дальнейшей оптимизации заметим, что при фиксированном a у нас есть несколько интересных отрезков b. Первый из них соответствует решению неравенства a + b − 1 n ⇔ b n − a + 1.
Второй — a + b − 1 > n ⇔ b > n − a + 1. Не будем забывать, что a + 1 b n, то есть на самом деле
отрезки выглядят так: b ∈ [a + 1,n − a + 1] и b ∈ [max(a + 1,n − a + 2),n]. Для каждого b из первого
отрезка нужно прибавить к ответу a − 1. А для каждого b из второго отрезка значение n − b.

Теперь заметим, что при a n2 первый отрезок остается b ∈ [a + 1,n − a + 1], а второй
[n−a+2,n]. Для начала рассмотрим этот случай. Тогда для фиксированного a нужно прибавить к
ответу (n − 2 · a + 1) · (a − 1) + n−a+2 b n[n − b] = (n − 2 · a + 1) · (a − 1) + (a − 1) · n − n−a+2 b n b.
Обозначим f(i,j) сумму натуральных чисел от i до j включительно. Тогда для каждого 1 a n2
нужно прибавить к ответу (2 · n − 2 · a + 1) · (a − 1) − f(n − a + 2,n).

Для случая, когда a > n2, первый отрезок вырождается в пустой, в остальном случай разбирается
аналогично.

Теперь мы получили выражение, зависящее только от a. Нетрудно видеть, что при раскрытии
скобок полученное значение можно выразить через f, а также сумму 1 i k i2 = k·(k+1)6·(2·k+1). В
итоге получается следующая формула n·(n+2)24·(2·n−5). Чтобы посчитать значение по модулю 109 + 7
в языкам без встроенной поддержки длинной арифметики, можно использовать расширения некоторых компиляторов, например __int128_t в g + +.
