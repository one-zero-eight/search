Решение задачи «Вернись с сокровищами»

Концепция обучения агента

Для решения задачи навигации в динамическом лабиринте был разработан скрипт обучения
train_and_export.py, основанный на алгоритме Q-learning с модификациями для учета
специфики среды:

Основные принципы обучения:

1. Адаптивное исследование среды:
o Используется epsilon-greedy стратегия с экспоненциальным затуханием ε
o Начальное ε = 1.0 (полное исследование) → конечное ε = 0.05 (минимальное
исследование)
o Коэффициент затухания: 0.9995 на эпизод

2. Учет временных ограничений:
o Каждый эпизод ограничен 80 шагами
o Шаговая награда -0.1 стимулирует быстрый сбор сокровищ

3. Обработка динамических элементов:
o Динамические стены (15% вероятность изменения) учитываются через
многократное обучение
o Ловушки с большим отрицательным штрафом (-5) быстро снижают Q-значения
опасных действий

4. Оптимизация маршрута:
o Разделение задачи на подзадачи: сбор сокровищ → возвращение домой
o Q-таблица хранит состояния в формате "позиция|оставшиеся_сокровища"

Алгоритмические особенности:

import numpy as np
import random
class Agent:
"""
Финальный агент с замороженной Q-таблицей.
Обучение проведено на 10000 эпизодах с параметрами:

- alpha (learning_rate) = 0.1 (во время обучения)

- gamma (discount_factor) = 0.9

- epsilon_decay = 0.9995
"""
def __init__(self):
self.actions = [0, 1, 2, 3] # 0=up, 1=right, 2=down, 3=left
# Замороженные параметры после обучения
self.epsilon = 0.05 # Минимальное исследование
self.learning_rate = 0.0 # Обучение отключено
self.discount_factor = 0.0 # Не используется
# Обученная Q-таблица (сокращенный вид)
self.q_table = {

# Позиция (0,0) с 3 оставшимися сокровищами

'0,0|3': [22.85, 22.47, 25.11, 22.85],
# Позиции около первого сокровища (1,5)

'1,4|3': [36.82, 41.02, 36.82, 37.96],

'1,5|2': [29.27, 32.65, 30.02, 29.27],
# Позиции около второго сокровища (3,7)

'3,6|2': [0.00, 17.61, 0.00, 0.00],

'3,7|2': [0.00, -0.30, -0.03, 4.57],

# Позиции около третьего сокровища (6,4)
'6,4|1': [0.00, 9.30, 0.00, -0.30],
'6,4|0': [30.77, 27.58, 27.58, 28.23],
# Критические позиции (ловушки)

'2,6|3': [-5.00, -5.00, -5.00, -5.00], # Ловушка (2,6)
'7,5|3': [-5.00, -5.00, -5.00, -5.00], # Ловушка (7,5)
# Возвращение домой после сбора всех сокровищ

'0,0|0': [0.00, 0.00, 0.00, 0.00],

'1,0|0': [50.00, 46.50, 44.93, 46.50],

'2,0|0': [47.40, 44.03, 42.58, 44.03],

}
# Статистика для отладки
self.total_steps = 0
self.total_reward = 0
def _state_to_key(self, observation):
"""
Преобразует матрицу наблюдения в ключ для Q-таблицы.
Формат: "x,y|оставшиеся_сокровища"
"""
# Поиск позиции агента (значение 4 в матрице)
agent_pos = np.where(observation == 4)
if len(agent_pos[0]) > 0:
pos_key = f"{agent_pos[0][0]},{agent_pos[1][0]}"
else:
# Если агент не найден (стартовая позиция)
start_pos = np.where(observation == -1)
if len(start_pos[0]) > 0:
pos_key = f"{start_pos[0][0]},{start_pos[1][0]}"
else:
pos_key = "0,0"

# Подсчет оставшихся сокровищ (значение 2)
treasures_left = np.sum(observation == 2)
return f"{pos_key}|{treasures_left}"
def choose_action(self, state):
"""
Выбирает действие на основе обученной Q-таблицы.
Использует epsilon-greedy стратегию с минимальным исследованием.
"""
observation = state['observation']
state_key = self._state_to_key(observation)

# Если состояние неизвестно (не встречалось при обучении)
if state_key not in self.q_table:
return random.choice(self.actions)

# С вероятностью epsilon выбираем случайное действие
if random.random() < self.epsilon:
return random.choice(self.actions)
else:
# Выбираем действие с максимальным Q-значением
q_values = self.q_table[state_key]
max_q = max(q_values)
best_actions = [i for i, q in enumerate(q_values) if q == max_q]
return random.choice(best_actions)
def learn(self, state, action, reward, next_state, done):
"""
Метод оставлен для совместимости.
В финальной версии обучение отключено.
"""
self.total_steps += 1
self.total_reward += reward

Решение задачи «Охотник за сокровищами»

Данная задача носит творческий характер и не имеет единственного правильного решения.
Участникам предлагается разработать агента, способного действовать в условиях частичной
наблюдаемости, динамических угроз и ограниченного времени. Ниже рассмотрены основные
подходы к решению, а также детали реализации на основе обучения с подкреплением.

Обзор возможных подходов

Эвристический подход

Эвристический подход основан на заранее заданных правилах и алгоритмах. Агент может
использовать алгоритмы поиска пути (например, A* или Dijkstra) для нахождения
кратчайших маршрутов к сокровищам и обратно на стартовую позицию. При этом
необходимо реализовать систему приоритетов, которая учитывает ценность сокровищ,
расстояние до них и близость ловушек. Для работы в условиях ограниченной видимости
агент должен сохранять внутреннюю карту, обновляя её по мере исследования. Основное
достоинство этого подхода — предсказуемость и отсутствие необходимости в длительном
обучении. Однако создание устойчивых эвристик для динамической среды с двигающимися
ловушками может оказаться сложной задачей.

Обучение с подкреплением

Подход на основе обучения с подкреплением предполагает, что агент обучается методом
проб и ошибок, максимизируя суммарную награду. Среда формулируется как частично
наблюдаемый марковский процесс (POMDP), где агенту доступно только локальное
наблюдение размером 5×5. Для обучения могут использоваться алгоритмы глубокого
обучения с подкреплением, такие как DQN или PPO. Агент обучается на множестве эпизодов,
постепенно улучшая свою политику. Этот подход способен находить неочевидные стратегии
и адаптироваться к динамике среды, но требует значительных вычислительных ресурсов и
времени на обучение.

Гибридный подход

Гибридный подход комбинирует достоинства эвристических методов и обучения с
подкреплением. Высокоуровневое планирование (выбор целей, построение маршрута) может
осуществляться с помощью эвристик, а низкоуровневые решения (обход ловушек, реакция на
угрозы) — с помощью обученной модели. Такая архитектура повышает стабильность работы
агента и снижает время обучения.

class MemoryMap:
def __init__(self, size=15):
self.size = size
self.map = np.full((size, size), -1, dtype=np.float32)
self.explored = np.zeros((size, size), dtype=bool)
def update(self, agent_pos, observation):
# Обновление карты на основе локального наблюдения
vision_size = observation.shape[0]
offset = vision_size // 2
for i in range(vision_size):
for j in range(vision_size):
world_i = agent_pos[0] + (i - offset)
world_j = agent_pos[1] + (j - offset)
if 0 <= world_i < self.size and 0 <= world_j < self.size:
cell_value = observation[i, j]
if cell_value != -1:
self.map[world_i, world_j] = cell_value
self.explored[world_i, world_j] = True
