Задача G. Прямая кинематическая задача для
плоского манипулятора (2 звена, плоскость XZ)

Условие задачи

Рассматривается плоский робот-манипулятор, состоящий из двух жёстких звеньев длиной L1 и L2, соединённых шарнирами. Первое звено закреплено в начале координат
O = (0,0) и может вращаться в плоскости XZ.

Система координат:

• ось X направлена горизонтально вправо;

• ось Z направлена вертикально вверх.
Углы задаются следующим образом:

• угол α — от горизонтали (оси X) к первому звену L1 (0◦ ≤ α ≤ 135◦);

• угол β — угол между звеньями L1 и L2 (20◦ ≤ β ≤ 300◦), как на рисунке.

Комментарий к углу β

При таком определении:

• β = 0◦ — направлено в точности в сторону, противоположную направлению L1;

• 0◦ < β < 180◦ — L2 уходит “вниз” относительно линии продолжения L1 (как на
рисунке);

• β = 180◦ — L2 звенья выпрямлены, L2 продолжает L1;

• β > 180◦ — L2 “перебрасывается” на другую сторону и уходит “вверх” относительно
линии продолжения L1.

Связь β с абсолютным углом второго звена. Угол β в этой задаче задаётся
в вершине A между звеноv L1 и звеном L2. Поэтому абсолютный угол второго звена
относительно оси oX равен
φ2 = α + β − 180◦
(в радианах: φ2 = α + β − π).

Интуитивная проверка по крайним положениям:
β = 180◦ ⇒ φ2 = α (L2 продолжает L1), β = 0◦ ⇒ φ2 = α ± 180◦ (L2 сложено назад).

звена L2 к горизонтали s.

Требуется найти координаты конца второго звена (x,z).

Входные данные

Во входной поток подаются четыре вещественных числа:

где L1,L2 — длины звеньев, α,β — углы в градусах.

Выходные данные

Вывести два числа — координаты (x,z) конца второго звена. Ответ округлить до 3
знаков после запятой.

Пример

Работаем в плоскости XZ с координатами (x,z).

Дополним приложенный эскиз перпендикуляром из конца первого звена (точка A)

// Прямая кинематическая задача для манипулятора из 2х звеньев на XZ плоскости
#include <iostream>
#include <cmath>
#include <iomanip>
using namespace std;
int main() {
double L1, L2, alphaDeg, betaDeg;
cin >> L1 >> L2 >> alphaDeg >> betaDeg;

}

// alpha: от оси X до первого звена
double alpha = alphaDeg * M_PI / 180.0;
// beta: угол между L1 и L2 (как показано на рисунке)
double beta = betaDeg * M_PI / 180.0;

// окончание первого звена
double x1 = L1 * cos(alpha);
double z1 = L1 * sin(alpha);

// абсолютный угол второго звена
double phi2 = alpha + beta - M_PI;

// окончание второго звена
double x = x1 + L2 * cos(phi2);
double z = z1 + L2 * sin(phi2);
cout << fixed << setprecision(3)

<< x << ” ” << z << endl;
return 0;

Типичные ошибки

• забыли перевести градусы в радианы;

• неверно вычислили φ2 (нужно α + β - 180);

• использовали β как абсолютный угол вместо угла между звеньями;

• неверно интерпретировали ось Z (должна быть вертикальной).

Задача H. Прямая кинематическая задача с
вращающейся базой (3 степени свободы)

Условие задачи

Рассматривается робот-манипулятор, состоящий из:

• вертикальной вращающейся базы высотой h;

• двух звеньев длинами L1 и L2, расположенных в плоскости.
База может вращаться вокруг вертикальной оси OZ на угол γ (−90◦ ≤ γ ≤ 90◦).
В плоскости, связанной с базой, расположены два звена:

• первое звено поворачивается на угол α от оси OX (0◦ ≤ α ≤ 135◦);

• второе звено отклоняется на угол β от первого (20◦ ≤ β ≤ 300◦);

• абсолютный угол второго звена (наклон L2 к оси s): φ2 = α + β − 180◦.

Требуется найти координаты рабочего органа (x,y,z) в декартовой системе координат по известным размерам манипулятора и углам его звеньев.

Теоретическое объяснение

Рассматривается манипулятор с двумя звеньями в плоскости sZ и поворотом этой плоскости вокруг оси Z на угол γ.

• Ось s — горизонтальная ось в плоскости sZ, полученная как проекция манипулятора на плоскость XY .

• Ось Z направлена вертикально вверх.

• Угол γ — угол в плоскости XY от оси X до оси s.

• Угол α — угол от горизонтали (оси s) к первому звену L1 в плоскости sZ.

• Угол β — угол между самим звеном L1 и звеном L2, измеренный так, как
показано стрелкой на эскизе:

– при 0◦ ≤ β ≤ 180◦ звено L2 отклонено вниз относительно линии продолжения
L1;

– при β > 180◦ звено L2 отклонено вверх.

Таким образом, β — это “локальный” угол в суставе, удобный для визуализации и
ограничения в задаче, но не совпадает с углом наклона второго звена относительно
оси Os.

Формулы прямой кинематики в плоскости sZ

Работаем сначала в плоскости sZ с координатами (s,z), где

• s — координата вдоль оси s (горизонталь),

• z — высота вдоль оси Z.

Вершина колонны:

H = (0, h).

Первое звено L1 имеет угол α от горизонтали, поэтому координаты точки A (конца
L1):
sA = L1 cosα, zA = h + L1 sinα.

Второе звено L2 образует с первым звеном угол β как это показано на рисунке. Поскольку β отсчитывается от направления L1 и полный угол под верхней пунктирной
линией составляет 180◦=α+β+φ2, то абсолютный угол наклона второго звена относительно оси s:
φ2 = α + β − 180◦.
Координаты точки B (конец L2) в плоскости sZ:
sB = sA + L2 cosφ2,
zB = zA + L2 sinφ2.

Переход к глобальным координатам (x,y,z)

Ось s — это повёрнутая на угол γ ось X в плоскости XY . Поэтому, зная (sB,zB), получаем:
x = sB cosγ, y = sB sinγ, z = zB.
Итого:
sA = L1 cosα,
zA = h + L1 sinα,
sB = sA + L2 cosφ2, где φ2 = α + β − 180◦,
zB = zA + L2 sinφ2,
x = sB cosγ,
y = sB sinγ,
z = zB.

Все углы в формулах должны быть переведены в радианы:

Пример реализации на C++

Ниже приведён код прямой кинематики с учётом именно такой геометрии задания углов,
как на эскизах.

#include <iostream>
#include <cmath>
#include <iomanip>
using namespace std;
int main() {
double L1, L2, h;
double alphaDeg, betaDeg, gammaDeg;
cin >> L1 >> L2 >> h ;
cin >> alphaDeg >> betaDeg >> gammaDeg;
double alpha = alphaDeg * M_PI / 180.0; // от горизонтали (оси s) к L1
double beta = betaDeg * M_PI / 180.0; // угол между L1 и L2, как на рисунке
double gamma = gammaDeg * M_PI / 180.0; // угол между осями X и s

// Координаты конца первого звена в плоскости sZ
double sA = L1 * cos(alpha);
double zA = h + L1 * sin(alpha);
// Абсолютный угол второго звена в плоскости sZ
double phi2 = alpha + beta - M_PI; // = alpha + beta - 180° (абсолютный угол L2)
// Координаты конца второго звена в плоскости sZ
double sB = sA + L2 * cos(phi2);
double zB = zA + L2 * sin(phi2);
// Переход к глобальным координатам X, Y, Z

}
double x = sB * cos(gamma);
double y = sB * sin(gamma);
double z = zB;
cout << fixed << setprecision(3)

<< x << ” ” << y << ” ” << z << endl;
return 0;

Пример прямой кинематики

Рассмотрим параметры:

L1 = 3, L2 = 2, h = 2,
α = 45◦, β = 75◦, γ = 45◦.

1. Конец первого звена
sA = L1 cosα = 3 · 0.7071 = 2.121,
zA = h + L1 sinα = 2 + 3 · 0.7071 = 4.121.

2. Абсолютный угол второго звена
Так как угол β отложен от самого звена L1, абсолютный наклон второго звена:
φ2 = α + β − 180◦ = 45◦ + 75◦ − 180◦ = −60◦.

3. Конец второго звена
sB = sA + L2 cos(φ2) = 2.121 + 2 · 0.5 = 3.121,
zB = zA + L2 sin(φ2) = 4.121 + 2(−0.8660) = 2.389.

4. Переход в глобальные координаты
x = sB cosγ = 3.121 · 0.7071 = 2.207,
y = sB sinγ = 3.121 · 0.7071 = 2.207,
z = zB = 2.389.

Итог

(x, y, z) = (2.207, 2.207, 2.389)

Задача I. Обратная кинематическая задача с
вращающейся базой (3 степени свободы)

Условие задачи

Рассматривается тот же робот-манипулятор, что и в задаче H:

• вертикальная вращающаяся база высотой h;

• два звена длиной L1 и L2, работающих в плоскости sZ;

• поворот рабочей плоскости вокруг оси Z на угол γ (−90◦ ≤ γ ≤ 90◦);

• первое звено L1 в плоскости sZ наклонено на угол α от оси s (0◦ ≤ α ≤ 135◦);

• второе звено L2 образует с первым звеном угол β (угол между звеньями, как на
эскизе) (20◦ ≤ β ≤ 180◦).
Точка O находится в основании колонны. В глобальной системе координат XY Z:

• ось Z направлена вверх;

• оси X и Y лежат в горизонтальной плоскости;

• ось s — это ось X, повёрнутая на угол γ в плоскости XY .

Прямая кинематика (задача H) по заданным L1,L2,h,α,β,γ позволяет найти координаты конца второго звена (x,y,z).

В этой задаче требуется решить обратную задачу:

По известным L1,L2,h и заданной точке (x,y,z) найти такие углы γ, α и β,
чтобы конец второго звена оказался в точке (x,y,z).

Считаем, что точка достижима и робот работает в конфигурации “локоть вниз”, то
есть выбираем решение с 0◦ ≤ β ≤ 180◦.

Рис. 2: Геометрия для вывода формулы угла α в плоскости sZ′

Шаг 1. Переход к плоской задаче в координатах (s,z′). Пусть требуется достичь
точки с координатами (x,y,z). Переходим к плоским координатам:
s = √x2 + y2, z′ = z − h,
то есть в плоскости sZ′ точка
B = (s,z′).
Обозначим P — проекцию точки B на ось s (как на рисунке), тогда OP = s, PB = z′.
Угол наклона стороны OB относительно оси s равен
δ = atan2(z′,s).

Шаг 2. Выделяем вспомогательный угол ψ в вершине O. Рассмотрим треугольник OAB со сторонами
OA = L1, AB = L2,
и известным углом при вершине A:
̸ OAB = β.
Введём угол ψ в вершине O между сторонами OB и OA (на рисунке он обозначен ψ).
Тогда из геометрии (см. рисунок) угол стороны OA относительно оси s равен сумме:
α = δ + ψ.

Шаг 3. Находим ψ. Опустим из точки B перпендикуляр на прямую, содержащую
сторону OA, и обозначим основание перпендикуляра через K (см. рисунок). Тогда

BK ⊥ OA, O,K,A находятся на одной прямой, ̸ OKB = 90◦.

Подчеркнём: точка K может оказаться как на отрезке OA, так и на его продолжении
(выше точки A или “за” точкой O). Дальнейшие формулы корректны во всех случаях.

1) Выражаем BK через L2 и β. В прямоугольном треугольнике ABK угол при вершине A равен β (это угол между сторонами AO и AB, как на рисунке), поэтому
BK = L2 sinβ.
Эта формула не зависит от того, где расположен K на прямой OA.

2) Выражаем ориентированную величину OK (со знаком). Чтобы избежать неоднозначностей (например, когда K лежит на продолжении OA), вводим ориентированную величину OK как проекцию вектора −−→OB на направление −→OA:

OK = projOA(OB).
Из разложения −−→OB = −→OA + −→AB получаем:
projOA(OB) = projOA(OA) + projOA(AB).
Здесь
projOA(OA) = L1, projOA(AB) = −L2 cosβ,
поскольку угол между направлением AB и направлением AO равен β, а направление
AO противоположно направлению OA. Поэтому ориентированная проекция равна

OK = L1 − L2 cosβ.

Если K оказывается “за” точкой O, то OK < 0; если K оказывается выше точки A, то
OK > L1. В обоих случаях формула остаётся верной (именно благодаря ориентации).

3) Находим ψ из прямоугольного треугольника OBK. По построению BK ⊥ OA
и OK ∥ OA, значит в прямоугольном треугольнике OBK угол ψ (угол между сторонами
OB и OA) равен углу между сторонами OB и OK. Тогда корректно во всех четвертях:
ψ = atan2(BK, OK).
Подставляя пункты 1)–2), получаем универсальную формулу:
ψ = atan2(L2 sinβ, L1 − L2 cosβ).

4) Итог для α. Так как (по рисунку) α = δ + ψ, где δ = atan2(z′,s), окончательно:
α = atan2(z′,s) + atan2(L2 sinβ, L1 − L2 cosβ).

Шаг 4. Итоговая формула для α. Подставляя выражение для ψ в формулу α =
δ + ψ, получаем:
α = atan2(z′,s) + atan2(L2 sinβ, L1 − L2 cosβ).

Комментарий. В некоторых источниках формулу пишут как α = δ ± ψ (две конфигурации). В данной задаче используется именно та конфигурация, которая показана на
рисунке, поэтому берётся сумма α = δ + ψ.

Итоговый алгоритм решения обратной задачи

Дано: L1, L2, h и точка (x,y,z).

1. Вычислить угол поворота основания:
γ = atan2(y,x).
Если x = 0 и y = 0, можно положить γ = 0.

2. Перейти к плоскости sZ′:
s = √x2 + y2, z′ = z − h.

3. Вычислить расстояние до точки в плоскости:

Проверить достижимость:

|L1 − L2| ≤ d ≤ L1 + L2.
Если условие не выполняется, решения нет.

4. Найти угол β:

, β = arccos(cosβ),
где перед arccos следует ограничить cosβ в диапазон [−1,1] (из-за погрешностей).

Пример решения на C++

Ниже приведён пример решения на C++.
#include <iostream>
#include <cmath>
#include <algorithm>
using namespace std;
int main() {
double L1, L2, h;
double x, y, z;
cin >> L1 >> L2 >> h;
cin >> x >> y >> z;

// 1) gamma
double gamma = 0.0;
if (fabs(x) > 1e-12 || fabs(y) > 1e-12) {
gamma = atan2(y, x);
}

// 2) s, z'
double s = hypot(x, y);
double zp = z - h;

// 3) d и возможность дойти до координаты
double d = hypot(s, zp);
if (d > L1 + L2 + 1e-12 || d < fabs(L1 - L2) - 1e-12) {
cout << ”NO SOLUTION\n”;
return 0;
}

// 4) beta
double cosBeta = (L1*L1 + L2*L2 - d*d) / (2.0 * L1 * L2);
cosBeta = max(-1.0, min(1.0, cosBeta));
double beta = acos(cosBeta);

// 5) alpha = delta + psi (как на рисунке в задаче)
double delta = atan2(zp, s);
double psi = atan2(L2 * sin(beta), L1 - L2 * cos(beta));
double alpha = delta + psi;

// 6) условия определения абсолютного угла фи_2
double phi2 = alpha + beta - M_PI;

// output in degrees (по условиям задачи)
auto deg = [](double rad){ return rad * 180.0 / M_PI; };
cout.setf(ios::fixed);
cout.precision(3);
cout << ”gamma=” << deg(gamma)

<< ” alpha=” << deg(alpha)
<< ” beta=” << deg(beta)
// для отладки можно добавить вывод угла фи_2 << ” phi2=” << deg(phi2)
<< ”\n”;
return 0;
}

Типичные ошибки

• Забыли вычесть высоту базы h и сразу искали углы по точке (s,z) вместо (s,z′).

• Перепутали порядок углов при выводе (например, сначала α, потом γ).

• Забыли перевести углы из радиан в градусы перед выводом.

• Перепутали знак в формуле теоремы косинусов для β (должно быть L21 + L22 − d2 в
числителе).

• Не ограничили cosβ в диапазоне [−1,1] и получили NaN при acos.

Решение

Формулы обратной кинематики (как выразить γ,α,β через (x,y,z) при достижимости)
выведены в решении задачи I. Здесь мы не повторяем вывод, а используем те же
обозначения и формулы, и подробно поясняем проверку достижимости.

1. Что значит «точка достижима»

Точка достижима тогда и только тогда, когда существует хотя бы один набор углов
(γ,α,β), удовлетворяющий одновременно:

• геометрии манипулятора (звенья длиной L1 и L2 в плоскости sZ действительно
«дотягиваются» до точки);

• ограничениям на углы:
−90◦ ≤ γ ≤ 90◦, 0◦ ≤ α ≤ 135◦, 20◦ ≤ β ≤ 180◦;

• выбранной конфигурации (как в задаче 3, «локоть вниз», то есть берём решение с
β ∈ [0◦,180◦] и далее проверяем диапазон [20◦,180◦]).

Важно: поворот основания γ не влияет на расстояние до точки, поэтому проверка удобно
делится на два независимых шага:

1. сначала проверяем достижимость точки в плоской задаче в координатах (s,z′);

2. затем проверяем, что вычисленный γ попадает в разрешённый диапазон.

2. Геометрическая проверка достижимости в плоскости sZ′
Как и в задаче 3, переходим к плоской задаче:
s = √x2 + y2, z′ = z − h.

В плоскости sZ′ нам нужно дотянуться двумя звеньями L1 и L2 от начала координат O
до точки B = (s,z′). Обозначим расстояние:
d = √s2 + (z′)2.

Геометрический смысл. Звенья L1 и L2 образуют треугольник OAB, где OA = L1,
AB = L2, а OB = d. Такой треугольник существует тогда и только тогда, когда
выполнено неравенство треугольника:

Практическая проверка.

|L1 − L2| ≤ d ≤ L1 + L2.

• Если d > L1 + L2, точка слишком далеко: NO.

• Если d < |L1 − L2|, точка слишком близко (есть «мертвая зона»): NO.

• Иначе треугольник существует, и геометрически точка достижима (без учёта ограничений на углы).

3. Проверка достижимости по ограничениям углов

Даже если треугольник существует, точка может быть запрещена из-за диапазонов углов. Поэтому после вычисления углов нужно проверить их диапазоны.

3.1. Угол γ

Если (x,y) ̸= (0,0), то
γ = atan2(y,x).
Если x = y = 0, можно положить γ = 0 (поворот вокруг Z не влияет на точку, так как
проекция на XY равна нулю).
Далее обязательно проверяем:

−90◦ ≤ γ ≤ 90◦.
Если нет — NO (нужный поворот основания запрещён).

3.2. Угол β (суставной угол)
Из решения задачи 3:

L21 + L22 − d2
2L1L2

существенно за [−1,1] — это уже обработано пунктом 2.
После вычисления проверяем ограничение задачи:
20◦ ≤ β ≤ 180◦.
Если нет — NO.

3.3. Угол α

4. Итоговый алгоритм вывода

1. Прочитать L1,L2,h,x,y,z.

2. Вычислить s = √x2 + y2, z′ = z − h, d = √s2 + (z′)2.

3. Если d < |L1 − L2| или d > L1 + L2, вывести NO.

4. Вычислить γ = atan2(y,x) (или 0 при x = y = 0). Если γ ∈/ [−90◦,90◦], вывести NO.

5. Вычислить β по формуле выше. Если β ∈/ [20◦,180◦], вывести NO.

6. Вычислить α = δ + ψ по формулам выше. Если α ∈/ [0◦,135◦], вывести NO.

7. Иначе вывести YES и во второй строке γ,α,β (в градусах, 3 знака).

Замечание: если требуется нормировать углы (например, привести α в диапазон [−180◦,180◦]),
это делается до проверки диапазонов, но в данной постановке при корректных вычислениях γ ∈ [−180◦,180◦], β ∈ [0◦,180◦], а α получается «естественным» из α = δ + ψ; затем

Шаг 4. Форма + площадь + центр прямоугольника

Что делаем: для каждого найденного контура:

• считаем площадь и отбрасываем контуры вне диапазона [Amin,Amax];

• определяем тип фигуры в строго определённом порядке:

– сначала проверяем, является ли фигура кругом или овалом;

– только если фигура не круглая, определяем многоугольную форму по
числу вершин approxPolyDP;

– квадрат и прямоугольник различаем по minAreaRect с допустимым отклонением 2%.

• если форма и площадь подходят, берём центр ограничивающего прямоугольника.

Почему важен такой порядок. Если сначала аппроксимировать контур многоугольником, то даже круг часто аппроксимируется 6–10 вершинами (из-за пиксельной границы и сглаживания) и ошибочно распознаётся как многоугольник. Поэтому в решении
сначала проверяется, является ли фигура достаточно круглой, и только потом анализируется число вершин.

Задача M. Перспективное преобразование: восстановить квадрат

Что видит робот?

На изображении, которое получает робот в камеру в перспективе виден квадрат, заданный четырьмя кругами одинакового цвета:

• круги находятся в вершинах квадрата;

• из-за перспективы в кадре видна трапеция;

• верхняя и нижняя стороны квадрата параллельны нижней границе изображения. Для определения размера квадрата считайте что нижняя сторона квадрата не искажена перспективой.

Дополнительные условия. В некоторых тестах между кругами могут присутствовать соединяющие линии того же цвета. Эти линии:

• не ближе одного диаметра круга к его краю;

• не влияют на правильный ответ;

• не обязательны для использования в решении.

Также могут присутствовать 2/3/5 кругов отличного от трапеции цвета.

Параметры

• диаметр кругов: от 10 до 40 пикселей;

• цвет кругов — один из: red, yellow, green, blue, black, white.

Цветовые диапазоны (RGB)

• red: R ∈ [235,255], G ∈ [0,20], B ∈ [0,20]

• yellow: R ∈ [235,255], G ∈ [235,255], B ∈ [0,20]

• green: R ∈ [0,20], G ∈ [235,255], B ∈ [0,20]

def order_points_trapezoid(pts):
# TL, TR, BR, BL
pts = pts.tolist()
pts.sort(key=lambda p: (p[1], p[0])) # по y, потом по x
top = sorted(pts[:2], key=lambda p: p[0])
bot = sorted(pts[2:], key=lambda p: p[0])
tl, tr = top[0], top[1]
bl, br = bot[0], bot[1]
return np.array([tl, tr, br, bl], dtype=np.float32)

Задача N. Ходы коня на шахматной доске

Условие

На изображении показана шахматная доска 8×8 в перспективе. Позиция коня отмечена
красным кругом внутри одной клетки.

Нужно определить, в какие клетки конь может попасть за один ход, и вывести
эти клетки в шахматной нотации.

Как устроено изображение

• Доска состоит из жёлтых и чёрных клеток (шахматный порядок).

• Вокруг доски есть чёрная рамка толщиной 20% от размера клетки.

• Доска видна в перспективе, при этом нижняя сторона доски параллельна
нижней стороне изображения.

• Размер доски на кадре: от 25% до 85% ширины кадра.

• Фон почти белый: каждый канал RGB в диапазоне [235,255].

Система координат клеток

Клетки обозначаются как в шахматах: буква + цифра.

• Буквы A..H идут слева направо вдоль нижней стороны доски.

• Цифры 1..8 идут снизу вверх.

То есть A1 — нижняя левая клетка, H8 — верхняя правая.

Идея решения

Доска в перспективе выглядит как трапеция. Мы превратим её в «вид сверху», чтобы
клетки стали ровной сеткой 8 × 8:

1. найдём внешнюю чёрную рамку доски;

2. выровняем доску через warpPerspective;

3. найдём красный круг и определим клетку;

4. посчитаем ходы коня и выведем клетки A1..H8.

Шаг 3. Ищем 4 угла и выравниваем доску

4.1. Выделяем красный цвет через inRange

В OpenCV цвет хранится как BGR (синий, зелёный, красный), а не RGB. Наш красный круг в генераторе имеет цвет примерно (B,G,R)=(10,10,245). Поэтому мы задаём
диапазон:

B ∈ [0,20], G ∈ [0,20], R ∈ [235,255].

Команда cv2.inRange проверяет каждый пиксель: если он попал в диапазон — в
маске будет 255, иначе 0.

# warped — выровненная картинка доски
mask_red = cv2.inRange(warped, (0,0,235), (20,20,255))

4.2. Зачем нужна морфология (и что такое OPEN)

Иногда на маске появляются маленькие “шумы”: одиночные белые точки или крошечные пятнышки. Например, из-за сжатия PNG, переходов на границах или небольших
артефактов.

Чтобы убрать такие мелкие мусорные точки, используют морфологические операции. Операция OPEN = эрозия + дилатация:
• эрозия “съедает” маленькие белые точки;

• дилатация возвращает размер большой фигуры обратно.
То есть OPEN оставляет большую фигуру (наш круг), но убирает мелкий мусор.
kernel = np.ones((3,3), np.uint8)
mask_red = cv2.morphologyEx(mask_red, cv2.MORPH_OPEN, kernel, iterations=1)

4.5. А если круг частично обрезан?

Иногда красный круг может быть близко к краю выровненного изображения warped.
Тогда часть круга может “обрезаться”.
Это не проблема, потому что:

• маска всё равно содержит большую часть круга;

• контур находится;

• моменты дают центр по оставшейся части.
А дальше в шаге 5 мы всё равно переводим (cx,cy) в номер клетки, и небольшой
сдвиг обычно не меняет клетку, потому что маркер лежит внутри клетки, а не на
границе.

Но часть ходов может выходить за границы доски, например, если конь стоит у края.
Поэтому внутри функции мы:

• перебираем все 8 смещений (dx,dy);

• считаем новую клетку (nf,nr) = (file_idx + dx, rank_idx + dy);

• оставляем только те, где 0 ≤ nf < 8 и 0 ≤ nr < 8.
def knight_moves(f, r):
deltas = [(1,2),(2,1),(-1,2),(-2,1),(1,-2),(2,-1),(-1,-2),(-2,-1)]
res = []
for dx, dy in deltas:
nf, nr = f + dx, r + dy
if 0 <= nf < 8 and 0 <= nr < 8:
res.append((nf, nr))
# сортируем, чтобы ответ всегда был в одном и том же порядке
res.sort(key=lambda t: (t[0], t[1]))
return res

Мы сортируем клетки в knight_moves по правилу: сначала по букве (A..H), затем по
цифре (1..8). Тогда:

• ответ получается однозначным и будет соответствовать требованиям условия задачи;
После knight_moves у нас список пар чисел, например:
[(0,2), (2,2), (3,1), (3,3)].

Однако в ответе нужно печатать шахматные обозначения: A3, C3, D2, D4. Для этого
каждая пара (f,r) должна превратиться в строку функцией sq_name:

• f = 0..7 переводим в букву A..H;

• r = 0..7 переводим в цифру 1..8 (по формуле r + 1).
def sq_name(f, r):
# f=0 -> 'A', f=7 -> 'H'
letter = chr(ord('A') + f)
# r=0 -> '1', r=7 -> '8'
digit = str(r + 1)
return letter + digit
moves = knight_moves(file_idx, rank_idx)
ans = [sq_name(f, r) for (f, r) in moves]
