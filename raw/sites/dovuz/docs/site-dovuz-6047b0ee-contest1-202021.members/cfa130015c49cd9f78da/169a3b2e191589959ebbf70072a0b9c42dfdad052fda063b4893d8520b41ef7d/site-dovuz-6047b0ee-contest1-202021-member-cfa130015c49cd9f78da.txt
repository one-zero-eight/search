Nice Shape

Имя входного файла: стандартный ввод
Имя выходного файла: стандартный вывод
Ограничение по времени: 4 секунды
Ограничение по памяти: 512 мегабайт

Вам даны n ладей на бесконечной шахматной доске.
i-я из них находится в клетке (ri,ci).

За один ход вы можете переместить любую ладью на любую клетку в той же строке/столбце.
Иначе говоря, за один ход вы можете выбрать любое i а затем либо заменить ri на любое целое
число, либо заменить ci на любое целое число. Вы не можете двигать ладью в клетку, которая
содержит другую ладью.

Четыре разные ладьи a,b,c,d образуют симпатичную фигуру если вы можете найти прямоугольник, что a,b,c,d это его углы. Иначе говоря, если множество клеток {(ra,ca),(rb,cb),(rc,cc),(rd,cd)}
совпадает с множеством {(x1,y1),(x1,y2),(x2,y1),(x2,y2)} для какого-то набора целых чисел
x1,x2,y1,y2, где x1 = x2 и y1 = y2

Например, белые ладьи на следующей картинке образуют симптатичную фигуру.

Ваша задача — найти минимальное количество действий, которое нужно совершить, чтобы получить симпатичную фигурку.

Иначе говоря, вам нужно найти минимальное число операций, после которого может найтись
прямоугольник, который содержит ладьи в четырех углах.

Формат входных данных

В первой строке записано одно целое число t (1 t 25000): количество наборов входных
данных.
Далее следуют описания t наборов входных данных.
В первой строке записано одно целое число n (4 n 100000).
В i-й из следующих n строк записаны два целых числа ri,ci (1 ri,ci 109)
Для каждой пары i,j, что i = j, выполнено ri = rj или ci = cj.
Сумма по всем n не превосходит 100000.

Формат выходных данных

Для каждого набора входных данных, выведите одно целое число: минимальное количество
действий, которое нужно совершить, чтобы получить хотя бы одну симпатичную фигуру среди
данных ладей.

Система оценки

| Подзадача | Баллы | Ограничения |
| --- | --- | --- |
| 1 | 10 | n 4 |
| 2 | 10 | n 50 |
| 3 | 10 | n 200 |
| 4 | 30 | n 2000 |
| 5 | 40 | n 105 |
