Решение задачи “Статистика текста”

1. Импорт библиотек
import re
import zipfile
from collections import Counter

Для решения задачи используются стандартные библиотеки Python:

 re для работы с регулярными выражениями при извлечении слов

 zipfile для создания архива с результатами

 Counter из collections для подсчета частот длин слов при расчете моды

2. Извлечение слов из текста
def find_words(content):
return re.findall(r'[a-zA-Zа-яА-ЯёЁ]+', content)

Функция find_words извлекает все слова из текста по правилам задачи. Регулярное
выражение [a-zA-Zа-яА-ЯёЁ]+ находит непрерывные последовательности
буквенных символов (латинских и кириллических, включая ё), игнорируя все
остальные символы как разделители.

3. Чтение файла и извлечение слов
with open('text.txt', 'r', encoding='utf-8') as file:
content = file.read()
words = find_words(content)

Считываем содержимое входного файла text.txt в кодировке UTF-8 и передаем его
в функцию извлечения слов. Результат сохраняется в список words.

4. Сохранение извлеченных слов
with open('words.txt', 'w', encoding='utf-8') as file:
for word in words:
file.write(word + '\n')

Записываем каждое извлеченное слово в файл words.txt, каждое слово на новой
строке. Файл сохраняется в кодировке UTF-8 для корректного отображения русских
и английских букв.

5. Расчет статистических метрик
def count_stats(lengths):
count = len(lengths)
if count == 0:
return 0.0, 0, 0
total = sum(lengths)
avg = total / count
sorted_lengths = sorted(lengths)
position = (count - 1) // 2
middle = sorted_lengths[position]
freq = Counter(lengths)
max_count = max(freq.values())
candidates = [l for l, c in freq.items() if c == max_count]
common = min(candidates)
return avg, middle, common
word_lengths = [len(w) for w in words]
average, middle, common = count_stats(word_lengths)

Функция count_stats рассчитывает три статистические метрики:

 Среднее арифметическое: сумма длин всех слов деленная на их количество

 Медиана: значение в середине отсортированного списка длин (нижняя
медиана при четном числе элементов)

 Мода: наиболее частая длина слова, при равенстве частот выбирается
наименьшее значение

Сначала создаем список длин всех слов, затем передаем его в функцию расчета
статистики.

6. Сохранение результатов
with open('result.txt', 'w', encoding='utf-8') as file:
file.write(f"{average:.6f}\n")
file.write(f"{middle}\n")
file.write(f"{common}\n")

Записываем результаты в файл result.txt в требуемом формате:

 Первая строка: среднее арифметическое с точностью 6 знаков после запятой

 Вторая строка: медиана (целое число)

 Третья строка: мода (целое число)

7. Создание архива
with zipfile.ZipFile('task1.zip', 'w') as archive:
archive.write('words.txt')
archive.write('result.txt')

Создаем ZIP-архив task1.zip и добавляем в него оба результирующих файла:
words.txt и result.txt.

def calculate_window_stats(values, center_index):
window = values[center_index-5:center_index+6]
window_size = len(window)
mean_value = sum(window) / window_size
squared_diffs = [(x - mean_value) ** 2 for x in window]
variance = sum(squared_diffs) / window_size
std_dev = math.sqrt(variance)
return mean_value, std_dev

Функция calculate_window_stats вычисляет среднее значение и стандартное
отклонение для окна из 11 точек вокруг указанного индекса. Используется
популяционная формула для стандартного отклонения.

def convolve_image(input_image, filter_kernel):
image_height, image_width = input_image.shape
kernel_size = filter_kernel.shape[0]
padding_size = kernel_size // 2
padded_image = np.pad(input_image, padding_size, mode='reflect')
output_image = np.zeros_like(input_image, dtype=np.float32)
for y in range(image_height):
for x in range(image_width):
region = padded_image[y:y+kernel_size, x:x+kernel_size]
output_image[y, x] = np.sum(region * filter_kernel)
return output_image

Эта функция применяет свертку к изображению: - Обрабатывает пиксели на
границах с использованием отражения - Извлекает области изображения,

def create_convolution_matrix(filter_weights, step_size, image_dimension=8):
filter_height, filter_width = filter_weights.shape
output_height = (image_dimension - filter_height) // step_size + 1
output_width = (image_dimension - filter_width) // step_size + 1
total_output_pixels = output_height * output_width
total_input_pixels = image_dimension * image_dimension
convolution_matrix = np.zeros((total_output_pixels, total_input_pixels))
for output_row in range(output_height):
for output_col in range(output_width):
matrix_row = output_row * output_width + output_col
start_row = output_row * step_size
start_col = output_col * step_size
for filter_row in range(filter_height):
for filter_col in range(filter_width):
input_row = start_row + filter_row
input_col = start_col + filter_col
matrix_col = input_row * image_dimension + input_col
convolution_matrix[matrix_row, matrix_col] = filter_weights[
filter_row, filter_col]
return convolution_matrix

def find_objects(grid):
objects = {'S': [], 'T': [], 'X': []}
for i, row in enumerate(grid):
for j, cell in enumerate(row):
if cell in objects:
objects[cell].append((i, j))
return objects

Функция find_objects проходит по всей сетке и сохраняет координаты стартовой

3. Движение по сетке
def next_position(row, col, direction, height, width):
new_row, new_col = row, col
if direction == 'up':
new_row = max(0, row - 1)
elif direction == 'down':
new_row = min(height - 1, row + 1)
elif direction == 'left':
new_col = max(0, col - 1)
elif direction == 'right':
new_col = min(width - 1, col + 1)
return new_row, new_col

Функция next_position вычисляет новую позицию агента при движении в заданном
направлении. Если движение выходит за границы сетки, агент остается на текущей
позиции.

def get_reward(cell):
if cell == 'T':
return 10.0
elif cell == 'X':
return -5.0
else:
return -0.1

Функция get_reward определяет награду за переход в указанную клетку: +10 за
сокровище, -5 за ловушку, -0.1 за все остальные переходы.

5. Алгоритм Value Iteration
def value_iteration(grid, gamma=0.9, steps=100):
height = len(grid)
width = len(grid[0])
directions = ['up', 'down', 'left', 'right']
values = [[0.0] * width for _ in range(height)]
first_step_values = None
for step in range(steps):
new_values = [[0.0] * width for _ in range(height)]
for i in range(height):
for j in range(width):
if grid[i][j] in ['T', 'X']:
new_values[i][j] = 0.0
continue
best_value = -float('inf')
for direction in directions:
ni, nj = next_position(i, j, direction, height, width)
reward = get_reward(grid[ni][nj])
value = reward + gamma * values[ni][nj]
if value > best_value:
best_value = value
new_values[i][j] = best_value
if step == 0:
first_step_values = [row[:] for row in new_values]
values = new_values
return values, first_step_values

Алгоритм Value Iteration выполняет 100 итераций для вычисления оптимальной
ценности каждого состояния. На каждой итерации:

 Для терминальных состояний (T, X) значение остается равным 0

 Для остальных состояний вычисляется максимальная ценность по всем
возможным действиям

 После первой итерации сохраняются значения для файла v1.txt
