Problem A. Shustrik, Persik, and Eternal Friendship

Time limit: 1 second

In an ancient temple, a legendary treasure is hidden, symbolizing the eternal friendship of the hamster
Shustrik and the cat Persik. Shustrik and Persik want to show you this magical place. To get there, they
need to open the gates of the ancient temple, which requires arranging a circular mosaic of sacred symbols
(digits 0-9) in the correct order.

The mosaic will be considered arranged in the correct order if the potential of the string of sacred symbols
and the number of applications of the magical operation are minimized. The potential of a string is defined
as the number of blocks of identical digits it consists of. For example, the potential of the string 112223
is 3, while for 12233321 it is 5. The magical operation that Shustrik and Persik can perform is as follows:
they can cyclically shift the string to the right or left by 1. Since the place is truly magical, the friends
can perform this operation as many times as they want.

Help Shustrik and Persik calculate how many times they will have to apply the magical operation for
the mosaic to be arranged in the correct order. Remember that the mosaic is considered arranged in the
correct order only when both the potential of the string of sacred symbols and the number of applications
of the magical operation are minimized.

Input

The first line contains a single integer n (1 ≤ n ≤ 106).
The second line contains the string s — the mosaic of sacred symbols.

Output

Output the number of magical operations that Shustrik and Persik will have to perform. If during the
magical operations the friends shift to the left, output the number of magical operations with a negative
sign «-» (without quotes); if to the right, output it without the negative sign «-».

Scoring

| 3 | 30 | n ≤ 1000 | 1, 2 |

Problem B. Magic Circle

Time limit: 2 seconds
n wizards stood in a circle and decided to perform q rituals.

We number the wizards from 1 to n in a clockwise direction. The i-th ritual involves wizard number k if
there exists a non-negative integer x such that (firsti + stepi · x − 1) mod n + 1 = k, where mod is
the modulus operation. For better understanding, it is worth looking at the illustration in the example.

Initially, each wizard had 1018 units of mana. The i-th ritual changes the mana of the involved wizards by
costi. That is, if costi > 0, the mana increases by |costi| units; if costi < 0, it decreases by |costi| units;
and if costi = 0, it remains unchanged.

Determine the number of the wizard with the most mana after all q rituals. If there are several, choose
the one with the smallest number.

Input

The first line contains two integers n and q (1 ≤ n,q ≤ 2 · 105).

In the i-th of the following q lines, there are 3 integers firsti, stepi, and costi (1 ≤ firsti ≤ n;
1 ≤ stepi ≤ 109; −109 ≤ costi ≤ 109).

Output

Output a single number—the number of the wizard with the most mana after all q rituals. If there are
several, choose the one with the smallest number.

Scoring

Problem C. Pleasant Paths

Time limit: 1 second

The map of the forest represents a rooted tree, where the vertices are clearings, the edges are paths
between them, and the weight of an edge is the popularity of these paths. All clearings are numbered
from 1 to n.

Hedgehog Shurshik lives in the clearing located at the root vertex number 1. During each of his walks, the
hedgehog starts from vertex 1 and goes to the leaf vertices for the tastiest apples, but only via a pleasant
path. A pleasant path in the tree is a path from the root vertex to a leaf vertex such that at each descent,
the hedgehog chooses the least popular road (i.e., descends along the edge with the smallest popularity
value, and if there are several, to the vertex with the smallest number). A vertex is called a leaf if it has
exactly one outgoing path and is not the root.

Shurshik made q walks, each of which followed several rules: first, the hedgehog found a pleasant path,
then added +1 to the popularity of all edges on the path. Help Shurshik determine how many times he
will visit each leaf vertex.

Input

Each test consists of several testcases. The first line contains a single integer t (1 ≤ t ≤ 104) — the number
of testcases. The following describes the testcases.

The first line contains two integers n and q (2 ≤ n ≤ 2 · 105, 0 ≤ q ≤ 1018) — the number of vertices in
the tree and the number of walks made by Shurshik.

The next n−1 lines describe the edges of the tree. Each line contains three integers ui, vi, wi (1 ≤ ui,vi ≤ n,
0 ≤ wi ≤ 1018) — the numbers of the vertices connected by the path and its initial popularity.

It is guaranteed that the sum of n across all tests does not exceed 2 · 105 and the given graph is a tree
with vertex 1 as the root.

Output

For each testcase, output the information about the visits to the leaf vertices.
For each leaf vertex in ascending order of its number, output on a separate line two numbers: the leaf
number and the number of times Shurshik visited this leaf during all q walks.

Problem D. Hamster Spectacle

Time limit: 5 seconds

In the famous Hamster Academy, an annual olympiad among hamsters is held. In a row, there are n
hamsters in shirts, each with the personal record of the hamster in running on a wheel — a positive
integer ai (how many laps per minute the hamster can do). Each record number X can be broken down
into special skills. All the skills that a hamster possesses are the numbers that are divisors of X. For
example, a hamster with a record of 12 has skills 1, 2, 3, 4, 6, 12. The more unique skills a group of
hamsters demonstrates, the more spectacular the performance.

To evaluate, judges can choose a continuous team of hamsters — from the L-th to the R-th in the
row. However, the more hamsters in the team, the harder it is to organize and feed them, making the
performance less spectacular. The cost of maintaining the team is equal to its size (R − L + 1) and
corresponds to the value by which the spectacle of the corresponding team of hamsters decreases.

Help determine which spectacle of performances will be maximal. The final spectacle of the performance
is defined as F(L,R) = X − (R − L + 1), where X is the number of distinct positive integers that are
special skills of at least one hamster with a record ai, such that L ≤ i ≤ R; and R − L + 1 is the cost of
maintaining the team from the L-th to the R-th hamster in the row.

Recall that a divisor of an integer s is an integer d such that s is divisible by d without a remainder.

Input

In the first line, there is one integer n (1 ≤ n ≤ 5 · 105) — the length of the row of sitting hamsters.
In the second line, there are n integers a1, a2, ..., an (1 ≤ ai ≤ 5 · 106) — the numbers written on the
shirts of the hamsters.

Output

Output a single integer — the maximum value of the spectacle of the hamsters’ performance F(L,R).

Scoring

group, all tests of the necessary groups for it, and tests from the problem statement are passed.

To be straightforward — cat Persik† loves bracket sequences and powers of two!
Persik plays with the string s — several times (possibly zero) he divides it into parts and assembles it
back.
In one step, the following occurs:
The sequence is divided into blocks of length m = 2x (x ≥ 1), each block is split into two halves, and the
halves within the block are swapped.

We are interested in when Persik will get tired of playing (i.e., when he gets bored of changing the original
string) — to do this, help us find out (depending on the type of query):

1. How many different ways are there to obtain a valid bracket sequence‡ (VBS) from the original
string s while Persik plays with it. Two ways are considered different if for some i the character
originally at position i has moved to different positions in these two ways.

2. How many different VBS can be obtained from the original string. Two VBS a,b are considered

For each string, output the required number:

For Q = 1 — the number of different permutations such that the resulting string is a VBS.
